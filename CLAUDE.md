# Piscine

Plateforme web d'exercices appliqués pour le programme MMI (voir README.md).

## Lancer le projet
Prototype statique, sans installation. Depuis la racine du dépôt :
​```bash
python3 -m http.server 8000
​```
URL : http://localhost:8000/src/

## Structure
​```
src/        code source (index.html, style.css, script.js)
assets/     images, sons, polices
README.md   document de cadrage
​```

## Conventions
- kebab-case pour les fichiers, commentaires en français.
- Garder cette même organisation sur tous mes projets.
