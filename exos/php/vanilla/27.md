## Cours
Le **contrôleur** relie le modèle et la vue : il reçoit une demande, interroge le **modèle**, puis choisit la **vue** à afficher avec les bonnes données.

Le **routage** décide quel contrôleur (et quelle méthode) répond à quelle demande. Sur un vrai site, tout passe par un seul fichier d'entrée, `index.php`, qui lit l'action demandée (par exemple `index.php?action=liste`) et appelle la bonne méthode.

```php
function router(string $action): void {
    switch ($action) {
        case "accueil":
            echo "Bienvenue";
            break;
        default:
            http_response_code(404);   // le serveur répond « 404 Not Found »
            echo "Page introuvable";
    }
}
```

- Chaque action connue est un `case`. Le `default` couvre **tout le reste** : c'est ta page 404.
- `http_response_code(404)` fixe le code HTTP de la réponse. Sans lui, une page « introuvable » répondrait quand même `200 OK`. Il faut l'appeler **avant** tout affichage.
- Un contrôleur ne contient **ni HTML ni requête de données** : il appelle le modèle et la vue.

## Énoncé
Dans `index.php`, recopie ce début (un modèle et une vue déjà prêts). Sa première ligne, `ob_start()`, retient l'affichage : le code HTTP ne peut être changé **qu'avant** tout affichage, or on va simuler plusieurs requêtes à la suite.

```php
ob_start();

class ProduitModele {
    private array $produits = [
        1 => ["nom" => "Clavier", "prix" => 45],
        2 => ["nom" => "Souris", "prix" => 20],
    ];
    public function tous(): array { return $this->produits; }
    public function trouver(int $id): ?array { return $this->produits[$id] ?? null; }
}

function rendre(string $vue, array $donnees): string {
    extract($donnees);
    ob_start();
    require sys_get_temp_dir() . "/vues27/" . $vue . ".php";
    return ob_get_clean();
}

@mkdir(sys_get_temp_dir() . "/vues27");
file_put_contents(sys_get_temp_dir() . "/vues27/liste.php",
    '<ul><?php foreach ($produits as $p): ?><li><?= htmlspecialchars($p["nom"]) ?></li><?php endforeach; ?></ul>');
file_put_contents(sys_get_temp_dir() . "/vues27/fiche.php",
    '<h1><?= htmlspecialchars($produit["nom"]) ?> : <?= $produit["prix"] ?> €</h1>');
```

1. Écris une classe `ProduitControleur` avec deux méthodes :
   - `liste()` : demande tous les produits au modèle puis **affiche** la vue `liste`,
   - `fiche(int $id)` : cherche le produit dans le modèle. S'il existe, **affiche** la vue `fiche` ; sinon, affiche `Produit introuvable` avec le code **404**.
2. Écris une fonction `router(string $action, int $id = 0)` : `liste` appelle `liste()`, `fiche` appelle `fiche($id)`, et toute autre action fixe le code **404** puis affiche `Page introuvable`.
3. Appelle `router` quatre fois, chaque appel suivi d'un saut de ligne `"\n"` : `liste`, `fiche` avec l'id `2`, `fiche` avec l'id `99`, puis `contact`.

## Méthode
- [ ] Le contrôleur crée le modèle (`new ProduitModele()`) et appelle `rendre(...)`
- [ ] Le `default` du `switch` (ou le `else`) gère la page 404
- [ ] Pas de HTML écrit dans le contrôleur : il est dans les vues

## Résultat
- [ ] Ligne 1 : `<ul><li>Clavier</li><li>Souris</li></ul>`
- [ ] Ligne 2 : `<h1>Souris : 20 €</h1>`
- [ ] Ligne 3 : `Produit introuvable`
- [ ] Ligne 4 : `Page introuvable`

## Indice
Dans `router`, un `switch ($action)` avec `case "liste":`, `case "fiche":` et un `default:` suffit. N'oublie pas le `break;` à la fin de chaque `case`.

## Solution: index.php
```php
<?php

ob_start();

class ProduitModele {
    private array $produits = [
        1 => ["nom" => "Clavier", "prix" => 45],
        2 => ["nom" => "Souris", "prix" => 20],
    ];
    public function tous(): array { return $this->produits; }
    public function trouver(int $id): ?array { return $this->produits[$id] ?? null; }
}

function rendre(string $vue, array $donnees): string {
    extract($donnees);
    ob_start();
    require sys_get_temp_dir() . "/vues27/" . $vue . ".php";
    return ob_get_clean();
}

@mkdir(sys_get_temp_dir() . "/vues27");
file_put_contents(sys_get_temp_dir() . "/vues27/liste.php",
    '<ul><?php foreach ($produits as $p): ?><li><?= htmlspecialchars($p["nom"]) ?></li><?php endforeach; ?></ul>');
file_put_contents(sys_get_temp_dir() . "/vues27/fiche.php",
    '<h1><?= htmlspecialchars($produit["nom"]) ?> : <?= $produit["prix"] ?> €</h1>');

class ProduitControleur {
    public function liste(): void {
        $modele = new ProduitModele();
        echo rendre("liste", ["produits" => $modele->tous()]);
    }

    public function fiche(int $id): void {
        $modele = new ProduitModele();
        $produit = $modele->trouver($id);
        if ($produit === null) {
            http_response_code(404);
            echo "Produit introuvable";
            return;
        }
        echo rendre("fiche", ["produit" => $produit]);
    }
}

function router(string $action, int $id = 0): void {
    $controleur = new ProduitControleur();
    switch ($action) {
        case "liste":
            $controleur->liste();
            break;
        case "fiche":
            $controleur->fiche($id);
            break;
        default:
            http_response_code(404);
            echo "Page introuvable";
    }
}

router("liste");
echo "\n";
router("fiche", 2);
echo "\n";
router("fiche", 99);
echo "\n";
router("contact");
echo "\n";
```
