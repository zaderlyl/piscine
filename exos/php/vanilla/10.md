## Cours
Le **constructeur** est une méthode spéciale, `__construct`, que PHP exécute **automatiquement** à chaque `new`. Il sert à préparer l'objet : on lui passe directement les valeurs de départ, au lieu d'affecter les attributs un par un.

```php
class Joueur {
    public string $pseudo;
    public int $points;

    public function __construct(string $pseudo, int $points = 0) {
        $this->pseudo = $pseudo;
        $this->points = $points;
    }
}

$a = new Joueur("Lea", 50);
$b = new Joueur("Tom");   // points vaut 0 : valeur par défaut
```

- On n'appelle jamais `__construct` à la main : c'est `new` qui le fait.
- Un paramètre avec une **valeur par défaut** (`$points = 0`) est facultatif.
- Le constructeur ne renvoie rien.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec les attributs publics `$nom` (`string`) et `$energie` (`int`).
2. Ajoute un constructeur qui reçoit `$nom` et `$energie`. Le paramètre `$energie` vaut **100 par défaut**.
3. Ajoute une méthode `getDescription()` qui **renvoie** (avec `return`) le texte `nom : energie`, par exemple `R2D2 : 80`.
4. Crée un robot `R2D2` avec l'énergie `80`, puis un robot `Wall-E` **sans préciser l'énergie**.
5. Affiche la description de chacun, un par ligne : utilise `echo ... . "\n";`.

## Méthode
- [ ] Le constructeur s'écrit `public function __construct(string $nom, int $energie = 100)`
- [ ] Affecte les attributs dans le constructeur avec `$this->`
- [ ] `getDescription()` utilise `return`, c'est le `echo` qui affiche

## Résultat
- [ ] Première ligne : `R2D2 : 80`
- [ ] Deuxième ligne : `Wall-E : 100`

## Indice
`new Robot("Wall-E")` ne donne qu'un argument : PHP utilise alors la valeur par défaut du deuxième paramètre.

## Solution: index.php
```php
<?php

class Robot {
    public string $nom;
    public int $energie;

    public function __construct(string $nom, int $energie = 100) {
        $this->nom = $nom;
        $this->energie = $energie;
    }

    public function getDescription(): string {
        return $this->nom . " : " . $this->energie;
    }
}

$r1 = new Robot("R2D2", 80);
$r2 = new Robot("Wall-E");

echo $r1->getDescription() . "\n";
echo $r2->getDescription() . "\n";
```
