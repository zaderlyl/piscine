## Cours
Jusqu'ici, n'importe quel code pouvait lire et modifier les attributs d'un objet. L'**encapsulation** consiste à les protéger avec `private` : seul le code **de la classe** peut alors y toucher.

```php
class Compte {
    private int $solde = 100;

    public function getSolde(): int {   // getter : lit, ne modifie rien
        return $this->solde;
    }
}

$c = new Compte();
echo $c->getSolde();  // 100
echo $c->solde;       // Erreur : attribut private
```

- `public` : accessible partout. `private` : accessible **uniquement dans la classe**.
- Pour lire un attribut `private` depuis l'extérieur, on écrit un **getter** (accesseur), par convention `getNom()`.
- Un getter **renvoie** une valeur avec `return` et ne modifie pas l'objet.
- Lire un attribut `private` depuis l'extérieur provoque une `Error` : on peut l'attraper avec `try / catch (Error $e)`.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec deux attributs **privés** : `$nom` (`string`) et `$energie` (`int`).
2. Ajoute un constructeur qui reçoit le nom et l'énergie.
3. Ajoute les getters `getNom()` et `getEnergie()`.
4. Crée le robot `R2D2` d'énergie `80`, puis affiche, un par ligne, son nom et son énergie **avec les getters**.
5. Essaie ensuite de lire directement `$robot->energie` dans un `try`, et affiche `Accès interdit` dans le `catch (Error $e)`.

## Méthode
- [ ] Mets `private` devant chaque attribut
- [ ] Les getters ont `return $this->...`
- [ ] Entoure la lecture directe d'un `try { ... } catch (Error $e) { ... }`

## Résultat
- [ ] Ligne 1 : `R2D2`
- [ ] Ligne 2 : `80`
- [ ] Ligne 3 : `Accès interdit`

## Indice
Dans le `try`, écris `echo $robot->energie;` : PHP lève une erreur car l'attribut est `private`, et le `catch` affiche ton message.

## Solution: index.php
```php
<?php

class Robot {
    private string $nom;
    private int $energie;

    public function __construct(string $nom, int $energie) {
        $this->nom = $nom;
        $this->energie = $energie;
    }

    public function getNom(): string {
        return $this->nom;
    }

    public function getEnergie(): int {
        return $this->energie;
    }
}

$robot = new Robot("R2D2", 80);

echo $robot->getNom() . "\n";
echo $robot->getEnergie() . "\n";

try {
    echo $robot->energie;
} catch (Error $e) {
    echo "Accès interdit\n";
}
```
