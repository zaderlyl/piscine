## Cours
L'**héritage** permet de créer une classe **fille** à partir d'une classe **mère** : la fille reprend tout ce que fait la mère, et ajoute ses propres éléments. Elle s'écrit avec `extends`. On dit « un explorateur **est un** robot ».

```php
class Animal {
    private string $nom;

    public function __construct(string $nom) {
        $this->nom = $nom;
    }

    public function getNom(): string {
        return $this->nom;
    }
}

class Chien extends Animal {
    private string $race;

    public function __construct(string $nom, string $race) {
        parent::__construct($nom);   // initialise la partie « Animal »
        $this->race = $race;
    }

    public function getRace(): string {
        return $this->race;
    }
}

$c = new Chien("Rex", "Berger");
echo $c->getNom();   // méthode héritée de Animal
```

- `parent::__construct(...)` exécute le constructeur de la mère, pour initialiser ce qui est hérité.
- La fille peut utiliser toutes les méthodes publiques de la mère (ici `getNom()`).
- `$objet instanceof Classe` vaut `true` si l'objet est de cette classe **ou d'une de ses classes filles**.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec un attribut privé `$nom`, un constructeur qui le reçoit et un getter `getNom()`.
2. Écris une classe `RobotExplorateur` qui **hérite** de `Robot`. Elle ajoute un attribut privé `$planete`, un constructeur `($nom, $planete)` qui appelle `parent::__construct`, et un getter `getPlanete()`.
3. Crée un tableau `$robots` contenant un `Robot` nommé `R2D2` et un `RobotExplorateur` nommé `Opportunity` qui explore `Mars`.
4. Avec un `foreach`, affiche le nom de chaque robot, un par ligne. Pour un explorateur, ajoute ` - ` puis sa planète (utilise `instanceof`).

## Méthode
- [ ] `class RobotExplorateur extends Robot`
- [ ] Appelle `parent::__construct($nom);` en premier dans le constructeur de la fille
- [ ] Dans la boucle, teste `$robot instanceof RobotExplorateur` avant d'appeler `getPlanete()`

## Résultat
- [ ] Ligne 1 : `R2D2`
- [ ] Ligne 2 : `Opportunity - Mars`

## Indice
`getNom()` n'est écrit que dans `Robot`, mais `RobotExplorateur` l'a aussi : c'est ce qu'on appelle hériter.

## Tests
```js
const lignes = sortie.trim().split("\n").map((l) => l.trim());
assert(lignes[0] === "R2D2", "Ligne 1 : le nom du robot ordinaire");
assert(lignes[1] === "Opportunity - Mars", "Ligne 2 : « Opportunity - Mars »");
assert(/class\s+RobotExplorateur\s+extends\s+Robot\b/.test(code), "RobotExplorateur doit hériter de Robot (extends)");

```

## Solution: index.php
```php
<?php

class Robot {
    private string $nom;

    public function __construct(string $nom) {
        $this->nom = $nom;
    }

    public function getNom(): string {
        return $this->nom;
    }
}

class RobotExplorateur extends Robot {
    private string $planete;

    public function __construct(string $nom, string $planete) {
        parent::__construct($nom);
        $this->planete = $planete;
    }

    public function getPlanete(): string {
        return $this->planete;
    }
}

$robots = [
    new Robot("R2D2"),
    new RobotExplorateur("Opportunity", "Mars"),
];

foreach ($robots as $robot) {
    echo $robot->getNom();
    if ($robot instanceof RobotExplorateur) {
        echo " - " . $robot->getPlanete();
    }
    echo "\n";
}
```
