## Cours
Quand ton JavaScript envoie des données avec `fetch`, il envoie souvent du **JSON** dans le corps de la requête :

```js
fetch("/api/utilisateur.php", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ nom: "Lea", age: 20 }),
});
```

Piège : côté PHP, **`$_POST` est vide** ! `$_POST` ne contient que les formulaires classiques. Le JSON arrive dans le **flux brut** de la requête, qu'on lit avec :

```php
$corps = file_get_contents("php://input");   // le texte JSON reçu
```

Il faut ensuite le transformer en tableau PHP avec `json_decode` :

```php
$donnees = json_decode($corps, true);   // true : on veut un tableau associatif
echo $donnees["nom"];                   // Lea
```

Si le JSON est mal formé, `json_decode` renvoie `null` sans rien dire. Avec le drapeau `JSON_THROW_ON_ERROR`, il lève à la place une `JsonException` que l'on attrape :

```php
try {
    $donnees = json_decode($corps, true, 512, JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
    // le JSON était invalide
}
```

Dans cet exo, il n'y a pas de vraie requête : le texte JSON reçu est simplement mis dans une variable `$corps`.

## Énoncé
Dans `index.php` :
1. Écris une fonction `lireJson(string $corps): ?array` qui décode le JSON en tableau associatif avec `JSON_THROW_ON_ERROR`. Si le JSON est invalide (`JsonException`), elle renvoie `null`.
2. Appelle-la avec le corps `{"nom":"Lea","age":20}` et affiche `Lea a 20 ans` (nom et âge viennent des données décodées).
3. Appelle-la avec le corps invalide `{"nom": ` et affiche `JSON invalide` quand elle renvoie `null`.

Un résultat par ligne.

## Méthode
- [ ] `json_decode($corps, true, 512, JSON_THROW_ON_ERROR)` dans un `try`
- [ ] `catch (JsonException $e)` renvoie `null`
- [ ] Le `echo` est fait en dehors de la fonction

## Résultat
- [ ] Ligne 1 : `Lea a 20 ans`
- [ ] Ligne 2 : `JSON invalide`

## Indice
Les trois premiers arguments de `json_decode` sont le texte, `true` (tableau associatif) et la profondeur `512`. Le drapeau vient en quatrième.

## Solution: index.php
```php
<?php

function lireJson(string $corps): ?array {
    try {
        return json_decode($corps, true, 512, JSON_THROW_ON_ERROR);
    } catch (JsonException $e) {
        return null;
    }
}

$donnees = lireJson('{"nom":"Lea","age":20}');
echo $donnees["nom"] . " a " . $donnees["age"] . " ans\n";

$donnees = lireJson('{"nom": ');
if ($donnees === null) {
    echo "JSON invalide\n";
}
```
