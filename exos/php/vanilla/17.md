## Cours
**PDO** est l'outil de PHP pour parler à une base de données. On commence toujours par créer une connexion avec `new PDO(...)` : on lui donne un **DSN**, c'est-à-dire l'adresse de la base.

```php
$pdo = new PDO("sqlite:ma-base.db");     // un fichier SQLite
$pdo = new PDO("sqlite::memory:");        // une base temporaire, gardée en mémoire
```

Ici on utilise **SQLite** avec `sqlite::memory:` : aucune installation, la base disparaît à la fin du programme. C'est parfait pour s'entraîner.

Par défaut, PDO reste silencieux quand il y a une erreur. On lui demande de **lever une exception** (`PDOException`) avec :

```php
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
```

On peut alors attraper l'erreur avec un `try/catch` :

```php
try {
    $pdo = new PDO("sqlite:/dossier/inexistant/base.db");
} catch (PDOException $e) {
    echo "Connexion impossible";
}
```

## Énoncé
Dans `index.php` :
1. Écris une fonction `connecter(string $dsn): ?PDO` qui crée la connexion avec le DSN reçu, active `PDO::ERRMODE_EXCEPTION`, et la renvoie. Si une `PDOException` est levée, elle renvoie `null`.
2. Appelle-la avec `sqlite::memory:` : si le résultat n'est pas `null`, affiche `Connecté`.
3. Appelle-la avec `sqlite:/dossier/inexistant/base.db` : si le résultat est `null`, affiche `Connexion impossible`.

Un résultat par ligne.

## Méthode
- [ ] Le `new PDO(...)` est dans un `try`
- [ ] `catch (PDOException $e)` renvoie `null`
- [ ] Le mode d'erreur est réglé avec `setAttribute`
- [ ] Les `echo` sont faits en dehors de la fonction

## Résultat
- [ ] Ligne 1 : `Connecté`
- [ ] Ligne 2 : `Connexion impossible`

## Indice
Le type de retour `?PDO` veut dire « un objet PDO, ou `null` ». Compare avec `=== null` pour savoir si la connexion a échoué.

## Solution: index.php
```php
<?php

function connecter(string $dsn): ?PDO {
    try {
        $pdo = new PDO($dsn);
        $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
        return $pdo;
    } catch (PDOException $e) {
        return null;
    }
}

$pdo = connecter("sqlite::memory:");
if ($pdo !== null) {
    echo "Connecté\n";
}

$pdo = connecter("sqlite:/dossier/inexistant/base.db");
if ($pdo === null) {
    echo "Connexion impossible\n";
}
```
