## Cours
PHP permet de mémoriser les informations d'un visiteur d'une page à l'autre grâce à deux mécanismes :
1. **Les sessions serveur** : activées avec `session_start()`, les données sont conservées côté serveur dans le tableau superglobal `$_SESSION`.
2. **Les cookies HTTP sécurisés** : déposés sur le navigateur avec `setcookie()`. Pour empêcher le vol de session (attaques XSS) et les requêtes intersites forgées (CSRF), on active impérativement :
   - `'httponly' => true` : rend le cookie invisible en JavaScript (`document.cookie`).
   - `'secure' => true` : garantit la transmission uniquement via le protocole chiffré HTTPS.
   - `'samesite' => 'Lax'` ou `'Strict'` : empêche l'envoi du cookie lors d'une navigation venant d'un site tiers.

Exemple :
```php
session_start();
$_SESSION['pseudo'] = 'Camille';

setcookie('preference', 'sombre', [
    'expires' => time() + 3600 * 24,
    'path' => '/',
    'secure' => true,
    'httponly' => true,
    'samesite' => 'Lax'
]);
```

## Énoncé
Dans `index.php` :
1. Démarre la session PHP avec `session_start()`.
2. Enregistre dans `$_SESSION['role']` la chaîne `'administrateur'`.
3. Définis un cookie sécurisé nommé `'theme'` avec la valeur `'sombre'` et les options :
   - `'secure' => true`
   - `'httponly' => true`
   - `'samesite' => 'Lax'`
4. Affiche avec `echo` la chaîne `"Session prête pour " . $_SESSION['role']`.

## Méthode
- [ ] Appelle `session_start()` au début
- [ ] Enregistre la valeur dans `$_SESSION['role']`
- [ ] Configure `setcookie` avec le tableau d'options sécurisées
- [ ] Affiche le message de confirmation avec `echo`

## Résultat
- [ ] La sortie affiche `Session prête pour administrateur`

## Indice
La fonction `session_start()` doit être appelée avant tout affichage ou utilisation de `$_SESSION`.

## Tests
```js
assert(sortie.includes("Session prête pour administrateur"), "Affiche « Session prête pour administrateur » avec echo");
```

## Solution: index.php
```php
<?php
session_start();
$_SESSION['role'] = 'administrateur';

setcookie('theme', 'sombre', [
    'expires' => time() + 3600 * 24 * 30,
    'path' => '/',
    'secure' => true,
    'httponly' => true,
    'samesite' => 'Lax'
]);

echo "Session prête pour " . $_SESSION['role'];
```
