## Cours
En PHP moderne (PHP 8+) avec le mode strict activé (`declare(strict_types=1);`), les fonctions peuvent expliciter le type de leurs paramètres et le type de leur valeur de retour :

```php
function multiplier(int $a, int $b): int {
    return $a * $b;
}
```

Les types scalaires les plus courants sont :
- `int` : entiers
- `float` : nombres décimaux
- `string` : chaînes de caractères
- `bool` : booléens (`true` / `false`)
- `array` : tableaux

Le typage strict empêche les conversions implicites imprévues et sécurise l'architecture du code dès le départ.

## Énoncé
Dans `index.php` :
1. Active le typage strict avec `declare(strict_types=1);`.
2. Déclare une fonction `calculerTotal` recevant un entier `$prix` (`int`) et un entier `$quantite` (`int`), qui retourne leur multiplication sous forme d'entier (`: int`).
3. Appelle la fonction avec les valeurs `12` et `3`, puis affiche le résultat précédé de `Total : ` (pour obtenir `Total : 36`).

## Méthode
- [ ] Active le typage strict sur la première ligne
- [ ] Déclare la signature : `function calculerTotal(int $prix, int $quantite): int`
- [ ] Reste fidèle au calcul : `return $prix * $quantite;`
- [ ] Affiche le résultat avec concaténation : `echo "Total : " . calculerTotal(12, 3);`

## Résultat
- [ ] La sortie affichée est exactement `Total : 36`

## Indice
La concaténation de chaînes s'effectue avec le point `.` : `echo "Total : " . calculerTotal(12, 3);`.

## Tests
```js
assert(/declare\s*\(\s*strict_types\s*=\s*1\s*\)/.test(code), "Active le typage strict avec declare(strict_types=1);");
assert(/function\s+calculerTotal\s*\(/.test(code), "Déclare la fonction calculerTotal");
assert(/int\s+\$prix/.test(code) && /int\s+\$quantite/.test(code), "Type les paramètres en int");
assert(/:\s*int\b/.test(code), "Type le retour de la fonction en int (: int)");
assert(/calculerTotal\s*\(\s*12\s*,\s*3\s*\)/.test(code), "Appelle calculerTotal(12, 3)");
assert(sortie.trim() === "Total : 36", "La sortie console doit être exactement « Total : 36 »");
```

## Solution: index.php
```php
<?php

declare(strict_types=1);

function calculerTotal(int $prix, int $quantite): int {
    return $prix * $quantite;
}

echo "Total : " . calculerTotal(12, 3);
```
