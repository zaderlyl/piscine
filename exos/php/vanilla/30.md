## Cours
Par sécurité, un navigateur **interdit** à une page d'appeler une API située sur un **autre site** (une autre origine). Exemple : ta page sur `http://localhost:5500` ne peut pas appeler `http://localhost:8000/api.php` sans autorisation. Cette règle s'appelle le **CORS**.

C'est l'**API** qui donne l'autorisation, avec des en-têtes de réponse :

```php
header("Access-Control-Allow-Origin: *");                    // qui peut appeler (* = tout le monde)
header("Access-Control-Allow-Methods: GET, POST, OPTIONS");  // quelles méthodes
header("Access-Control-Allow-Headers: Content-Type");        // quels en-têtes de requête
```

Pour une requête « sensible » (par exemple un `POST` en JSON), le navigateur envoie d'abord, tout seul, une **requête préliminaire** (*preflight*) avec la méthode **`OPTIONS`** : « as-tu le droit d'appeler cette API ? ». L'API doit répondre **sans corps** avec le code **`204`** (No Content) et les en-têtes CORS. Si c'est bon, le navigateur envoie alors la vraie requête.

```php
if ($_SERVER["REQUEST_METHOD"] === "OPTIONS") {
    http_response_code(204);
    exit;                      // on s'arrête : pas de corps pour un preflight
}
```

Les en-têtes CORS doivent aussi être présents sur la **vraie** réponse.

## Énoncé
Dans `index.php`, recopie ce début : il contient deux petites fonctions pour simuler plusieurs requêtes et résumer la réponse.

```php
ob_start();

function reinitialiser(): void {
    header_remove();
    http_response_code(200);
}

function resume(): string {
    $cors = array_filter(headers_list(), fn($h) => str_starts_with($h, "Access-Control-"));
    return http_response_code() . " | " . count($cors) . " en-têtes CORS";
}
```

1. Écris `cors(): void` qui envoie les trois en-têtes CORS ci-dessus.
2. Écris `traiter(string $methode): void` qui :
   - appelle `cors()`,
   - si la méthode est `OPTIONS`, fixe le code `204` et s'arrête **sans rien afficher** (`return`),
   - sinon affiche le JSON `{"message":"Bonjour"}` (avec `json_encode`).
3. Termine avec ces lignes, à recopier :

```php
reinitialiser();
traiter("OPTIONS");
echo resume() . "\n";

reinitialiser();
traiter("GET");
echo "\n" . resume() . "\n";
```

## Méthode
- [ ] `cors()` est appelée **dans tous les cas**, y compris pour `OPTIONS`
- [ ] Pour `OPTIONS` : code `204` puis `return`, aucun `echo`
- [ ] Pour les autres méthodes : un `echo json_encode([...])`

## Résultat
- [ ] Ligne 1 : `204 | 3 en-têtes CORS`
- [ ] Ligne 2 : `{"message":"Bonjour"}`
- [ ] Ligne 3 : `200 | 3 en-têtes CORS`

## Indice
`json_encode(["message" => "Bonjour"])` produit `{"message":"Bonjour"}`. Les trois en-têtes `Access-Control-` s'envoient avec trois appels à `header(...)`.

## Solution: index.php
```php
<?php

ob_start();

function reinitialiser(): void {
    header_remove();
    http_response_code(200);
}

function resume(): string {
    $cors = array_filter(headers_list(), fn($h) => str_starts_with($h, "Access-Control-"));
    return http_response_code() . " | " . count($cors) . " en-têtes CORS";
}

function cors(): void {
    header("Access-Control-Allow-Origin: *");
    header("Access-Control-Allow-Methods: GET, POST, OPTIONS");
    header("Access-Control-Allow-Headers: Content-Type");
}

function traiter(string $methode): void {
    cors();
    if ($methode === "OPTIONS") {
        http_response_code(204);
        return;
    }
    echo json_encode(["message" => "Bonjour"]);
}

reinitialiser();
traiter("OPTIONS");
echo resume() . "\n";

reinitialiser();
traiter("GET");
echo "\n" . resume() . "\n";
```
