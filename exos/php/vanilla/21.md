## Cours
Modifier (`UPDATE`) et supprimer (`DELETE`) se font comme l'insertion : avec une **requête préparée**.

```php
$requete = $pdo->prepare("UPDATE produits SET prix = :prix WHERE id = :id");
$requete->bindParam(":prix", $prix);
$requete->bindParam(":id", $id);
$requete->execute();

$requete = $pdo->prepare("DELETE FROM produits WHERE id = :id");
$requete->bindParam(":id", $id);
$requete->execute();
```

Attention au `WHERE` : **sans lui, la requête s'applique à toutes les lignes** de la table !

Comment savoir si la ligne existait vraiment ? `$requete->rowCount()` donne le **nombre de lignes touchées** : `1` si la ligne a été modifiée ou supprimée, `0` si l'identifiant n'existait pas.

## Énoncé
Dans `index.php`, recopie ce début : il prépare la base avec trois produits.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO produits (nom, prix) VALUES ('Clavier', 45), ('Souris', 20), ('Écran', 150)");
```

1. Écris `changerPrix(PDO $pdo, int $id, int $prix): bool` qui modifie le prix du produit et renvoie `true` si une ligne a été modifiée (`rowCount() > 0`).
2. Écris `supprimer(PDO $pdo, int $id): bool` qui supprime le produit et renvoie `true` si une ligne a été supprimée.
3. Termine avec ces lignes, à recopier :

```php
echo changerPrix($pdo, 1, 50) ? "modifié" : "inconnu";
echo "\n";
echo $pdo->query("SELECT prix FROM produits WHERE id = 1")->fetchColumn() . " €\n";
echo changerPrix($pdo, 99, 10) ? "modifié" : "inconnu";
echo "\n";
echo supprimer($pdo, 2) ? "supprimé" : "inconnu";
echo "\n";
echo $pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn() . " produits\n";
```

## Méthode
- [ ] Les deux fonctions utilisent `prepare` + `bindParam` + `execute`
- [ ] N'oublie pas le `WHERE id = :id`
- [ ] Renvoie `$requete->rowCount() > 0`

## Résultat
- [ ] Ligne 1 : `modifié`
- [ ] Ligne 2 : `50 €`
- [ ] Ligne 3 : `inconnu`
- [ ] Ligne 4 : `supprimé`
- [ ] Ligne 5 : `2 produits`

## Indice
Dans `UPDATE produits SET prix = :prix WHERE id = :id`, il y a bien **deux** paramètres à lier.

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO produits (nom, prix) VALUES ('Clavier', 45), ('Souris', 20), ('Écran', 150)");

function changerPrix(PDO $pdo, int $id, int $prix): bool {
    $requete = $pdo->prepare("UPDATE produits SET prix = :prix WHERE id = :id");
    $requete->bindParam(":prix", $prix);
    $requete->bindParam(":id", $id);
    $requete->execute();
    return $requete->rowCount() > 0;
}

function supprimer(PDO $pdo, int $id): bool {
    $requete = $pdo->prepare("DELETE FROM produits WHERE id = :id");
    $requete->bindParam(":id", $id);
    $requete->execute();
    return $requete->rowCount() > 0;
}

echo changerPrix($pdo, 1, 50) ? "modifié" : "inconnu";
echo "\n";
echo $pdo->query("SELECT prix FROM produits WHERE id = 1")->fetchColumn() . " €\n";
echo changerPrix($pdo, 99, 10) ? "modifié" : "inconnu";
echo "\n";
echo supprimer($pdo, 2) ? "supprimé" : "inconnu";
echo "\n";
echo $pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn() . " produits\n";
```
