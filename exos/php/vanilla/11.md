## Cours
Un attribut peut contenir un **autre objet**. Mais attention : PHP ne copie pas l'objet, il garde une **référence**, c'est-à-dire un lien vers le même objet.

```php
$moteur = new Moteur(120);
$voiture = new Voiture($moteur);   // la voiture garde un lien vers $moteur

$voiture->moteur->puissance = 150; // modifie le moteur...
echo $moteur->puissance;           // ...donc 150 ici aussi !
```

- `new` crée un objet. Ici, il n'y a eu qu'**un seul** `new Moteur` : donc un seul moteur, atteignable par deux chemins.
- On enchaîne les flèches pour descendre : `$voiture->moteur->puissance` se lit de gauche à droite.
- Pour savoir si deux variables désignent le **même** objet, on utilise `===`.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec un constructeur qui reçoit `$nom` et `$energie` (attributs publics).
2. Écris une classe `Pilote` avec un attribut public `$nom` et un attribut public `$robot`. Son constructeur reçoit le nom **et** le robot.
3. Crée un robot `R2D2` d'énergie `80` dans `$r1`, puis un pilote `Leia` qui pilote `$r1`.
4. Modifie l'énergie **en passant par le pilote** : `$leia->robot->energie = 35;`
5. Affiche, un par ligne :
   - l'énergie de `$r1`,
   - le nom du robot de Leia,
   - `oui` si `$leia->robot` et `$r1` sont le même objet (sinon `non`).

## Méthode
- [ ] Le pilote reçoit le robot dans son constructeur, il ne le crée pas
- [ ] Un seul `new Robot(...)` dans tout le programme
- [ ] Compare les deux objets avec `===`

## Résultat
- [ ] Ligne 1 : `35`
- [ ] Ligne 2 : `R2D2`
- [ ] Ligne 3 : `oui`

## Indice
Modifier `$leia->robot->energie`, c'est modifier `$r1` : les deux chemins mènent au même objet, donc `$r1->energie` affiche bien `35`.

## Tests
```js
const lignes = sortie.trim().split("\n").map((l) => l.trim());
assert(lignes[0] === "35", "Ligne 1 : l'énergie de $r1 doit valoir 35");
assert(lignes[1] === "R2D2", "Ligne 2 : le robot de Leia s'appelle R2D2");
assert(lignes[2] === "oui", "Ligne 3 : $leia->robot et $r1 sont le même objet");
assert((code.match(/new\s+Robot\s*\(/g) || []).length === 1, "Un seul « new Robot(...) » dans le programme");
```

## Solution: index.php
```php
<?php

class Robot {
    public string $nom;
    public int $energie;

    public function __construct(string $nom, int $energie) {
        $this->nom = $nom;
        $this->energie = $energie;
    }
}

class Pilote {
    public string $nom;
    public Robot $robot;

    public function __construct(string $nom, Robot $robot) {
        $this->nom = $nom;
        $this->robot = $robot;
    }
}

$r1 = new Robot("R2D2", 80);
$leia = new Pilote("Leia", $r1);

$leia->robot->energie = 35;

echo $r1->energie . "\n";
echo $leia->robot->nom . "\n";
echo ($leia->robot === $r1 ? "oui" : "non") . "\n";
```
