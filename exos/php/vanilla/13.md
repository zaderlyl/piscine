## Cours
Avec un attribut `private`, on ne peut plus le modifier de l'extérieur. Pour le permettre **en gardant le contrôle**, on écrit un **setter** (mutateur) : une méthode qui vérifie la valeur avant de l'accepter.

```php
class Compte {
    private int $solde = 0;

    public function setSolde(int $nouveau): bool {
        if ($nouveau < 0) {
            return false;          // refusé : le solde ne change pas
        }
        $this->solde = $nouveau;
        return true;               // accepté
    }
}
```

- Un setter **renvoie `true`** quand la valeur est acceptée et **`false`** quand elle est refusée.
- Quand la valeur est refusée, l'attribut **garde son ancienne valeur**.
- C'est la grande différence avec un attribut `public` : le setter peut dire non.
- Le constructeur a intérêt à passer par le setter, pour que les règles soient respectées dès la création.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec un attribut privé `$energie` (`int`, valeur de départ `100`).
2. Ajoute un getter `getEnergie()`.
3. Ajoute un setter `setEnergie(int $valeur): bool` qui **refuse** toute valeur inférieure à `0` ou supérieure à `100` (il renvoie `false` sans rien changer), et sinon enregistre la valeur et renvoie `true`.
4. Crée un robot, puis dans cet ordre :
   - essaie `setEnergie(150)` et affiche `accepté` ou `refusé` selon le résultat,
   - affiche l'énergie du robot,
   - essaie `setEnergie(60)` et affiche `accepté` ou `refusé`,
   - affiche l'énergie du robot.
   Un résultat par ligne.

## Méthode
- [ ] Le test de validité se fait avec un `if` avant d'affecter
- [ ] Utilise `return false;` pour refuser et `return true;` pour accepter
- [ ] Affiche le texte avec un `if ... else` (ou un ternaire) sur le résultat du setter

## Résultat
- [ ] Les quatre lignes sont `refusé`, `100`, `accepté`, `60`

## Indice
L'énergie du robot vaut `100` au départ : comme `150` est refusé, elle vaut toujours `100` à l'affichage suivant.

## Solution: index.php
```php
<?php

class Robot {
    private int $energie = 100;

    public function getEnergie(): int {
        return $this->energie;
    }

    public function setEnergie(int $valeur): bool {
        if ($valeur < 0 || $valeur > 100) {
            return false;
        }
        $this->energie = $valeur;
        return true;
    }
}

$robot = new Robot();

echo ($robot->setEnergie(150) ? "accepté" : "refusé") . "\n";
echo $robot->getEnergie() . "\n";
echo ($robot->setEnergie(60) ? "accepté" : "refusé") . "\n";
echo $robot->getEnergie() . "\n";
```
