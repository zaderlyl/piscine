## Cours
Certaines opérations demandent **plusieurs requêtes qui vont ensemble**. Exemple : un virement bancaire retire de l'argent d'un compte **puis** l'ajoute à un autre. Si la première requête réussit et que la seconde échoue, l'argent disparaît !

Une **transaction** garantit le « tout ou rien » : soit **toutes** les requêtes sont validées, soit **aucune**.

```php
try {
    $pdo->beginTransaction();   // début : rien n'est encore définitif
    // ... plusieurs requêtes ...
    $pdo->commit();             // tout s'est bien passé : on valide
} catch (Exception $e) {
    $pdo->rollBack();           // un problème : on annule TOUT depuis beginTransaction
}
```

- `beginTransaction()` ouvre la transaction.
- `commit()` valide définitivement les changements.
- `rollBack()` **annule** tous les changements faits depuis `beginTransaction()`.

Pour déclencher l'annulation, on lève nous-mêmes une exception quand une règle n'est pas respectée : `throw new Exception("Solde insuffisant");`.

## Énoncé
Dans `index.php`, recopie ce début : deux comptes et une fonction qui affiche les soldes.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE comptes (id INTEGER PRIMARY KEY AUTOINCREMENT, nom TEXT NOT NULL, solde INTEGER NOT NULL)");
$pdo->exec("INSERT INTO comptes (nom, solde) VALUES ('Lea', 100), ('Hugo', 50)");

function soldes(PDO $pdo): string {
    $lignes = $pdo->query("SELECT nom, solde FROM comptes ORDER BY id")->fetchAll(PDO::FETCH_ASSOC);
    return implode(", ", array_map(fn($l) => $l["nom"] . " : " . $l["solde"], $lignes));
}
```

1. Écris `virement(PDO $pdo, int $de, int $vers, int $montant): bool` qui, dans une transaction :
   - retire `$montant` du solde du compte `$de` (`UPDATE`),
   - **vérifie ensuite** le solde de ce compte : s'il est négatif, lève une exception,
   - ajoute `$montant` au solde du compte `$vers`,
   - valide avec `commit()` et renvoie `true`.
   En cas d'exception : `rollBack()` et renvoie `false`.
2. Termine avec ces lignes, à recopier :

```php
echo "Virement : " . (virement($pdo, 1, 2, 30) ? "oui" : "non") . "\n";
echo soldes($pdo) . "\n";
echo "Virement : " . (virement($pdo, 1, 2, 500) ? "oui" : "non") . "\n";
echo soldes($pdo) . "\n";
```

## Méthode
- [ ] `beginTransaction()` au début, `commit()` à la fin du `try`
- [ ] `catch (Exception $e)` appelle `rollBack()` et renvoie `false`
- [ ] Le retrait est fait **avant** la vérification : c'est le `rollBack()` qui remet le solde

## Résultat
- [ ] Ligne 1 : `Virement : oui`
- [ ] Ligne 2 : `Lea : 70, Hugo : 80`
- [ ] Ligne 3 : `Virement : non`
- [ ] Ligne 4 : `Lea : 70, Hugo : 80` (rien n'a bougé après l'échec)

## Indice
Pour lire le solde après le retrait : `SELECT solde FROM comptes WHERE id = :id` puis `fetchColumn()`. Pense à la requête préparée pour chaque `UPDATE`.

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE comptes (id INTEGER PRIMARY KEY AUTOINCREMENT, nom TEXT NOT NULL, solde INTEGER NOT NULL)");
$pdo->exec("INSERT INTO comptes (nom, solde) VALUES ('Lea', 100), ('Hugo', 50)");

function soldes(PDO $pdo): string {
    $lignes = $pdo->query("SELECT nom, solde FROM comptes ORDER BY id")->fetchAll(PDO::FETCH_ASSOC);
    return implode(", ", array_map(fn($l) => $l["nom"] . " : " . $l["solde"], $lignes));
}

function virement(PDO $pdo, int $de, int $vers, int $montant): bool {
    try {
        $pdo->beginTransaction();

        $retrait = $pdo->prepare("UPDATE comptes SET solde = solde - :montant WHERE id = :id");
        $retrait->bindParam(":montant", $montant);
        $retrait->bindParam(":id", $de);
        $retrait->execute();

        $lecture = $pdo->prepare("SELECT solde FROM comptes WHERE id = :id");
        $lecture->bindParam(":id", $de);
        $lecture->execute();
        if ($lecture->fetchColumn() < 0) {
            throw new Exception("Solde insuffisant");
        }

        $depot = $pdo->prepare("UPDATE comptes SET solde = solde + :montant WHERE id = :id");
        $depot->bindParam(":montant", $montant);
        $depot->bindParam(":id", $vers);
        $depot->execute();

        $pdo->commit();
        return true;
    } catch (Exception $e) {
        $pdo->rollBack();
        return false;
    }
}

echo "Virement : " . (virement($pdo, 1, 2, 30) ? "oui" : "non") . "\n";
echo soldes($pdo) . "\n";
echo "Virement : " . (virement($pdo, 1, 2, 500) ? "oui" : "non") . "\n";
echo soldes($pdo) . "\n";
```
