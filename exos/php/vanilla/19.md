## Cours
Pour ajouter une ligne, on **n'assemble jamais** la requête avec du texte venu de l'utilisateur :

```php
// DANGER : injection SQL possible
$pdo->exec("INSERT INTO produits (nom) VALUES ('$nom')");
```

Si `$nom` contient `L'écran` (avec une apostrophe) la requête casse, et un pirate peut y glisser du SQL. La bonne méthode est la **requête préparée** : on écrit la requête avec des **paramètres nommés** (`:nom`), puis on leur donne leurs valeurs.

```php
$requete = $pdo->prepare("INSERT INTO produits (nom, prix) VALUES (:nom, :prix)");
$requete->bindParam(":nom", $nom);
$requete->bindParam(":prix", $prix);
$requete->execute();
```

- `prepare` prépare la requête (rien n'est encore envoyé).
- `bindParam` associe un paramètre à une **variable**.
- `execute` lance la requête avec les valeurs.
- `$pdo->lastInsertId()` donne l'identifiant de la ligne qu'on vient d'ajouter (en texte).

## Énoncé
Dans `index.php`, recopie ce début : il prépare la connexion et la table.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
```

1. Écris `ajouter(PDO $pdo, string $nom, int $prix): int` qui insère le produit avec une **requête préparée** (`:nom` et `:prix`) et renvoie l'identifiant créé en entier (`(int) $pdo->lastInsertId()`).
2. Affiche (un par ligne) l'identifiant renvoyé pour : `Clavier` à 45, `Souris` à 20, puis `L'écran` à 150.
3. Termine avec cette ligne, à recopier :

```php
echo $pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn() . " produits\n";
```

## Méthode
- [ ] `prepare` avec `:nom` et `:prix`, jamais de variable collée dans la requête
- [ ] `bindParam` pour chaque paramètre, puis `execute()`
- [ ] La fonction renvoie `(int) $pdo->lastInsertId()`

## Résultat
- [ ] Lignes 1 à 3 : `1`, `2`, `3`
- [ ] Ligne 4 : `3 produits`

## Indice
`L'écran` contient une apostrophe : avec une requête préparée, elle passe sans problème. C'est justement ce qui montre que tu es protégé.

## Tests
```js
const lignes = sortie.trim().split("\n").map((l) => l.trim());
assert(lignes[0] === "1" && lignes[1] === "2" && lignes[2] === "3", "Les identifiants renvoyés sont 1, 2 puis 3");
assert(lignes[3] === "3 produits", "Ligne 4 : « 3 produits »");
assert(/->prepare\(/.test(code) && /bindParam\(/.test(code) && /execute\(/.test(code), "Utilise prepare, bindParam et execute");
assert(!/VALUES\s*\([^)]*\$/.test(code), "Aucune variable collée dans la requête : utilise des paramètres nommés");
```

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");

function ajouter(PDO $pdo, string $nom, int $prix): int {
    $requete = $pdo->prepare("INSERT INTO produits (nom, prix) VALUES (:nom, :prix)");
    $requete->bindParam(":nom", $nom);
    $requete->bindParam(":prix", $prix);
    $requete->execute();
    return (int) $pdo->lastInsertId();
}

echo ajouter($pdo, "Clavier", 45) . "\n";
echo ajouter($pdo, "Souris", 20) . "\n";
echo ajouter($pdo, "L'écran", 150) . "\n";

echo $pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn() . " produits\n";
```
