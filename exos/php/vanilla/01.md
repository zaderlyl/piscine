## Cours
En PHP, les structures de contrôle s'écrivent avec une syntaxe proche de JavaScript :

```php
if ($note >= 10) {
    echo "Admis";
} else {
    echo "Ajourné";
}
```

Les **tableaux associatifs** associent des clés personnalisées à des valeurs grâce à l'opérateur `=>` :

```php
$profil = [
    "pseudo" => "Alex",
    "score" => 42,
];

echo $profil["pseudo"]; // "Alex"
```

Pour parcourir un tableau, PHP fournit la boucle **`foreach`** :
```php
foreach ($profil as $cle => $valeur) {
    echo "$cle : $valeur\n";
}
```

## Énoncé
Dans `index.php` :
1. Ajoute `declare(strict_types=1);` dès la première ligne après `<?php` pour activer le typage strict.
2. Déclare un tableau associatif `$produit` contenant les clés `"nom" => "Livre"` et `"prix" => 15`.
3. À l'aide d'une condition `if / else`, si le prix du produit est strictement supérieur à `10`, affiche `Livre coûteux`. Sinon, affiche `Livre économique`.

## Méthode
- [ ] Active le typage strict : `declare(strict_types=1);`
- [ ] Déclare le tableau `$produit = [ "nom" => "Livre", "prix" => 15 ];`
- [ ] Vérifie la condition avec `if ($produit["prix"] > 10)`
- [ ] Affiche le résultat avec `echo`

## Résultat
- [ ] Le script affiche `Livre coûteux` dans la console

## Indice
La condition s'écrit `if ($produit["prix"] > 10) { echo "Livre coûteux"; } else { echo "Livre économique"; }`.

## Tests
```js
assert(sortie.includes("Livre coûteux"), "Le script doit afficher « Livre coûteux » pour un prix de 15");
assert(!sortie.includes("Livre économique"), "Le script ne doit pas afficher « Livre économique » pour ce test");
```

## Solution: index.php
```php
<?php

declare(strict_types=1);

$produit = [
    "nom" => "Livre",
    "prix" => 15,
];

if ($produit["prix"] > 10) {
    echo "Livre coûteux";
} else {
    echo "Livre économique";
}
```
