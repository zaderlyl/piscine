## Cours
`echo` affiche du texte dans la sortie du script.

## Énoncé
Dans `index.php`, affiche exactement le mot **Bonjour**.

## Méthode
- [ ] Utilise `echo`

## Résultat
- [ ] La sortie est `Bonjour`

## Indice
Le texte va entre guillemets.

## Tests
```js
assert(sortie.trim() === "Bonjour", "La sortie doit être exactement « Bonjour »");
```

## Solution: index.php
```php
<?php
echo "Bonjour";
```
