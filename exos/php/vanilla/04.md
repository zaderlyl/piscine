## Cours
En sécurité des applications web, un mot de passe ne doit **jamais** être stocké en texte clair :
- `password_hash($motDePasse, PASSWORD_DEFAULT)` : génère une empreinte robuste avec un sel cryptographique aléatoire.
- `password_verify($motDePasse, $hash)` : compare le mot de passe saisi et l'empreinte en temps constant afin d'éviter les attaques par analyse temporelle.
- `session_regenerate_id(true)` : regénère un nouvel identifiant de session dès que l'utilisateur s'authentifie, détruisant l'ancien pour contrer les attaques par **fixation de session**.

Exemple :
```php
if (password_verify($saisi, $hashEnBase)) {
    session_regenerate_id(true);
    $_SESSION['utilisateur_id'] = 42;
}
```

## Énoncé
Dans `index.php` :
1. Démarre la session avec `session_start()`.
2. Déclare `$motDePasse = "Secret123!";`.
3. Génère son empreinte avec `password_hash($motDePasse, PASSWORD_DEFAULT)`.
4. Vérifie l'empreinte avec `password_verify($motDePasse, $hash)`.
5. Si la vérification est positive :
   - Régénère l'identifiant de session avec `session_regenerate_id(true)`.
   - Définit `$_SESSION['auth'] = true;`.
   - Affiche `"Connexion réussie"`.

## Méthode
- [ ] Utilise `password_hash` avec l'algorithme par défaut
- [ ] Utilise `password_verify` pour tester la correspondance
- [ ] Régénère l'identifiant avec `session_regenerate_id(true)`

## Résultat
- [ ] La sortie affiche `Connexion réussie`

## Indice
La fonction `session_regenerate_id(true)` prend la valeur booléenne `true` pour effacer l'ancien fichier de session.

## Tests
```js
assert(sortie.includes("Connexion réussie"), "Affiche « Connexion réussie » avec echo quand password_verify réussit");
```

## Solution: index.php
```php
<?php
session_start();

$motDePasse = "Secret123!";
$hash = password_hash($motDePasse, PASSWORD_DEFAULT);

if (password_verify($motDePasse, $hash)) {
    session_regenerate_id(true);
    $_SESSION['auth'] = true;
    echo "Connexion réussie";
}
```
