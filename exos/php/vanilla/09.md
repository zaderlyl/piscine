## Cours
Jusqu'ici, tu rangeais des données dans des tableaux et tu écrivais des fonctions à côté. La **programmation orientée objet** réunit les deux : un **objet** contient ses propres données et ses propres actions.

Une **classe** est le **plan** de fabrication d'un objet. Elle décrit :
- les **attributs** : les données de l'objet (le nom, l'énergie…) ;
- les **méthodes** : ses actions, des fonctions rangées dans la classe.

**Étape 1 : déclarer une classe et fabriquer un objet.**

```php
class Compteur {
    public int $valeur = 0;     // un attribut
}

$c = new Compteur();            // new fabrique un objet à partir du plan
$c->valeur = 10;                // -> atteint un attribut de l'objet
echo $c->valeur;                // 10
```

- `class Compteur { ... }` déclare le plan. Par convention le nom commence par une majuscule.
- `new Compteur()` crée **un objet** (on dit une *instance*). On peut en créer autant qu'on veut : chacun a ses propres valeurs.
- La flèche `->` lit ou modifie un attribut. Il n'y a **pas de `$`** après la flèche : `$c->valeur`.

**Étape 2 : ajouter une méthode.** Dans une méthode, **`$this`** désigne l'objet sur lequel on travaille.

```php
class Compteur {
    public int $valeur = 0;

    public function ajouter(int $n): void {
        $this->valeur = $this->valeur + $n;
    }
}

$c = new Compteur();
$c->ajouter(5);                 // dans la méthode, $this est $c
echo $c->valeur;                // 5
```

Deux objets créés avec `new` sont distincts : modifier l'un ne change pas l'autre.

## Énoncé
Dans `index.php` :

**Partie 1, la classe et l'objet**
1. Écris une classe `Robot` avec deux attributs publics : `$nom` (`string`) et `$energie` (`int`).
2. Crée un robot avec `new Robot()`, donne-lui le nom `R2D2` et l'énergie `80`.
3. Affiche son nom, ` : `, son énergie, puis un saut de ligne (`"\n"`). Tu dois voir `R2D2 : 80`.

**Partie 2, les méthodes**
4. Ajoute à la classe une méthode `recharger(int $quantite)` qui **ajoute** `$quantite` à l'énergie du robot.
5. Ajoute une méthode `sePresenter()` qui affiche `Je suis ` suivi du nom, puis l'énergie entre parenthèses (par exemple `Je suis R2D2 (80)`).
6. Recharge ton robot de `15`, puis demande-lui de se présenter.

## Méthode
- [ ] Déclare les attributs avec `public string $nom;` et `public int $energie;`
- [ ] Crée l'objet avec `new Robot()`, puis affecte ses attributs avec `->`
- [ ] Dans les méthodes, utilise `$this->` pour atteindre les attributs

## Résultat
- [ ] Ligne 1 : `R2D2 : 80`
- [ ] Ligne 2 : `Je suis R2D2 (95)`

## Indice
Dans `recharger`, l'énergie devient « l'énergie actuelle + la quantité » : `$this->energie = $this->energie + $quantite;` (ou `+=`).

## Solution: index.php
```php
<?php

class Robot {
    public string $nom;
    public int $energie;

    public function recharger(int $quantite): void {
        $this->energie += $quantite;
    }

    public function sePresenter(): void {
        echo "Je suis " . $this->nom . " (" . $this->energie . ")";
    }
}

$robot = new Robot();
$robot->nom = "R2D2";
$robot->energie = 80;
echo $robot->nom . " : " . $robot->energie . "\n";

$robot->recharger(15);
$robot->sePresenter();
```
