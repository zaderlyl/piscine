## Cours
Une **classe** est un plan : elle décrit les **attributs** (les données) et les **méthodes** (les actions) d'un objet. Dans une méthode, **`$this`** désigne l'objet sur lequel on travaille, et `->` permet d'atteindre ses attributs.

```php
class Compteur {
    public int $valeur = 0;

    public function ajouter(int $n): void {
        $this->valeur = $this->valeur + $n;
    }
}

$c = new Compteur();
$c->ajouter(5);
echo $c->valeur; // 5
```

- `$c->ajouter(5)` appelle la méthode sur l'objet `$c` : dans la méthode, `$this` **est** `$c`.
- Il n'y a pas de `$` après la flèche : `$this->valeur`, pas `$this->$valeur`.
- Deux objets créés avec `new` sont distincts : modifier l'un ne change pas l'autre.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec deux attributs publics : `$nom` (`string`) et `$energie` (`int`).
2. Ajoute une méthode `recharger(int $quantite)` qui **ajoute** `$quantite` à l'énergie du robot.
3. Ajoute une méthode `sePresenter()` qui affiche `Je suis ` suivi du nom, puis l'énergie entre parenthèses (par exemple `Je suis R2D2 (80)`).
4. Crée un robot, donne-lui le nom `R2D2` et l'énergie `80`, recharge-le de `15`, puis demande-lui de se présenter.

## Méthode
- [ ] Déclare les attributs avec `public string $nom;` et `public int $energie;`
- [ ] Dans les méthodes, utilise `$this->` pour atteindre les attributs
- [ ] Crée l'objet avec `new Robot()`, puis affecte ses attributs avec `->`

## Résultat
- [ ] La sortie est exactement `Je suis R2D2 (95)`

## Indice
Dans `recharger`, l'énergie devient « l'énergie actuelle + la quantité » : `$this->energie = $this->energie + $quantite;` (ou `+=`).

## Solution: index.php
```php
<?php

class Robot {
    public string $nom;
    public int $energie;

    public function recharger(int $quantite): void {
        $this->energie += $quantite;
    }

    public function sePresenter(): void {
        echo "Je suis " . $this->nom . " (" . $this->energie . ")";
    }
}

$robot = new Robot();
$robot->nom = "R2D2";
$robot->energie = 80;
$robot->recharger(15);
$robot->sePresenter();
```
