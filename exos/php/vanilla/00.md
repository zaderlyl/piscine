## Cours
**PHP** est un langage qui s'exécute sur le **serveur**, avant que la page n'arrive dans le navigateur. Il sert à calculer, à décider et à produire du contenu : c'est lui qui permet, par exemple, d'afficher la liste des articles d'un site ou de traiter un formulaire.

### Un fichier PHP
Un programme PHP s'écrit dans un fichier qui se termine par `.php`, par exemple `index.php`. Le code est placé entre `<?php` et `?>`. Chaque instruction se termine par un point-virgule.

### Afficher du texte
`echo` envoie du texte dans la sortie du script. Un texte s'écrit entre guillemets.

```php
<?php
echo "Bonjour";
```

Dans les exercices, la sortie de ton script s'affiche dans la console, à droite. Dans l'exercice suivant, tu vas écrire ton premier `echo`.
