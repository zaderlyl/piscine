## Cours
Dans un vrai projet, chaque classe est rangée dans **son propre fichier** (`Robot.php`, `Pilote.php`…). Pour s'en servir, il faudrait écrire un `require_once` par classe en haut de chaque page : c'est long et on en oublie.

L'**autoloading** règle le problème : on explique à PHP, **une seule fois**, comment trouver le fichier d'une classe. Dès qu'il rencontre `new Robot()` et ne connaît pas `Robot`, il appelle notre fonction pour la charger.

```php
spl_autoload_register(function (string $classe) {
    $fichier = "classes/" . $classe . ".php";
    if (file_exists($fichier)) {
        require $fichier;
    }
});

$r = new Robot();   // charge classes/Robot.php automatiquement
```

- `spl_autoload_register()` reçoit une fonction qui prend en paramètre le **nom de la classe**.
- Convention : le fichier porte le nom de la classe (`Robot` → `Robot.php`).
- On vérifie que le fichier existe (`file_exists`) avant de le charger avec `require`.

## Énoncé
Dans `index.php`, la création du dossier et du fichier de classe est déjà écrite : recopie ce début, puis complète la suite.

```php
$dossier = sys_get_temp_dir() . "/classes";
if (!is_dir($dossier)) {
    mkdir($dossier);
}
file_put_contents($dossier . "/Robot.php", '<?php class Robot { public function parler(): void { echo "Bip !"; } }');
```

1. Enregistre un autoloader avec `spl_autoload_register()` : il construit le chemin `$dossier/NomDeClasse.php` (pense à `use ($dossier)` pour utiliser la variable dans la fonction), vérifie que le fichier existe, puis le charge avec `require`.
2. **Sans écrire de `require` pour `Robot`**, crée un `Robot` avec `new` et appelle sa méthode `parler()`.

## Méthode
- [ ] Une fonction anonyme `function (string $classe) use ($dossier) { ... }` dans `spl_autoload_register`
- [ ] Le fichier se déduit du nom de la classe : `$dossier . "/" . $classe . ".php"`
- [ ] Aucun `require` écrit à la main pour `Robot`

## Résultat
- [ ] La sortie est exactement `Bip !`

## Indice
Le `require` est dans la fonction d'autoload, pas dans le reste du programme : PHP l'exécute tout seul au moment du `new Robot()`.

## Solution: index.php
```php
<?php

$dossier = sys_get_temp_dir() . "/classes";
if (!is_dir($dossier)) {
    mkdir($dossier);
}
file_put_contents($dossier . "/Robot.php", '<?php class Robot { public function parler(): void { echo "Bip !"; } }');

spl_autoload_register(function (string $classe) use ($dossier) {
    $fichier = $dossier . "/" . $classe . ".php";
    if (file_exists($fichier)) {
        require $fichier;
    }
});

$robot = new Robot();
$robot->parler();
```
