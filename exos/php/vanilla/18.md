## Cours
Avec PDO, une requête qui **ne renvoie pas de résultat** (créer une table, modifier, supprimer) s'envoie avec `exec()` :

```php
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
```

- `INTEGER PRIMARY KEY AUTOINCREMENT` : un identifiant unique qui s'incrémente tout seul (1, 2, 3…).
- `NOT NULL` : la colonne doit toujours avoir une valeur.
- `TEXT` et `INTEGER` sont les types SQLite pour du texte et des nombres entiers.

Si la table existe déjà, `CREATE TABLE` lève une erreur. On ajoute `IF NOT EXISTS` pour que la commande soit **sans danger** même si on la lance plusieurs fois :

```sql
CREATE TABLE IF NOT EXISTS produits ( ... )
```

## Énoncé
Dans `index.php`, recopie ce début : il crée la connexion.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
```

1. Écris `creerTable(PDO $pdo): void` qui crée la table `produits` avec trois colonnes : `id` (clé primaire auto-incrémentée), `nom` (texte, obligatoire) et `prix` (entier, obligatoire). Utilise `IF NOT EXISTS`.
2. Appelle `creerTable($pdo)` **deux fois** de suite.
3. Termine avec ces lignes, à recopier :

```php
$colonnes = $pdo->query("PRAGMA table_info(produits)")->fetchAll(PDO::FETCH_COLUMN, 1);
echo implode(", ", $colonnes) . "\n";
```

## Méthode
- [ ] La requête est envoyée avec `$pdo->exec(...)`
- [ ] `IF NOT EXISTS` évite l'erreur au deuxième appel
- [ ] `id` est `INTEGER PRIMARY KEY AUTOINCREMENT`

## Résultat
- [ ] Une seule ligne : `id, nom, prix`

## Indice
Tu peux écrire la requête sur plusieurs lignes dans une chaîne PHP entre guillemets : les retours à la ligne ne gênent pas SQL.

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

function creerTable(PDO $pdo): void {
    $pdo->exec("CREATE TABLE IF NOT EXISTS produits (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT NOT NULL,
        prix INTEGER NOT NULL
    )");
}

creerTable($pdo);
creerTable($pdo);

$colonnes = $pdo->query("PRAGMA table_info(produits)")->fetchAll(PDO::FETCH_COLUMN, 1);
echo implode(", ", $colonnes) . "\n";
```
