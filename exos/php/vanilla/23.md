## Cours
Une base de données range les informations dans plusieurs tables reliées entre elles. Ici, chaque produit appartient à une **catégorie** : la table `produits` contient une **clé étrangère** `categorie_id` qui pointe vers l'`id` de la table `categories`.

Pour afficher « le produit **et** le nom de sa catégorie », on **joint** les deux tables :

```sql
SELECT produits.nom AS produit, categories.nom AS categorie
FROM produits
JOIN categories ON categories.id = produits.categorie_id
```

- `JOIN ... ON` relie chaque produit à sa catégorie.
- `AS` donne un nom à la colonne dans le résultat (utile quand deux colonnes s'appellent `nom`).

**Piège classique (le « N+1 »)** : lire les produits, puis pour **chaque** produit refaire une requête pour sa catégorie. Avec 100 produits, ça fait 101 requêtes ! Une jointure fait le même travail avec **une seule** requête.

## Énoncé
Dans `index.php`, recopie ce début : il prépare deux tables et trois produits.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE categories (id INTEGER PRIMARY KEY AUTOINCREMENT, nom TEXT NOT NULL)");
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    categorie_id INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO categories (nom) VALUES ('Périphériques'), ('Écrans')");
$pdo->exec("INSERT INTO produits (nom, categorie_id) VALUES ('Clavier', 1), ('Souris', 1), ('Moniteur', 2)");
```

1. Écris `listeProduits(PDO $pdo): array` qui renvoie, **avec une seule requête et une jointure**, les produits avec le nom de leur catégorie (colonnes `produit` et `categorie`), triés par `produits.id`.
2. Affiche chaque ligne sous la forme `Clavier (Périphériques)`, une par ligne.

## Méthode
- [ ] Une seule requête, avec `JOIN ... ON categories.id = produits.categorie_id`
- [ ] Les colonnes sont renommées avec `AS produit` et `AS categorie`
- [ ] Pas de requête dans une boucle

## Résultat
- [ ] Ligne 1 : `Clavier (Périphériques)`
- [ ] Ligne 2 : `Souris (Périphériques)`
- [ ] Ligne 3 : `Moniteur (Écrans)`

## Indice
Les `exec` du début ne comptent pas : ton code ne doit contenir qu'**un seul** appel à `query` (ou à `prepare`).

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE categories (id INTEGER PRIMARY KEY AUTOINCREMENT, nom TEXT NOT NULL)");
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    categorie_id INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO categories (nom) VALUES ('Périphériques'), ('Écrans')");
$pdo->exec("INSERT INTO produits (nom, categorie_id) VALUES ('Clavier', 1), ('Souris', 1), ('Moniteur', 2)");

function listeProduits(PDO $pdo): array {
    return $pdo->query(
        "SELECT produits.nom AS produit, categories.nom AS categorie
         FROM produits
         JOIN categories ON categories.id = produits.categorie_id
         ORDER BY produits.id"
    )->fetchAll(PDO::FETCH_ASSOC);
}

foreach (listeProduits($pdo) as $ligne) {
    echo $ligne["produit"] . " (" . $ligne["categorie"] . ")\n";
}
```
