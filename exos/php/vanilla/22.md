## Cours
Quand une table contient des centaines de lignes, on ne les affiche pas toutes d'un coup : on les découpe en **pages**. SQL propose deux mots pour ça :

```sql
SELECT * FROM produits ORDER BY id LIMIT 3 OFFSET 6
```

- `LIMIT 3` : renvoie au maximum 3 lignes.
- `OFFSET 6` : saute les 6 premières lignes.
- `ORDER BY id` : indispensable, sans tri l'ordre des lignes n'est pas garanti.

Pour la page numéro `$numero` (la première page est la numéro 1) avec `$parPage` lignes par page, le décalage vaut :

```php
$decalage = ($numero - 1) * $parPage;
```

Les valeurs de `LIMIT` et `OFFSET` sont des **nombres** : on les lie avec le type `PDO::PARAM_INT`.

```php
$requete->bindParam(":limite", $parPage, PDO::PARAM_INT);
```

Pour savoir combien il y a de pages au total : `ceil($total / $parPage)` (arrondi au-dessus).

## Énoncé
Dans `index.php`, recopie ce début : il prépare la base avec sept produits.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL
)");
for ($i = 1; $i <= 7; $i++) {
    $pdo->exec("INSERT INTO produits (nom) VALUES ('Produit $i')");
}
```

1. Écris `page(PDO $pdo, int $numero, int $parPage): array` qui renvoie la liste des **noms** de la page demandée (triés par `id`, requête préparée avec `:limite` et `:decalage`).
2. Écris `nombrePages(PDO $pdo, int $parPage): int` qui renvoie le nombre de pages nécessaires.
3. Avec 3 produits par page, affiche : les noms de la page 1 séparés par `, `, puis ceux de la page 3, puis `3 pages`.

## Méthode
- [ ] `ORDER BY id LIMIT :limite OFFSET :decalage`
- [ ] Décalage = `($numero - 1) * $parPage`
- [ ] `fetchAll(PDO::FETCH_COLUMN)` renvoie directement la liste des noms
- [ ] `nombrePages` : `COUNT(*)` puis `ceil`

## Résultat
- [ ] Ligne 1 : `Produit 1, Produit 2, Produit 3`
- [ ] Ligne 2 : `Produit 7`
- [ ] Ligne 3 : `3 pages`

## Indice
`implode(", ", $tableau)` assemble les noms. La dernière page peut contenir moins de lignes que les autres : c'est normal.

const lignes = sortie.trim().split("\n").map((l) => l.trim());

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL
)");
for ($i = 1; $i <= 7; $i++) {
    $pdo->exec("INSERT INTO produits (nom) VALUES ('Produit $i')");
}

function page(PDO $pdo, int $numero, int $parPage): array {
    $decalage = ($numero - 1) * $parPage;
    $requete = $pdo->prepare("SELECT nom FROM produits ORDER BY id LIMIT :limite OFFSET :decalage");
    $requete->bindParam(":limite", $parPage, PDO::PARAM_INT);
    $requete->bindParam(":decalage", $decalage, PDO::PARAM_INT);
    $requete->execute();
    return $requete->fetchAll(PDO::FETCH_COLUMN);
}

function nombrePages(PDO $pdo, int $parPage): int {
    $total = (int) $pdo->query("SELECT COUNT(*) FROM produits")->fetchColumn();
    return (int) ceil($total / $parPage);
}

echo implode(", ", page($pdo, 1, 3)) . "\n";
echo implode(", ", page($pdo, 3, 3)) . "\n";
echo nombrePages($pdo, 3) . " pages\n";
```
