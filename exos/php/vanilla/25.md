## Cours
Quand un site grandit, mélanger dans une même page les données, le HTML et la logique devient vite ingérable. Le motif **MVC** range le code en trois rôles :

| Rôle | Ce qu'il fait |
|---|---|
| **M**odèle | Les **données** et les règles pour les lire ou les modifier |
| **V**ue | L'**affichage** (le HTML), sans aucune logique de données |
| **C**ontrôleur | Le **chef d'orchestre** : il reçoit la demande, interroge le modèle, choisit la vue |

Dans cet exo, on commence par le **modèle**. C'est une classe qui connaît les données et propose des méthodes pour les obtenir. Le reste du programme n'a pas besoin de savoir **où** sont rangées les données (un tableau, un fichier, une base…).

```php
class UtilisateurModele {
    private array $utilisateurs = [
        1 => ["nom" => "Lea"],
        2 => ["nom" => "Tom"],
    ];

    public function tous(): array {
        return $this->utilisateurs;
    }

    public function trouver(int $id): ?array {   // ?array : un tableau ou null
        return $this->utilisateurs[$id] ?? null;
    }
}
```

- `?array` veut dire « un tableau, ou `null` ». On renvoie `null` quand l'élément n'existe pas.
- L'opérateur `??` donne la valeur de droite si celle de gauche n'existe pas.
- Le modèle **ne fait aucun `echo`** : il renvoie des données, c'est à l'appelant de les afficher.

## Énoncé
Dans `index.php` :
1. Écris une classe `ProduitModele` avec un attribut privé `$produits` (un tableau) initialisé avec :
   - `1` : nom `Clavier`, prix `45`
   - `2` : nom `Souris`, prix `20`
   - `3` : nom `Écran`, prix `180`

   Chaque produit est un tableau associatif avec les clés `nom` et `prix`.
2. Ajoute `tous(): array` qui renvoie tous les produits.
3. Ajoute `trouver(int $id): ?array` qui renvoie un produit, ou `null` s'il n'existe pas.
4. Utilise ton modèle et affiche, un par ligne :
   - le nombre de produits suivi de ` produits`,
   - le produit `2` sous la forme `Souris : 20 €`,
   - `Produit 99 introuvable` si `trouver(99)` renvoie `null`.

## Méthode
- [ ] Le modèle ne contient aucun `echo`
- [ ] Les données sont dans l'attribut privé, on y accède par les méthodes
- [ ] Le `echo` se trouve en dehors de la classe

## Résultat
- [ ] Ligne 1 : `3 produits`
- [ ] Ligne 2 : `Souris : 20 €`
- [ ] Ligne 3 : `Produit 99 introuvable`

## Indice
`count($modele->tous())` donne le nombre de produits. Pour le cas introuvable, compare le retour de `trouver(99)` à `null` avec `===`.

## Tests
```js
const lignes = sortie.trim().split("\n").map((l) => l.trim());
assert(lignes[0] === "3 produits", "Ligne 1 : « 3 produits »");
assert(lignes[1] === "Souris : 20 €", "Ligne 2 : « Souris : 20 € »");
assert(lignes[2] === "Produit 99 introuvable", "Ligne 3 : « Produit 99 introuvable »");
const classe = code.match(/class\s+ProduitModele\b[\s\S]*?\n\}/);
assert(classe && !/\becho\b/.test(classe[0]), "Le modèle ne doit contenir aucun echo");
```

## Solution: index.php
```php
<?php

class ProduitModele {
    private array $produits = [
        1 => ["nom" => "Clavier", "prix" => 45],
        2 => ["nom" => "Souris", "prix" => 20],
        3 => ["nom" => "Écran", "prix" => 180],
    ];

    public function tous(): array {
        return $this->produits;
    }

    public function trouver(int $id): ?array {
        return $this->produits[$id] ?? null;
    }
}

$modele = new ProduitModele();

echo count($modele->tous()) . " produits\n";

$produit = $modele->trouver(2);
echo $produit["nom"] . " : " . $produit["prix"] . " €\n";

if ($modele->trouver(99) === null) {
    echo "Produit 99 introuvable\n";
}
```
