## Cours
La **vue** est le fichier qui contient le HTML. Elle ne va jamais chercher de données elle-même : on lui **transmet** ce dont elle a besoin. Pour cela, on écrit une petite fonction qui charge un fichier de vue en lui donnant des variables.

```php
function rendre(string $fichier, array $donnees): string {
    extract($donnees);      // ['nom' => 'Lea'] devient la variable $nom
    ob_start();             // on met la sortie de côté...
    require $fichier;       // ...le fichier de vue s'exécute...
    return ob_get_clean();  // ...et on récupère le texte produit
}
```

- `extract($donnees)` transforme chaque clé du tableau en variable : la vue peut utiliser `$nom` directement.
- `ob_start()` et `ob_get_clean()` capturent ce que la vue affiche, pour le **renvoyer** sous forme de texte au lieu de l'afficher tout de suite.
- Dans un fichier de vue, `<?= $x ?>` est un raccourci pour `<?php echo $x; ?>`.
- Une vue protège toujours ce qu'elle affiche avec `htmlspecialchars()` (sinon, faille XSS).

## Énoncé
Dans `index.php`, recopie ce début : il crée le fichier de vue `produit.php` (c'est le gabarit).

```php
$dossier = sys_get_temp_dir() . "/vues";
if (!is_dir($dossier)) {
    mkdir($dossier);
}
file_put_contents(
    $dossier . "/produit.php",
    '<h1><?= htmlspecialchars($nom) ?></h1>' . "\n" . '<p>Prix : <?= $prix ?> €</p>'
);
```

1. Écris la fonction `rendre(string $fichier, array $donnees): string` qui charge la vue avec `extract`, `ob_start`, `require` et `ob_get_clean`, puis renvoie le texte.
2. Affiche le rendu de `$dossier . "/produit.php"` avec les données `nom` : `<b>Clavier</b>` et `prix` : `45`.

La vue doit protéger le nom : le texte HTML du nom ne doit **pas** être interprété.

## Méthode
- [ ] `extract($donnees);` en premier dans la fonction
- [ ] Encadre le `require` par `ob_start()` et `ob_get_clean()`
- [ ] La fonction **renvoie** le texte (`return`), le `echo` est fait à l'appel

## Résultat
- [ ] Ligne 1 : `<h1>&lt;b&gt;Clavier&lt;/b&gt;</h1>`
- [ ] Ligne 2 : `<p>Prix : 45 €</p>`

## Indice
La vue fournie utilise déjà `htmlspecialchars`. Tu n'as rien à y changer : si `rendre` fonctionne, le `<b>` apparaît sous forme `&lt;b&gt;`.

## Solution: index.php
```php
<?php

$dossier = sys_get_temp_dir() . "/vues";
if (!is_dir($dossier)) {
    mkdir($dossier);
}
file_put_contents(
    $dossier . "/produit.php",
    '<h1><?= htmlspecialchars($nom) ?></h1>' . "\n" . '<p>Prix : <?= $prix ?> €</p>'
);

function rendre(string $fichier, array $donnees): string {
    extract($donnees);
    ob_start();
    require $fichier;
    return ob_get_clean();
}

echo rendre($dossier . "/produit.php", ["nom" => "<b>Clavier</b>", "prix" => 45]);
```
