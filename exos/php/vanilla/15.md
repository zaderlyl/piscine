## Cours
Un attribut `private` est invisible même pour les classes filles. Avec **`protected`**, il devient accessible dans la classe **et dans ses filles**, mais toujours pas depuis l'extérieur.

| Mot-clé | Accessible depuis… |
|---|---|
| `public` | partout |
| `protected` | la classe et ses classes filles |
| `private` | uniquement la classe qui le déclare |

Une classe fille peut aussi **redéfinir** une méthode de la mère : elle écrit une méthode de **même nom** avec un comportement adapté. La version de la mère n'a pas disparu : `parent::methode()` permet de la réutiliser.

```php
class Animal {
    protected int $vies = 9;

    public function decrire(): string {
        return "Animal avec " . $this->vies . " vies";
    }
}

class Chat extends Animal {
    public function decrire(): string {            // redéfinition
        return parent::decrire() . " (c'est un chat)";
    }

    public function perdreUneVie(): void {
        $this->vies--;                              // protected : accessible ici
    }
}
```

PHP choisit toujours la version de la **classe réelle** de l'objet, même si on le range dans un tableau avec des objets d'autres classes.

## Énoncé
Dans `index.php` :
1. Écris une classe `Robot` avec un attribut privé `$nom` et un attribut **protégé** `$energie`, un constructeur `($nom, $energie)` et une méthode `getDescription()` qui renvoie `nom : energie`.
2. Écris `RobotExplorateur` qui hérite de `Robot`, avec un attribut privé `$planete` et un constructeur `($nom, $energie, $planete)`.
3. Dans `RobotExplorateur`, ajoute `analyserTerrain()` qui retire `10` à `$this->energie` (accès direct, grâce à `protected`).
4. **Redéfinis** `getDescription()` dans `RobotExplorateur` : elle renvoie la description de la mère (avec `parent::`) suivie de ` | planète : ` et de la planète.
5. Crée un `Robot` `R2D2` (énergie `80`) et un `RobotExplorateur` `Opportunity` (énergie `70`, planète `Mars`). Fais analyser le terrain à l'explorateur, puis affiche la description de chacun, un par ligne.

## Méthode
- [ ] `protected int $energie;` dans la mère
- [ ] Dans la fille, `$this->energie -= 10;` fonctionne sans getter
- [ ] La redéfinition garde le même nom et appelle `parent::getDescription()`

## Résultat
- [ ] Ligne 1 : `R2D2 : 80`
- [ ] Ligne 2 : `Opportunity : 60 | planète : Mars`

## Indice
Le `nom` reste `private` : `getDescription()` de la mère peut l'utiliser, mais pas la fille. C'est pour cela que la fille passe par `parent::getDescription()`.

const lignes = sortie.trim().split("\n").map((l) => l.trim());

## Solution: index.php
```php
<?php

class Robot {
    private string $nom;
    protected int $energie;

    public function __construct(string $nom, int $energie) {
        $this->nom = $nom;
        $this->energie = $energie;
    }

    public function getDescription(): string {
        return $this->nom . " : " . $this->energie;
    }
}

class RobotExplorateur extends Robot {
    private string $planete;

    public function __construct(string $nom, int $energie, string $planete) {
        parent::__construct($nom, $energie);
        $this->planete = $planete;
    }

    public function analyserTerrain(): void {
        $this->energie -= 10;
    }

    public function getDescription(): string {
        return parent::getDescription() . " | planète : " . $this->planete;
    }
}

$robots = [
    new Robot("R2D2", 80),
    new RobotExplorateur("Opportunity", 70, "Mars"),
];

$robots[1]->analyserTerrain();

foreach ($robots as $robot) {
    echo $robot->getDescription() . "\n";
}
```
