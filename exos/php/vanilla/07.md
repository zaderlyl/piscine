## Cours
La réception de fichiers envoyés par un formulaire (`$_FILES`) présente de sérieux risques de sécurité (exécution de scripts malveillants, saturation du disque, etc.).

Une validation rigoureuse impose :
1. **Le contrôle d'erreur** : vérifier `$_FILES['fichier']['error'] === UPLOAD_ERR_OK`.
2. **La taille maximale** : rejeter les fichiers dépassant la limite autorisée (ex. 2 Mo).
3. **Le type MIME réel** : ne jamais faire confiance à l'extension du fichier ni à `$_FILES['fichier']['type']` (falsifiables par le client). On vérifie le type réel avec `mime_content_type($fichierTemp)`.
4. **Le renommage** : renommer systématiquement le fichier avec un nom aléatoire unique (`bin2hex(random_bytes(16)) . '.' . $extensionValidee`).

Exemple :
```php
$autorises = ['image/jpeg', 'image/png'];
if (in_array(mime_content_type($cheminFichier), $autorises, true)) {
    // Fichier autorisé
}
```

## Énoncé
Dans `index.php` :
1. Déclare une fonction `validerUploadFichier(int $taille, string $typeMime): bool` qui :
   - Vérifie que `$taille` ne dépasse pas `2000000` octets (2 Mo).
   - Vérifie que `$typeMime` est présent dans la liste blanche `['image/jpeg', 'image/png', 'image/webp']`.
   - Renvoie `true` si le fichier respecte ces deux critères, `false` sinon.
2. Appelle cette fonction avec une taille de `500000` et le type `'image/png'`.
3. Si la fonction renvoie `true`, affiche `"Upload sécurisé valide"`.

## Méthode
- [ ] Déclare la fonction avec les deux vérifications
- [ ] Utilise `in_array(..., ..., true)` pour contrôler le type MIME
- [ ] Affiche `"Upload sécurisé valide"`

## Résultat
- [ ] La sortie affiche `Upload sécurisé valide`

## Indice
Utilise `in_array($typeMime, $typesAutorises, true)` pour vérifier que le type figure dans la liste blanche.


## Solution: index.php
```php
<?php
function validerUploadFichier(int $taille, string $typeMime): bool {
    $tailleMax = 2000000;
    $typesAutorises = ['image/jpeg', 'image/png', 'image/webp'];

    if ($taille > $tailleMax) {
        return false;
    }

    if (!in_array($typeMime, $typesAutorises, true)) {
        return false;
    }

    return true;
}

if (validerUploadFichier(500000, 'image/png')) {
    echo "Upload sécurisé valide";
}
```
