## Cours
Une requête qui **renvoie des lignes** (`SELECT`) s'envoie avec `query()` (sans paramètre) ou `prepare()` (avec paramètres). On récupère ensuite les résultats :

```php
// toutes les lignes
$lignes = $pdo->query("SELECT * FROM produits")->fetchAll(PDO::FETCH_ASSOC);
// $lignes = [ ["id" => 1, "nom" => "Clavier", ...], ["id" => 2, ...] ]

// une seule ligne, avec un paramètre
$requete = $pdo->prepare("SELECT * FROM produits WHERE id = :id");
$requete->bindParam(":id", $id);
$requete->execute();
$ligne = $requete->fetch(PDO::FETCH_ASSOC);   // un tableau, ou false si rien trouvé
```

- `PDO::FETCH_ASSOC` donne des tableaux associatifs (les clés sont les noms de colonnes).
- `fetchAll` renvoie **toutes** les lignes, `fetch` renvoie **la suivante**.
- Quand il n'y a plus (ou pas) de ligne, `fetch` renvoie `false`.

## Énoncé
Dans `index.php`, recopie ce début : il prépare la base avec trois produits.

```php
$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO produits (nom, prix) VALUES ('Clavier', 45), ('Souris', 20), ('Écran', 150)");
```

1. Écris `tous(PDO $pdo): array` qui renvoie toutes les lignes en tableaux associatifs.
2. Écris `trouver(PDO $pdo, int $id): ?array` qui renvoie la ligne de cet identifiant (requête préparée), ou `null` si elle n'existe pas.
3. Affiche le nombre de produits suivi de ` produits`, puis pour le produit `2` : `nom : prix €`, puis pour le produit `99` : `Introuvable`.

## Méthode
- [ ] `fetchAll(PDO::FETCH_ASSOC)` dans `tous`
- [ ] `prepare` + `bindParam` + `fetch(PDO::FETCH_ASSOC)` dans `trouver`
- [ ] `fetch` renvoie `false` quand rien n'est trouvé : transforme-le en `null`

## Résultat
- [ ] Ligne 1 : `3 produits`
- [ ] Ligne 2 : `Souris : 20 €`
- [ ] Ligne 3 : `Introuvable`

## Indice
`count($tableau)` donne le nombre de lignes. Pour transformer `false` en `null` : `return $ligne === false ? null : $ligne;`.

## Solution: index.php
```php
<?php

$pdo = new PDO("sqlite::memory:");
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
$pdo->exec("CREATE TABLE produits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nom TEXT NOT NULL,
    prix INTEGER NOT NULL
)");
$pdo->exec("INSERT INTO produits (nom, prix) VALUES ('Clavier', 45), ('Souris', 20), ('Écran', 150)");

function tous(PDO $pdo): array {
    return $pdo->query("SELECT * FROM produits")->fetchAll(PDO::FETCH_ASSOC);
}

function trouver(PDO $pdo, int $id): ?array {
    $requete = $pdo->prepare("SELECT * FROM produits WHERE id = :id");
    $requete->bindParam(":id", $id);
    $requete->execute();
    $ligne = $requete->fetch(PDO::FETCH_ASSOC);
    return $ligne === false ? null : $ligne;
}

echo count(tous($pdo)) . " produits\n";

$produit = trouver($pdo, 2);
echo $produit["nom"] . " : " . $produit["prix"] . " €\n";

if (trouver($pdo, 99) === null) {
    echo "Introuvable\n";
}
```
