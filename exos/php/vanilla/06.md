## Cours
Une attaque **CSRF** (*Cross-Site Request Forgery*) consiste à tromper la victime pour lui faire exécuter à son insu une requête sensible sur un site où elle est déjà connectée.

Pour bloquer ces attaques, on intègre un jeton secret et imprévisible :
1. Générer un jeton cryptographique aléatoire : `$jeton = bin2hex(random_bytes(32));`.
2. Conserver ce jeton en session : `$_SESSION['csrf_token'] = $jeton;`.
3. L'insérer dans un champ masqué du formulaire : `<input type="hidden" name="csrf_token" value="...">`.
4. À la réception du formulaire, valider la concordance avec `hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])`.

Exemple :
```php
if (!hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'] ?? '')) {
    die("Requête invalide");
}
```

## Énoncé
Dans `index.php` :
1. Démarre la session avec `session_start()`.
2. Génère un jeton aléatoire de 32 octets avec `bin2hex(random_bytes(32))` et stocke-le dans `$_SESSION['csrf_token']`.
3. Simule un formulaire reçu avec `$_POST['csrf_token'] = $_SESSION['csrf_token'];`.
4. Compare les deux jetons avec `hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])`.
5. Si les jetons correspondent, affiche `"Jeton CSRF valide"`.

## Indice
La fonction `hash_equals($attendu, $recu)` effectue une comparaison en temps constant contre les attaques temporelles.

## Solution: index.php
```php
<?php
session_start();

$jeton = bin2hex(random_bytes(32));
$_SESSION['csrf_token'] = $jeton;

$_POST['csrf_token'] = $_SESSION['csrf_token'];

if (hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'])) {
    echo "Jeton CSRF valide";
}
```
