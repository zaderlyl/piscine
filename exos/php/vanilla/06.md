## Cours
Lors du traitement de données issues d'un formulaire `$_POST` :
1. **Protection XSS** : toute donnée affichée doit être neutralisée avec `htmlspecialchars($texte, ENT_QUOTES, 'UTF-8')` pour empêcher l'exécution de balises `<script>` arbitraires.
2. **Pattern PRG (Post-Redirect-Get)** : après avoir traité un formulaire POST, le serveur effectue une redirection (`header('Location: ...')`) pour éviter qu'un rafraîchissement de page ne réexécute l'action.
3. **Messages flash** : pour transmettre une notification à la page de destination après la redirection, on stocke un message dans `$_SESSION['flash']`, que l'on affiche puis supprime avec `unset()`.

Exemple :
```php
$propre = htmlspecialchars($_POST['commentaire'], ENT_QUOTES, 'UTF-8');
$_SESSION['flash'] = "Commentaire enregistré";
```

## Énoncé
Dans `index.php` :
1. Démarre la session avec `session_start()`.
2. Simule la réception d'un pseudo soumis : `$_POST['pseudo'] = "<script>alert('hack')</script>";`.
3. Assainis cette valeur dans une variable `$pseudoPropre` avec `htmlspecialchars($valeur, ENT_QUOTES, 'UTF-8')`.
4. Enregistre un message flash dans `$_SESSION['flash'] = "Bienvenue " . $pseudoPropre;`.
5. Affiche le message flash avec `echo`, puis supprime la variable avec `unset($_SESSION['flash'])`.

## Méthode
- [ ] Protège la chaîne avec `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`
- [ ] Stocke dans `$_SESSION['flash']`
- [ ] Affiche puis nettoie la variable avec `unset`

## Résultat
- [ ] La sortie affiche `Bienvenue &lt;script&gt;alert(&#039;hack&#039;)&lt;/script&gt;` sans interpréter le script HTML

## Indice
La fonction `htmlspecialchars` convertit les caractères spéciaux comme `<` et `>` en entités HTML sûres.

## Tests
```js
assert(sortie.includes("Bienvenue &lt;script&gt;"), "Échappe le pseudo avec htmlspecialchars avant de l'afficher");
assert(!sortie.includes("<script>"), "N'affiche jamais le pseudo brut : passe-le d'abord dans htmlspecialchars");
```

## Solution: index.php
```php
<?php
session_start();

$_POST['pseudo'] = "<script>alert('hack')</script>";
$pseudoPropre = htmlspecialchars($_POST['pseudo'], ENT_QUOTES, 'UTF-8');

$_SESSION['flash'] = "Bienvenue " . $pseudoPropre;
echo $_SESSION['flash'];
unset($_SESSION['flash']);
```
