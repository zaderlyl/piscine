## Cours
Une **API** répond avec des données, pas avec une page HTML. Le format le plus courant est le **JSON**, que le JavaScript sait lire directement avec `response.json()`.

Pour bien répondre, il faut trois choses :
1. Le **code HTTP** qui dit si ça s'est bien passé : `200` (OK), `404` (introuvable), `400` (requête invalide)…
2. L'en-tête **`Content-Type: application/json`**, pour que le client sache qu'il reçoit du JSON.
3. Le **corps** : le tableau PHP transformé en texte avec `json_encode`.

```php
function repondre(int $code, array $donnees): void {
    http_response_code($code);
    header("Content-Type: application/json");
    echo json_encode($donnees, JSON_UNESCAPED_UNICODE);
}
```

- `json_encode` transforme un tableau PHP en texte JSON. Un tableau associatif devient un objet `{...}`, un tableau simple devient une liste `[...]`.
- `JSON_UNESCAPED_UNICODE` garde les accents lisibles (`é` au lieu de `é`).
- Le code HTTP et les en-têtes se fixent **avant** d'afficher le corps.

## Énoncé
Dans `index.php`, recopie ce début : `ob_start()` retient l'affichage, car on va simuler deux requêtes à la suite.

```php
ob_start();

$produits = [
    1 => ["nom" => "Clavier", "prix" => 45],
    2 => ["nom" => "Souris", "prix" => 20],
];
```

1. Écris `repondre(int $code, array $donnees): void` : elle fixe le code HTTP, envoie l'en-tête `Content-Type: application/json`, puis affiche les données en JSON (avec `JSON_UNESCAPED_UNICODE`).
2. Écris `traiter(int $id)` : si le produit existe, elle répond avec le code `200` et `["succes" => true, "produit" => <le produit>]` ; sinon, avec le code `404` et `["succes" => false, "erreur" => "Produit introuvable"]`.
3. Appelle `traiter(1)` puis `traiter(99)`. Après chaque appel, affiche un saut de ligne, le code HTTP courant (`http_response_code()`) et un autre saut de ligne.

## Méthode
- [ ] Dans `repondre`, appelle `http_response_code($code)` et `header(...)` **avant** le `echo`
- [ ] Le tableau de réponse est transformé avec `json_encode`
- [ ] Pas d'autre texte que le JSON dans la réponse (le code est affiché à part, par ton programme principal)

## Résultat
- [ ] Ligne 1 : `{"succes":true,"produit":{"nom":"Clavier","prix":45}}`
- [ ] Ligne 2 : `200`
- [ ] Ligne 3 : `{"succes":false,"erreur":"Produit introuvable"}`
- [ ] Ligne 4 : `404`

## Indice
`$produits[$id] ?? null` renvoie `null` quand l'identifiant n'existe pas : c'est pratique pour choisir entre le `200` et le `404`.

## Tests
```js
const lignes = sortie.trim().split("\n").map((l) => l.trim());
assert(lignes[0] === '{"succes":true,"produit":{"nom":"Clavier","prix":45}}', "Ligne 1 : le JSON du produit 1");

assert(lignes[2] === '{"succes":false,"erreur":"Produit introuvable"}', "Ligne 3 : le JSON d'erreur pour le produit 99");
assert(lignes[3] === "404", "Ligne 4 : le code HTTP 404");
assert(/header\(\s*["']Content-Type:\s*application\/json/i.test(code), "Envoie l'en-tête Content-Type: application/json");

```

## Solution: index.php
```php
<?php

ob_start();

$produits = [
    1 => ["nom" => "Clavier", "prix" => 45],
    2 => ["nom" => "Souris", "prix" => 20],
];

function repondre(int $code, array $donnees): void {
    http_response_code($code);
    header("Content-Type: application/json");
    echo json_encode($donnees, JSON_UNESCAPED_UNICODE);
}

function traiter(int $id): void {
    global $produits;
    $produit = $produits[$id] ?? null;
    if ($produit === null) {
        repondre(404, ["succes" => false, "erreur" => "Produit introuvable"]);
        return;
    }
    repondre(200, ["succes" => true, "produit" => $produit]);
}

traiter(1);
echo "\n" . http_response_code() . "\n";

traiter(99);
echo "\n" . http_response_code() . "\n";
```
