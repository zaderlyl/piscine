## Cours
Pour présenter des données tabulaires (un planning, un relevé de notes, un catalogue de prix), HTML utilise les balises de tableau :

- `<table>` : la balise principale qui englobe tout le tableau.
- `<tr>` (table row) : définit **une ligne** horizontale du tableau.
- `<td>` (table data) : définit **une cellule** de contenu à l'intérieur d'une ligne.

Exemple d'un tableau à 2 lignes et 2 colonnes :
```html
<table>
  <tr>
    <td>Pomme</td>
    <td>1,50 €</td>
  </tr>
  <tr>
    <td>Poire</td>
    <td>2,00 €</td>
  </tr>
</table>
```

## Énoncé
Dans `index.html`, crée un tableau de données `<table>` contenant :
- au moins trois lignes `<tr>`
- au moins deux cellules `<td>` par ligne

Toutes les cellules doivent comporter du texte.

## Méthode
- [ ] Ouvre la balise `<table>`
- [ ] Crée au moins trois balises `<tr>`
- [ ] Place au moins deux `<td>` dans chaque `<tr>`
- [ ] Ferme chaque `<td>`, `<tr>` et le `</table>`

## Résultat
- [ ] La page affiche une grille de données d'au moins 3 lignes sur 2 colonnes

## Indice
La structure est toujours : `table` contient des `tr`, qui contiennent des `td`.

## Tests
```js
const table = $("table");
assert(table, "Il faut une balise <table>");

const lignes = table ? $$("tr", table) : [];
assert(lignes.length >= 3, "Le tableau doit comporter au moins trois lignes <tr>");

for (let i = 0; i < lignes.length; i++) {
  const cellules = $$("td", lignes[i]);
  assert(cellules.length >= 2, "La ligne " + (i + 1) + " doit comporter au moins deux cellules <td>");
  assert(
    cellules.every((td) => td.textContent.trim().length > 0),
    "Toutes les cellules de la ligne " + (i + 1) + " doivent comporter du texte"
  );
}
```
