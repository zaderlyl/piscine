## Cours
La balise `<img>` permet d'afficher une image. C'est une balise auto-fermante (elle ne possède pas de balise de fermeture `</img>`).

Elle s'accompagne d'attributs fondamentaux :
- `src` (source) : l'adresse ou le chemin du fichier image (ex. `src="photo.jpg"` ou une URL complète).
- `alt` (alternative text) : la description textuelle de l'image. **Cet attribut est obligatoire pour l'accessibilité** : les lecteurs d'écran pour déficients visuels le lisent à haute voix, et il s'affiche si l'image ne peut pas être chargée.
- `width` et `height` : la largeur et la hauteur en pixels (on écrit simplement le nombre, sans ajouter `px` en HTML). Renseigner ces dimensions réserve l'espace dans la page avant le chargement de l'image et évite les sauts d'affichage.

## Énoncé
Dans `index.html`, insère une balise `<img>` complète contenant :
- un attribut `src` avec le lien d'une image
- un texte alternatif descriptif dans l'attribut `alt`
- une largeur `width` et une hauteur `height` en pixels

## Méthode
- [ ] Utilise la balise `<img>`
- [ ] Renseigne les attributs `src`, `alt`, `width` et `height`
- [ ] Ne mets pas de balise fermante `</img>`

## Résultat
- [ ] La page affiche une image dimensionnée avec une description textuelle accessible

## Indice
La syntaxe d'une image en HTML :
`<img src="https://..." alt="Description de l'image" width="300" height="200">`

## Tests
```js
const img = $("img");
assert(img, "Ajoute une image <img> dans la page");
assert(img && img.getAttribute("src"), "Indique l'adresse de l'image dans l'attribut src");
assert(img && img.getAttribute("alt"), "Ajoute un attribut alt qui décrit l'image");
assert(img && img.getAttribute("alt").trim().length > 0, "Écris une description de l'image dans l'attribut alt");
assert(img && img.getAttribute("width") && Number(img.getAttribute("width")) > 0, "Ajoute à l'image une largeur width en pixels (un nombre)");
assert(img && img.getAttribute("height") && Number(img.getAttribute("height")) > 0, "Ajoute à l'image une hauteur height en pixels (un nombre)");
```

## Solution: index.html
```html
<p>
  <img src="https://picsum.photos/300/200" alt="Paysage naturel avec des montagnes" width="300" height="200">
</p>
```
