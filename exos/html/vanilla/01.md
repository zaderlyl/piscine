## Cours
Toute page HTML suit le même squelette :
- `<!DOCTYPE html>` dit au navigateur que c'est du HTML5.
- `<html>` entoure toute la page.
- `<head>` contient les informations sur la page (elles ne s'affichent pas).
- `<body>` contient ce que l'on voit.

Un commentaire s'écrit `<!-- comme ça -->` et n'est pas affiché. On indente les balises à l'intérieur d'une autre (deux espaces) pour lire le code plus facilement.

## Énoncé
Dans `index.html`, écris **à la main** le squelette complet d'une page : `DOCTYPE`, `html`, `head` et `body`. Ajoute **un commentaire** et **indente** le contenu de `body` avec deux espaces. Le `body` doit contenir au moins une balise.

## Méthode
- [ ] Commence par `<!DOCTYPE html>`
- [ ] Mets `head` et `body` à l'intérieur de `html`
- [ ] Ajoute un commentaire `<!-- ... -->`
- [ ] Indente le contenu du `body` de deux espaces

## Résultat
- [ ] La page a un squelette complet, avec un commentaire et une indentation

## Indice
Le squelette commence toujours par la même ligne. Ouvre et ferme chaque balise dans le bon ordre.

## Tests
```js
assert(document.doctype && document.doctype.name === "html", "Commence par <!DOCTYPE html>");
assert($("html") && $("head") && $("body"), "Il faut les balises html, head et body");
assert(document.createTreeWalker(document, NodeFilter.SHOW_COMMENT).nextNode(), "Ajoute un commentaire, par exemple <!-- mon commentaire -->");
assert([...document.body.childNodes].some((n) => n.nodeType === 3 && /\n\s{2,}/.test(n.textContent)), "Indente le contenu du body de deux espaces");
```

## Solution: index.html
```html
<!DOCTYPE html>
<html>
  <head>
  </head>
  <body>
    <!-- Ma première page -->
    <p>Bonjour</p>
  </body>
</html>
```
