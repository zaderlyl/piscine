## Cours
Un paragraphe s'écrit avec la balise `p` : on ouvre `<p>`, on écrit le texte, puis on ferme `</p>`.

## Énoncé
Dans `index.html`, écris un **paragraphe** (`p`) qui contient le mot `HTML`. Le texte est libre.

## Méthode
- [ ] Utilise la balise `p`
- [ ] Le mot `HTML` apparaît dans le paragraphe

## Résultat
- [ ] La page affiche un paragraphe contenant le mot `HTML`

## Indice
Un paragraphe s'écrit `<p>Mon texte</p>`.

## Tests
```js
assert($$("p").some((p) => p.textContent.includes("HTML")), "Il faut un paragraphe (p) qui contient le mot HTML");
```

## Solution: index.html
```html
<p>HTML sert à structurer une page web.</p>
```
