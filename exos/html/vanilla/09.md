## Cours
Les balises sémantiques précisent la signification d'un extrait de texte pour les navigateurs, les lecteurs d'écran et les moteurs de recherche :

- `<abbr title="Définition complète">` : définit une abréviation ou un acronyme. L'attribut `title` donne sa signification au survol.
- `<cite>` : indique le titre d'une œuvre (livre, film, tableau, chanson, article).
- `<code>` : signale un fragment de code informatique ou de balise, affiché en police monospace.
- `<kbd>` : représente une touche ou une frappe clavier (ex. raccourci clavier).
- `<time datetime="AAAA-MM-JJ">` : représente une date ou une heure précise, lisible par une machine grâce à l'attribut `datetime`.

## Énoncé
Dans `index.html`, écris un texte contenant chacune de ces balises sémantiques :
- une abréviation `<abbr>` avec un attribut `title` (ex. `MMI`, `HTML`)
- un titre d'œuvre avec `<cite>`
- un extrait de code informatique avec `<code>`
- un raccourci clavier avec `<kbd>`
- une date avec `<time>` accompagnée d'un attribut `datetime` (ex. `datetime="2026-09-01"`)

## Méthode
- [ ] Utilise `abbr`, `cite`, `code`, `kbd` et `time`
- [ ] Renseigne l'attribut `title` sur `<abbr>`
- [ ] Renseigne l'attribut `datetime` sur `<time>`

## Résultat
- [ ] La page utilise les cinq balises de sens avec leurs attributs requis

## Indice
Pour l'abréviation : `<abbr title="HyperText Markup Language">HTML</abbr>`.
Pour la date : `<time datetime="2026-01-15">15 janvier 2026</time>`.

## Tests
```js
const abbr = $("abbr");
assert(abbr && abbr.getAttribute("title"), "Ajoute une abréviation <abbr> avec un attribut title");
assert(abbr && abbr.textContent.trim().length > 0, "Écris l'abréviation entre <abbr> et </abbr>");

const cite = $("cite");
assert(cite && cite.textContent.trim().length > 0, "Ajoute le titre d'une œuvre dans une balise <cite>");

const code = $("code");
assert(code && code.textContent.trim().length > 0, "Ajoute un fragment de code dans une balise <code>");

const kbd = $("kbd");
assert(kbd && kbd.textContent.trim().length > 0, "Ajoute une touche clavier dans une balise <kbd>");

const time = $("time");
assert(time && time.getAttribute("datetime"), "Ajoute une date <time> avec un attribut datetime");
assert(time && time.textContent.trim().length > 0, "Écris la date à afficher entre <time> et </time>");
```
