## Cours
Cet exercice est un **palier** : il n'y a pas de nouvelle notion. Tu mobilises l'ensemble des connaissances acquises sur les formulaires HTML pour concevoir un formulaire d'inscription complet, accessible et structuré.

Veille à soigner l'accessibilité : chaque champ doit avoir son `<label>` explicitement relié par son identifiant.

## Énoncé
Dans `index.html`, conçois le formulaire d'inscription à une journée portes ouvertes :
1. Une balise `<form>`.
2. Deux cadres `<fieldset>` distincts, chacun débutant par sa balise `<legend>` (ex. « Vos coordonnées » et « Votre projet »).
3. Dans le premier cadre :
   - un champ texte pour le nom complet, obligatoire (`required`)
   - un champ de type `email`, obligatoire (`required`)
4. Dans le second cadre :
   - un menu déroulant `<select>` proposant au moins deux choix
   - une zone de texte multi-lignes `<textarea>` pour des questions ou commentaires
   - une case à cocher `<input type="checkbox">` (ex. acceptation des conditions)
5. Chaque champ doit être accompagné de son `<label>` relié via les attributs `for` et `id`.
6. Un bouton d'envoi `<button type="submit">`.

## Méthode
- [ ] Structure les deux blocs avec `<fieldset>` et `<legend>`
- [ ] Déclare chaque champ avec un `id` et un `name`
- [ ] Écris un `<label for="...">` correspondant à chaque `id`
- [ ] Ajoute le `<select>`, le `<textarea>`, la case à cocher et le bouton

## Résultat
- [ ] La page propose un formulaire complet d'inscription conforme aux bonnes pratiques d'ergonomie et d'accessibilité

## Indice
Rappelle-toi : chaque `input`, `select` et `textarea` doit avoir un `id` unique relié au `for` de son label.

## Tests
```js
const form = $("form");
assert(form, "Ajoute un formulaire <form>");

const fieldsets = [...(form?.querySelectorAll("fieldset") ?? [])];
assert(fieldsets.length >= 2, "Ajoute au moins deux cadres <fieldset> dans le formulaire");
assert(
  fieldsets.every((f) => f?.querySelector("legend") && f?.querySelector("legend").textContent.trim().length > 0),
  "Ajoute un titre <legend> non vide dans chaque <fieldset>"
);

const inputEmail = form?.querySelector("input[type='email'][required]");
assert(inputEmail, "Ajoute un champ <input type=\"email\"> obligatoire (attribut required)");

const select = form?.querySelector("select");
assert(select && [...(select?.querySelectorAll("option") ?? [])].length >= 2, "Ajoute un menu déroulant <select> avec au moins deux <option>");

const checkbox = form?.querySelector("input[type='checkbox']");
assert(checkbox, "Ajoute une case à cocher <input type=\"checkbox\">");

const textarea = form?.querySelector("textarea");
assert(textarea, "Ajoute une zone de texte <textarea>");

const bouton = form?.querySelector("button[type='submit'], input[type='submit'], button:not([type])");
assert(bouton, "Ajoute un bouton d'envoi <button type=\"submit\">");

// Vérification de la liaison des labels
const controles = [...(form?.querySelectorAll("input, select, textarea") ?? [])];
for (const ctrl of controles) {
  const idCtrl = ctrl.getAttribute("id");
  assert(idCtrl, "Ajoute un attribut id à chaque champ du formulaire");
  const label = form?.querySelector("label[for='" + idCtrl + "']");
  assert(label, "Relie le champ id=\"" + idCtrl + "\" à un <label for=\"" + idCtrl + "\">");
}
```

## Solution: index.html
```html
<form>
  <fieldset>
    <legend>Vos coordonnées</legend>
    <p>
      <label for="nom">Nom complet :</label>
      <input type="text" id="nom" name="nom" required>
    </p>
    <p>
      <label for="courriel">Adresse e-mail :</label>
      <input type="email" id="courriel" name="email" required>
    </p>
  </fieldset>

  <fieldset>
    <legend>Votre venue</legend>
    <p>
      <label for="creneau">Créneau souhaité :</label>
      <select id="creneau" name="creneau">
        <option value="matin">Matin (09h00 - 12h00)</option>
        <option value="apres-midi">Après-midi (14h00 - 17h00)</option>
      </select>
    </p>
    <p>
      <label for="remarques">Questions ou besoins particuliers :</label><br>
      <textarea id="remarques" name="remarques" rows="4" cols="30"></textarea>
    </p>
    <p>
      <label for="accord">
        <input type="checkbox" id="accord" name="accord" required>
        J'accepte d'être recontacté pour cet événement
      </label>
    </p>
  </fieldset>

  <p>
    <button type="submit">Confirmer mon inscription</button>
  </p>
</form>
```
