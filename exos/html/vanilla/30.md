## Cours
Un formulaire permet aux visiteurs d'envoyer des informations vers un serveur ou un script :

- `<form>` : la balise principale qui englobe tous les champs et boutons du formulaire.
- `<input type="text">` : un champ de saisie d'une ligne de texte. L'attribut `name` donne le nom sous lequel la donnée sera transmise au serveur.
- `<label>` : l'étiquette textuelle décrivant le champ. **Règle fondamentale d'accessibilité** : on associe un label à son champ en donnant la même valeur à l'attribut `for` du `<label>` et à l'attribut `id` de l'`<input>` :
  ```html
  <label for="prenom">Votre prénom :</label>
  <input type="text" id="prenom" name="prenom">
  ```
- `<button type="submit">Envoyer</button>` : le bouton qui déclenche la soumission du formulaire.

## Énoncé
Dans `index.html`, crée un formulaire contenant :
1. Une balise `<form>`.
2. Un champ de texte `<input type="text">` doté des attributs `id` et `name`.
3. Un `<label>` explicitement relié à ce champ grâce à l'attribut `for`.
4. Un bouton de soumission `<button type="submit">`.

## Méthode
- [ ] Ouvre la balise `<form>` et ferme-la après les champs
- [ ] Renseigne la même valeur pour `for="..."` sur le label et `id="..."` sur l'input
- [ ] N'oublie pas l'attribut `name` sur le champ de texte
- [ ] Ajoute le bouton de soumission

## Résultat
- [ ] La page affiche un champ de texte accessible avec son libellé et son bouton d'envoi

## Indice
La valeur de `for` sur le `<label>` doit correspondre exactement à la valeur de `id` sur l'`<input>`.

## Tests
```js
const form = $("form");
assert(form, "Il faut une balise <form>");

const input = $("input[type='text'], input:not([type])", form);
assert(input, "Le formulaire doit contenir un champ de texte <input type=\"text\">");
assert(input && input.getAttribute("id"), "Le champ <input> doit avoir un attribut id");
assert(input && input.getAttribute("name"), "Le champ <input> doit avoir un attribut name pour la transmission des données");

const idInput = input ? input.getAttribute("id") : "";
const label = $("label[for='" + idInput + "']", form);
assert(label, "Il faut un <label> avec l'attribut for=\"" + idInput + "\" relié au champ");
assert(label && label.textContent.trim().length > 0, "Le <label> doit comporter un texte descriptif");

const bouton = $("button[type='submit'], input[type='submit'], button:not([type])", form);
assert(bouton, "Le formulaire doit comporter un bouton de soumission (<button type=\"submit\">)");
```

## Solution: index.html
```html
<form>
  <p>
    <label for="nom-utilisateur">Nom complet :</label>
    <input type="text" id="nom-utilisateur" name="nom_utilisateur">
  </p>
  <p>
    <button type="submit">Envoyer le formulaire</button>
  </p>
</form>
```
