## Cours
Cet exercice est un **palier** : il n'y a pas de nouvelle notion. Tu réunis ce que tu as appris (titres, listes, liens, images, tableaux, formulaires, structure) pour construire une page complète à partir d'un cahier des charges.

Trois notions sont **imposées** et vérifiées avec soin : un tableau bien construit, un formulaire dont chaque champ a son `label`, et la structure de la page avec `header`, `main` et `footer`. Pour le reste (le choix de la recette, les textes, l'image), tu es libre.

## Énoncé
Dans `index.html`, construis la page d'une recette de cuisine de ton choix. Les repères ci-dessous sont **imposés** : les tests s'appuient dessus.

**Structure de la page**
- Un `<header>` qui contient le titre de la recette : un seul `<h1>` avec `id="titre"`.
- Un `<main>` qui contient tout le contenu de la recette.
- Un `<footer>` avec un texte (par exemple l'auteur ou la date).

**Dans le `<main>`**
1. Une liste des ingrédients, avec `id="ingredients"` : au moins 3 éléments `<li>`.
2. Une liste numérotée des étapes, avec `id="etapes"` : un `<ol>` d'au moins 3 éléments `<li>`.
3. Un lien « Aller aux étapes » qui mène à la liste des étapes (ancre vers `#etapes`).
4. Une image de la recette dans une `<figure>`, avec un `alt` et une légende `<figcaption>`.
5. Un tableau des valeurs nutritionnelles, avec `id="nutrition"` : une ligne d'en-tête (`<thead>` avec des `<th>`), au moins 2 colonnes et au moins 2 lignes de données.
6. Un formulaire de commentaire, avec `id="commentaire"` : un champ texte pour le nom, une zone de texte `<textarea>` pour le message et un bouton d'envoi. Chaque champ a son `<label>` relié par `for` et `id`.

## Méthode
- [ ] Pose d'abord la structure : `<header>`, `<main>`, `<footer>`
- [ ] Ajoute les deux listes et le lien d'ancre
- [ ] Ajoute la `<figure>` et le tableau avec son `<thead>`
- [ ] Termine par le formulaire, avec un `<label for="...">` par champ

## Résultat
- [ ] La page affiche une recette complète : titre, ingrédients, étapes numérotées, image légendée, tableau nutritionnel et formulaire de commentaire

## Indice
Les ids sont des repères pour les tests : `titre`, `ingredients`, `etapes`, `nutrition`, `commentaire`. Pour relier un champ à son label, donne un `id` au champ et le même nom à `for` du label.

## Tests
```js
// Structure de la page
assert($("header"), "Ajoute un <header> pour l'en-tête de la page");
assert($("main"), "Ajoute un <main> pour le contenu principal");
const pied = $("footer");
assert(pied && pied.textContent.trim().length > 0, "Ajoute un <footer> avec un texte");

assert($$("h1").length === 1, "Il faut exactement un <h1> dans la page");
assert($("#titre")?.tagName === "H1", "Le titre de la recette doit être le <h1> avec id=\"titre\"");
assert(!$("#titre") || $("#titre").textContent.trim().length > 0, "Le titre de la recette ne doit pas être vide");
assert(!$("#titre") || $("header #titre"), "Place le titre <h1> à l'intérieur du <header>");

// Les repères sont dans le <main>
for (const id of ["ingredients", "etapes", "nutrition", "commentaire"]) {
  assert($("#" + id), "Ajoute l'élément avec id=\"" + id + "\"");
  assert(!$("#" + id) || $("main #" + id), "Place l'élément id=\"" + id + "\" à l'intérieur du <main>");
}

// Listes
const ingredients = $("#ingredients");
assert(
  !ingredients || ingredients.querySelectorAll("li").length >= 3,
  "La liste id=\"ingredients\" devrait avoir au moins 3 éléments <li>"
);
const etapes = $("#etapes");
assert(!etapes || etapes.tagName === "OL", "La liste des étapes id=\"etapes\" doit être une liste numérotée <ol>");
assert(
  !etapes || etapes.querySelectorAll("li").length >= 3,
  "La liste id=\"etapes\" devrait avoir au moins 3 éléments <li>"
);

// Lien d'ancre
assert($("a[href='#etapes']"), "Ajoute un lien <a href=\"#etapes\"> qui mène à la liste des étapes");

// Image légendée
const figure = $("figure");
assert(figure, "Ajoute une <figure> pour l'image de la recette");
const image = figure?.querySelector("img");
if (figure) {
  assert(image && image.getAttribute("src"), "Ajoute une <img> avec un src dans la <figure>");
  assert(!image || image.getAttribute("alt")?.trim(), "Ajoute un texte alternatif (alt) non vide à l'image");
  assert(figure.querySelector("figcaption")?.textContent.trim(), "Ajoute une <figcaption> non vide dans la <figure>");
}

// Tableau (notion imposée)
const tableau = $("#nutrition");
if (tableau) {
  assert(tableau.tagName === "TABLE", "Le tableau nutritionnel doit être un <table> avec id=\"nutrition\"");
  assert(tableau.querySelector("thead th"), "Ajoute une ligne d'en-tête : un <thead> qui contient des <th>");
  assert(
    (tableau.querySelector("thead tr")?.children.length ?? 0) >= 2,
    "Le tableau devrait avoir au moins 2 colonnes (2 cellules d'en-tête)"
  );
  assert(
    tableau.querySelectorAll("tbody tr td").length >= 4,
    "Ajoute au moins 2 lignes de données (des <td>) sous l'en-tête"
  );
}

// Formulaire (notion imposée)
const formulaire = $("#commentaire");
if (formulaire) {
  assert(formulaire.tagName === "FORM", "Le formulaire de commentaire doit être un <form> avec id=\"commentaire\"");
  assert(
    formulaire.querySelector("input[type='text'], input:not([type])"),
    "Ajoute un champ texte <input type=\"text\"> pour le nom"
  );
  assert(formulaire.querySelector("textarea"), "Ajoute une zone de texte <textarea> pour le message");
  assert(
    formulaire.querySelector("button[type='submit'], button:not([type]), input[type='submit']"),
    "Ajoute un bouton d'envoi <button type=\"submit\">"
  );
  const champs = [...formulaire.querySelectorAll("input, textarea, select")].filter(
    (c) => !["submit", "button", "hidden"].includes(c.getAttribute("type"))
  );
  for (const champ of champs) {
    const idChamp = champ.getAttribute("id");
    assert(idChamp, "Ajoute un attribut id à chaque champ du formulaire");
    assert(
      !idChamp || formulaire.querySelector("label[for='" + idChamp + "']"),
      "Relie le champ id=\"" + idChamp + "\" à un <label for=\"" + idChamp + "\">"
    );
  }
}
```

## Solution: index.html
```html
<header>
  <h1 id="titre">Crêpes de la Chandeleur</h1>
</header>

<main>
  <p><a href="#etapes">Aller aux étapes</a></p>

  <figure>
    <img src="https://picsum.photos/400/250" alt="Une pile de crêpes dorées" width="400" height="250">
    <figcaption>Des crêpes bien dorées, prêtes à être garnies.</figcaption>
  </figure>

  <h2>Ingrédients</h2>
  <ul id="ingredients">
    <li>250 g de farine</li>
    <li>3 œufs</li>
    <li>50 cl de lait</li>
    <li>1 pincée de sel</li>
  </ul>

  <h2>Étapes</h2>
  <ol id="etapes">
    <li>Mélanger la farine, le sel et les œufs.</li>
    <li>Ajouter le lait petit à petit en fouettant.</li>
    <li>Laisser reposer la pâte une heure.</li>
    <li>Cuire chaque crêpe dans une poêle chaude.</li>
  </ol>

  <h2>Valeurs nutritionnelles</h2>
  <table id="nutrition">
    <thead>
      <tr>
        <th>Pour une crêpe</th>
        <th>Quantité</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Énergie</td>
        <td>120 kcal</td>
      </tr>
      <tr>
        <td>Glucides</td>
        <td>18 g</td>
      </tr>
    </tbody>
  </table>

  <h2>Un commentaire ?</h2>
  <form id="commentaire">
    <p>
      <label for="nom">Ton nom :</label>
      <input type="text" id="nom" name="nom">
    </p>
    <p>
      <label for="message">Ton message :</label><br>
      <textarea id="message" name="message" rows="4" cols="30"></textarea>
    </p>
    <p>
      <button type="submit">Envoyer</button>
    </p>
  </form>
</main>

<footer>
  <p>Recette proposée par la classe de MMI.</p>
</footer>
```
