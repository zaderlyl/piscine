## Cours
Cet exercice est un **palier** : il n'y a pas de nouvelle notion. Tu mobilises l'ensemble des balises de texte apprises jusqu'ici pour construire une page structurée et enrichie.

Prends l'habitude de bien imbriquer les balises en fermant d'abord la plus intérieure, puis celle qui l'englobe.

## Énoncé
Dans `index.html`, reproduis l'article suivant :

1. Un titre principal `<h1>` contenant le texte `Découvrir le Web`
2. Un sous-titre `<h2>` contenant le texte `Introduction aux bases`
3. Un premier paragraphe `<p>` qui contient :
   - au moins un mot en gras avec `<strong>`
   - au moins un mot en italique avec `<em>`
   - au moins un mot surligné avec `<mark>`
4. Un deuxième paragraphe `<p>` qui contient :
   - un fragment de code avec `<code>`
   - une mention discrète en petits caractères avec `<small>`

## Méthode
- [ ] Crée le `<h1>` puis le `<h2>`
- [ ] Rédige les deux paragraphes `<p>`
- [ ] Imbrique `strong`, `em` et `mark` dans le premier paragraphe
- [ ] Imbrique `code` et `small` dans le second paragraphe

## Résultat
- [ ] La page reproduit fidèlement la structure de l'article avec l'ensemble des balises demandées

## Indice
Structure ta page du haut vers le bas. N'oublie pas de fermer chaque balise dans le bon ordre.

## Tests
```js
const h1 = $("h1");
assert(h1 && h1.textContent.includes("Découvrir le Web"), "Ajoute un titre <h1> qui contient « Découvrir le Web »");

const h2 = $("h2");
assert(h2 && h2.textContent.includes("Introduction aux bases"), "Ajoute un sous-titre <h2> qui contient « Introduction aux bases »");

const paragraphes = $$("p");
assert(paragraphes.length >= 2, "Ajoute au moins deux paragraphes <p>");

const p1 = paragraphes[0];
assert(p1?.querySelector("strong"), "Mets un mot en gras avec <strong> dans le premier paragraphe");
assert(p1?.querySelector("em"), "Mets un mot en italique avec <em> dans le premier paragraphe");
assert(p1?.querySelector("mark"), "Surligne un mot avec <mark> dans le premier paragraphe");

const p2 = paragraphes[1];
assert(p2?.querySelector("code"), "Ajoute un fragment de code <code> dans le deuxième paragraphe");
assert(p2?.querySelector("small"), "Ajoute une mention <small> dans le deuxième paragraphe");
```

## Solution: index.html
```html
<h1>Découvrir le Web</h1>
<h2>Introduction aux bases</h2>
<p>Le web est un espace <strong>formidable</strong> pour apprendre, où la curiosité est <em>essentielle</em> et chaque projet est une <mark>aventure</mark>.</p>
<p>On commence souvent par écrire la balise <code>&lt;p&gt;</code> pour afficher du texte. <small>Rédigé pour les débutants.</small></p>
```
