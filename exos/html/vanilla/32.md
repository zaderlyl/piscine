## Cours
Pour proposer des choix prédéfinis aux utilisateurs, HTML propose deux solutions complémentaires :

### 1. Le menu déroulant fermé : `<select>`
L'utilisateur est obligé de choisir parmi les options de la liste :
- `<select name="pays">` : englobe la liste de sélection.
- `<option value="fr">France</option>` : chaque choix possible. L'attribut `value` est la valeur réelle transmise au serveur.
- `<optgroup label="Europe">` : permet de regrouper visuellement des options par sous-catégories.

### 2. Le champ libre avec suggestions : `<datalist>`
L'utilisateur tape librement dans un champ texte standard, mais le navigateur lui propose une liste d'autocomplétion :
- L'input indique sa source : `<input list="villes" name="ville">`
- La liste fournit les suggestions :
  ```html
  <datalist id="villes">
    <option value="Paris">
    <option value="Lyon">
  </datalist>
  ```

## Énoncé
Dans `index.html`, crée un formulaire contenant :
1. Un menu déroulant `<select>` avec un attribut `name`, contenant au moins trois `<option>` munies d'un attribut `value`.
2. Un champ `<input>` muni d'un attribut `list="mes-suggestions"`.
3. Une balise `<datalist id="mes-suggestions">` contenant au moins deux balises `<option>`.

## Méthode
- [ ] Crée le `<select>` et place ses `<option value="...">` à l'intérieur
- [ ] Crée un `<input list="...">`
- [ ] Crée un `<datalist id="...">` avec le même identifiant

## Résultat
- [ ] La page propose un menu déroulant classique ainsi qu'un champ avec aide à la saisie par autocomplétion

## Indice
La liaison du datalist se fait par identifiant :
`<input list="navigateurs">`
`<datalist id="navigateurs"><option value="Firefox"><option value="Chrome"></datalist>`

## Tests
```js
const select = $("select");
assert(select, "Ajoute un menu déroulant <select>");
assert(select && select.getAttribute("name"), "Ajoute un attribut name au <select>");

const optionsSelect = select ? [...(select?.querySelectorAll("option") ?? [])] : [];
assert(optionsSelect.length >= 3, "Mets au moins trois <option> dans le <select>");
assert(
  optionsSelect.every((opt) => opt.hasAttribute("value")),
  "Ajoute un attribut value à chaque <option> du <select>"
);

const inputList = $("input[list]");
assert(inputList, "Ajoute un champ <input> avec un attribut list (ex. list=\"navigateurs\")");

const idList = inputList ? inputList.getAttribute("list") : "";
const datalist = $("datalist[id='" + idList + "']");
assert(datalist, "Ajoute une <datalist id=\"" + idList + "\"> (même valeur que l'attribut list)");

const optionsDatalist = datalist ? [...(datalist?.querySelectorAll("option") ?? [])] : [];
assert(optionsDatalist.length >= 2, "Mets au moins deux <option> de suggestion dans la <datalist>");
```

## Solution: index.html
```html
<form>
  <p>
    <label for="filiere">Filière d'études :</label>
    <select id="filiere" name="filiere">
      <option value="mmi">MMI</option>
      <option value="info">Informatique</option>
      <option value="geii">GEII</option>
    </select>
  </p>

  <p>
    <label for="ville">Ville de résidence :</label>
    <input type="text" id="ville" name="ville" list="villes-proposees">
    <datalist id="villes-proposees">
      <option value="Paris">
      <option value="Marseille">
      <option value="Lyon">
    </datalist>
  </p>

  <p>
    <button type="submit">Valider</button>
  </p>
</form>
```
