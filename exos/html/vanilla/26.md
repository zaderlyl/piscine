## Cours
Certaines mises en page de tableaux nécessitent qu'une cellule s'étende sur plusieurs colonnes ou plusieurs lignes. On utilise pour cela les attributs de fusion :

- `colspan="n"` (column span) : fusionne la cellule sur **n colonnes horizontales**.
- `rowspan="n"` (row span) : fusionne la cellule sur **n lignes verticales**.

Règle de structure :
- Si une cellule a `colspan="2"`, elle prend la place de 2 colonnes : il faut donc retirer une cellule `<td>` ou `<th>` sur la même ligne.
- Si une cellule a `rowspan="2"`, elle s'étend sur la ligne du dessous : il faut donc retirer une cellule sur la ligne suivante.

Exemple :
```html
<tr>
  <th colspan="2">Titre étendu sur deux colonnes</th>
</tr>
```

## Énoncé
Dans `index.html`, construis un tableau contenant :
- au moins une cellule fusionnée horizontalement avec l'attribut `colspan` (valeur supérieure ou égale à 2)
- au moins une cellule fusionnée verticalement avec l'attribut `rowspan` (valeur supérieure ou égale à 2)

Toutes les cellules doivent comporter du texte.

## Méthode
- [ ] Ajoute `colspan="2"` (ou plus) sur une cellule `<th>` ou `<td>`
- [ ] Ajoute `rowspan="2"` (ou plus) sur une cellule `<th>` ou `<td>`
- [ ] Ajuste le nombre de cellules sur chaque ligne pour conserver un tableau régulier

## Résultat
- [ ] Le tableau affiche des cellules fusionnées en largeur et en hauteur

## Indice
Un planning d'horaires se prête très bien à cet exercice : une matière de 2h occupe `rowspan="2"`, et un titre de journée générale utilise `colspan="2"`.

## Tests
```js
const table = $("table");
assert(table, "Ajoute un tableau <table>");

const celluleColspan = table?.querySelector("th[colspan], td[colspan]");
assert(
  celluleColspan && Number(celluleColspan.getAttribute("colspan")) >= 2,
  "Fusionne au moins deux colonnes avec colspan (valeur 2 ou plus)"
);

const celluleRowspan = table?.querySelector("th[rowspan], td[rowspan]");
assert(
  celluleRowspan && Number(celluleRowspan.getAttribute("rowspan")) >= 2,
  "Fusionne au moins deux lignes avec rowspan (valeur 2 ou plus)"
);

const toutesCellules = [...(table?.querySelectorAll("th, td") ?? [])];
assert(
  toutesCellules.every((c) => c.textContent.trim().length > 0),
  "Écris du texte dans chaque cellule du tableau"
);
```

## Solution: index.html
```html
<table>
  <tr>
    <th colspan="3">Planning des soutenances</th>
  </tr>
  <tr>
    <th rowspan="2">Matin</th>
    <td>09h00</td>
    <td>Groupe A — Projet Web</td>
  </tr>
  <tr>
    <td>10h30</td>
    <td>Groupe B — Identité visuelle</td>
  </tr>
  <tr>
    <th>Après-midi</th>
    <td>14h00</td>
    <td>Groupe C — Vidéo</td>
  </tr>
</table>
```
