## Cours
Les liens HTML permettent également d'interagir directement avec les applications du système d'exploitation :

- `mailto:contact@exemple.fr` : ouvre le client e-mail par défaut (Thunderbird, Apple Mail, Outlook) avec l'adresse du destinataire prête.
- `tel:+33123456789` : permet de lancer un appel téléphonique en un clic sur smartphone ou tablette.
- `download` : attribut qui indique au navigateur de **télécharger le fichier** au lieu de tenter de l'afficher dans la page. On peut préciser le nom souhaité pour le fichier téléchargé (ex. `download="plaquette.pdf"`).

## Énoncé
Dans `index.html`, crée trois liens d'action :
1. Un lien pour envoyer un courriel avec le protocole `mailto:`.
2. Un lien pour composer un numéro de téléphone avec le protocole `tel:`.
3. Un lien pour télécharger un document avec l'attribut `download`.

## Méthode
- [ ] Renseigne `href="mailto:adresse@exemple.fr"` pour le courriel
- [ ] Renseigne `href="tel:numero"` pour le téléphone
- [ ] Ajoute l'attribut `download` sur le lien de téléchargement

## Résultat
- [ ] La page propose trois liens déclenchant respectivement l'e-mail, l'appel téléphonique et le téléchargement

## Indice
La balise reste toujours `<a>`, c'est la valeur du `href` ou la présence de l'attribut `download` qui change l'action :
`<a href="mailto:...">M'écrire</a>`
`<a href="tel:...">M'appeler</a>`
`<a href="cv.pdf" download>Télécharger mon CV</a>`

## Tests
```js
const lienMail = $("a[href^='mailto:']");
assert(lienMail, "Il faut un lien vers une adresse e-mail (commençant par mailto:)");
assert(lienMail && (lienMail.getAttribute("href") || "").includes("@"), "L'adresse e-mail doit comporter un @");
assert(lienMail && lienMail.textContent.trim().length > 0, "Le lien e-mail doit avoir un texte");

const lienTel = $("a[href^='tel:']");
assert(lienTel, "Il faut un lien vers un numéro de téléphone (commençant par tel:)");
assert(lienTel && lienTel.textContent.trim().length > 0, "Le lien téléphone doit avoir un texte");

const lienDownload = $("a[download]");
assert(lienDownload, "Il faut un lien de téléchargement comportant l'attribut download");
assert(lienDownload && lienDownload.getAttribute("href"), "Le lien de téléchargement doit avoir un attribut href");
assert(lienDownload && lienDownload.textContent.trim().length > 0, "Le lien de téléchargement doit avoir un texte");
```

## Solution: index.html
```html
<h2>Nous joindre</h2>
<p>Envoyer un courriel : <a href="mailto:contact@universite.fr">contact@universite.fr</a></p>
<p>Appeler le standard : <a href="tel:+33123456789">+33 1 23 45 67 89</a></p>
<p>Consulter notre documentation : <a href="plaquette.pdf" download>Télécharger la plaquette (PDF)</a></p>
```
