## Cours
Pour structurer des séries d'éléments, HTML propose deux types de listes :

- `<ul>` (unordered list) : liste à puces, lorsque l'ordre n'a pas d'importance (ingrédients, hobbies, liens).
- `<ol>` (ordered list) : liste numérotée (1, 2, 3...), lorsque l'ordre compte (étapes d'une recette, classement).

Chaque puce ou étape s'écrit obligatoirement avec la balise `<li>` (list item), placée directement dans le `<ul>` ou le `<ol>`.

## Énoncé
Dans `index.html`, écris deux listes :
1. Une liste à puces `<ul>` contenant au moins trois éléments `<li>`.
2. Une liste numérotée `<ol>` contenant au moins trois éléments `<li>`.

Le contenu des éléments est libre.

## Méthode
- [ ] Crée une liste `<ul>` et insère trois `<li>` à l'intérieur
- [ ] Crée une liste `<ol>` et insère trois `<li>` à l'intérieur

## Résultat
- [ ] La page affiche une liste à puces et une liste numérotée, chacune avec au moins trois éléments

## Indice
Chaque élément de liste doit être enveloppé dans `<li>...</li>`. N'oublie pas de fermer la balise `<ul>` ou `<ol>` à la fin de la liste.

## Tests
```js
const ul = $("ul");
assert(ul, "Il faut une liste à puces <ul>");
const itemsUl = ul ? $$("li", ul) : [];
assert(itemsUl.length >= 3, "La liste <ul> doit contenir au moins trois éléments <li>");
assert(itemsUl.every((li) => li.textContent.trim().length > 0), "Chaque élément de la liste <ul> doit avoir du texte");

const ol = $("ol");
assert(ol, "Il faut une liste numérotée <ol>");
const itemsOl = ol ? $$("li", ol) : [];
assert(itemsOl.length >= 3, "La liste <ol> doit contenir au moins trois éléments <li>");
assert(itemsOl.every((li) => li.textContent.trim().length > 0), "Chaque élément de la liste <ol> doit avoir du texte");
```
