## Cours
Le `head` ne s'affiche pas directement dans le corps de la page, mais il donne des informations indispensables au navigateur et aux moteurs de recherche :
- `<title>` définit le titre affiché sur l'onglet du navigateur.
- `<meta charset="UTF-8">` indique au navigateur l'encodage du texte pour que les accents s'affichent correctement.
- `<meta name="description" content="...">` décrit la page dans les résultats de recherche.

## Énoncé
Dans `index.html`, génère le squelette de la page (tu peux utiliser le raccourci `!` débloqué au précédent exercice) et complète le `head` avec :
- un **titre** non vide dans `title` ;
- un **encodage** `UTF-8` ;
- une **description** non vide.

## Méthode
- [ ] Le `title` est dans le `head`, et il n'est pas vide
- [ ] `meta charset="UTF-8"` est dans le `head`
- [ ] `meta name="description"` a un contenu

## Résultat
- [ ] L'onglet affiche le titre de la page

## Indice
La description s'écrit `<meta name="description" content="Ma page">`. Le `content` contient le texte.

## Tests
```js
assert(document.doctype && document.doctype.name === "html", "Commence par <!DOCTYPE html>");
assert($("html") && $("head") && $("body"), "Il faut les balises html, head et body");
assert(document.title.trim() !== "", "Ajoute un title non vide dans le head");
assert($$("head meta[charset]").some((m) => m.getAttribute("charset").toLowerCase() === "utf-8"), "Ajoute <meta charset=\"UTF-8\"> dans le head");
assert($$("head meta[name='description']").some((m) => m.content.trim() !== ""), "Ajoute une meta description avec un contenu");
```

## Solution: index.html
```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <meta name="description" content="Ma première page">
    <title>Ma page</title>
  </head>
  <body>
    <p>Bonjour</p>
  </body>
</html>
```
