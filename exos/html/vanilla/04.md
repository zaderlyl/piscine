## Cours
HTML propose six niveaux de titres, de `<h1>` (le plus important) à `<h6>` (le moins important).

## Énoncé
Dans `index.html`, écris six titres, un de chaque niveau, de `h1` à `h6`, dans l'ordre. Le texte est libre.

# Méthode
- [ ] Utilise les balises `h1` à `h6`

## Résultat
- [ ] La page contient un titre de chaque niveau, dans l'ordre

## Indice
Un titre s'écrit `<h1>Mon titre</h1>`. Change seulement le chiffre.

## Tests
```js
for (let i = 1; i <= 6; i++) {
  assert($$("h" + i).length === 1, "Il faut exactement un titre h" + i);
}
const ordre = $$("h1, h2, h3, h4, h5, h6").map((titre) => titre.tagName).join(",");
assert(ordre === "H1,H2,H3,H4,H5,H6", "Les titres doivent être dans l'ordre, de h1 à h6");
```

## Solution: index.html
```html
<h1>Titre 1</h1>
<h2>Titre 2</h2>
<h3>Titre 3</h3>
<h4>Titre 4</h4>
<h5>Titre 5</h5>
<h6>Titre 6</h6>
```
