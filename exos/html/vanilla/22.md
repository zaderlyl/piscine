## Cours
Sur le web, les images servent très souvent de boutons de navigation : cliquer sur un logo pour revenir à l'accueil, sur une miniature pour voir l'image en grand, ou sur une bannière pour visiter un partenaire.

Pour rendre une image cliquable, on l'enveloppe simplement dans une balise de lien `<a>` :

```html
<a href="index.html">
  <img src="logo.png" alt="Accueil du site">
</a>
```

Dans ce cas, l'attribut `alt` de l'image sert également d'intitulé de lien pour les technologies d'assistance : il doit décrire la destination ou l'action du clic.

## Énoncé
Dans `index.html`, crée une image cliquable :
1. Une balise de lien `<a>` avec un attribut `href` valide.
2. Une balise `<img>` placée à l'intérieur du lien, munie de ses attributs `src` et `alt`.

## Méthode
- [ ] Ouvre la balise `<a href="...">`
- [ ] Place la balise `<img src="..." alt="...">` à l'intérieur
- [ ] Ferme la balise `</a>` après l'image

## Résultat
- [ ] L'image est cliquable et redirige vers la cible configurée dans le lien

## Indice
La balise `<a>` englobe l'image :
`<a href="..."><img src="..." alt="..."></a>`

## Tests
```js
const lien = $("a");
assert(lien, "Ajoute un lien <a>");
assert(lien && lien.getAttribute("href"), "Indique la destination du lien dans l'attribut href");

const img = $("a > img");
assert(img, "Place l'image <img> directement entre <a> et </a>");
assert(img && img.getAttribute("src"), "Indique l'adresse de l'image dans l'attribut src");
assert(img && img.getAttribute("alt"), "Ajoute un attribut alt à l'image");
assert(img && img.getAttribute("alt").trim().length > 0, "Décris la destination du lien dans l'attribut alt de l'image");
```

## Solution: index.html
```html
<p>
  <a href="https://developer.mozilla.org" target="_blank" rel="noopener">
    <img src="https://picsum.photos/250/150" alt="Consulter la documentation MDN">
  </a>
</p>
```
