## Cours
L'attribut `type` de la balise `<input>` adapte la saisie, la validation native et le clavier affiché sur smartphone :

- `type="email"` : attend une adresse électronique avec un `@` et un domaine.
- `type="password"` : masque les caractères saisis pour préserver la confidentialité.
- `type="number"` : restreint la saisie aux nombres.
- `type="date"` : affiche un sélecteur de date (calendrier natif du système).
- `type="checkbox"` : case à cocher permettant de sélectionner plusieurs options indépendantes.
- `type="radio"` : bouton radio pour un choix unique. Plusieurs boutons radio ayant le même attribut `name` forment un groupe exclusif.

## Énoncé
Dans `index.html`, crée un formulaire d'inscription contenant **au moins quatre types d'inputs différents** parmi :
- `email`
- `password`
- `number`
- `date`
- `checkbox`
- `radio`

Chaque champ doit posséder un attribut `name` et être accompagné d'un `<label>`.

## Méthode
- [ ] Ouvre une balise `<form>`
- [ ] Insère au moins quatre champs avec des types distincts
- [ ] Renseigne l'attribut `name` sur chaque `<input>`
- [ ] Associe un `<label>` à chaque champ

## Résultat
- [ ] Le formulaire propose quatre contrôles de saisie variés et adaptés aux types de données

## Indice
Exemple de syntaxe pour les types spécialisés :
`<input type="email" id="mel" name="mel">`
`<input type="password" id="pass" name="pass">`

## Tests
```js
const form = $("form");
assert(form, "Ajoute un formulaire <form>");

const inputs = [...(form?.querySelectorAll("input") ?? [])];
const typesPresents = new Set(inputs.map((i) => i.getAttribute("type") || "text"));

const typesCibles = ["email", "password", "number", "date", "checkbox", "radio"];
const intersection = typesCibles.filter((t) => typesPresents.has(t));

assert(
  intersection.length >= 4,
  "Utilise au moins 4 types différents parmi email, password, number, date, checkbox, radio (déjà utilisés : " + (intersection.join(", ") || "aucun") + ")"
);

assert(
  inputs.every((i) => i.getAttribute("name")),
  "Ajoute un attribut name à chaque champ <input>"
);
```

## Solution: index.html
```html
<form>
  <p>
    <label for="courriel">Adresse e-mail :</label>
    <input type="email" id="courriel" name="email">
  </p>
  <p>
    <label for="mdp">Mot de passe :</label>
    <input type="password" id="mdp" name="mot_de_passe">
  </p>
  <p>
    <label for="age">Âge :</label>
    <input type="number" id="age" name="age">
  </p>
  <p>
    <label for="naissance">Date de naissance :</label>
    <input type="date" id="naissance" name="naissance">
  </p>
  <p>
    <button type="submit">S'inscrire</button>
  </p>
</form>
```
