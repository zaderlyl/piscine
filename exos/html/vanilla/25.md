## Cours
Un tableau de données professionnel et accessible sépare clairement son titre, ses en-têtes, ses données et ses totaux :

- `<caption>` : le titre du tableau, placé obligatoirement en tout premier dans le `<table>`.
- `<thead>` : regroupe les lignes d'en-têtes.
- `<th>` (table header) : cellule d'en-tête, affichée en gras et centrée par défaut. L'attribut `scope="col"` ou `scope="row"` précise s'il s'agit d'un en-tête de colonne ou de ligne.
- `<tbody>` : regroupe les lignes de données principales.
- `<tfoot>` : regroupe les lignes de conclusion ou de totaux.

Exemple :
```html
<table>
  <caption>Relevé de notes</caption>
  <thead>
    <tr>
      <th scope="col">Matière</th>
      <th scope="col">Note</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>18</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Moyenne</td>
      <td>18</td>
    </tr>
  </tfoot>
</table>
```

## Énoncé
Dans `index.html`, construis un tableau structuré complet :
- un titre de tableau avec `<caption>`
- un bloc d'en-tête `<thead>` avec au moins deux cellules `<th>`
- un corps `<tbody>` avec au moins deux lignes de données `<tr>`
- un pied de tableau `<tfoot>` avec une ligne de total ou bilan

## Méthode
- [ ] Commence le tableau par `<caption>`
- [ ] Utilise `<thead>` pour la ligne des colonnes avec `<th>`
- [ ] Remplis `<tbody>` avec les lignes de données
- [ ] Termine par `<tfoot>` pour le récapitulatif

## Résultat
- [ ] Le tableau est structuré sémantiquement avec son titre, son en-tête, ses données et son pied de tableau

## Indice
La balise `<caption>` se place immédiatement après `<table>`, avant `<thead>`.

## Tests
```js
const table = $("table");
assert(table, "Ajoute un tableau <table>");

const caption = table ? table?.querySelector("caption") : null;
assert(caption && caption.textContent.trim().length > 0, "Ajoute un titre au tableau avec <caption>");

const thead = table ? table?.querySelector("thead") : null;
assert(thead, "Ajoute un bloc d'en-tête <thead>");
const headers = thead ? [...(thead?.querySelectorAll("th") ?? [])] : [];
assert(headers.length >= 2, "Mets au moins deux cellules d'en-tête <th> dans le <thead>");

const tbody = table ? table?.querySelector("tbody") : null;
assert(tbody, "Ajoute un corps de tableau <tbody>");
const lignesBody = tbody ? [...(tbody?.querySelectorAll("tr") ?? [])] : [];
assert(lignesBody.length >= 2, "Mets au moins deux lignes <tr> dans le <tbody>");

const tfoot = table ? table?.querySelector("tfoot") : null;
assert(tfoot, "Ajoute un pied de tableau <tfoot>");
const lignesFoot = tfoot ? [...(tfoot?.querySelectorAll("tr") ?? [])] : [];
assert(lignesFoot.length >= 1, "Mets au moins une ligne <tr> dans le <tfoot>");
```

## Solution: index.html
```html
<table>
  <caption>Budget prévisionnel du projet</caption>
  <thead>
    <tr>
      <th scope="col">Poste de dépense</th>
      <th scope="col">Montant</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Hébergement et nom de domaine</td>
      <td>80 €</td>
    </tr>
    <tr>
      <td>Abonnements logiciels</td>
      <td>120 €</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total</th>
      <td>200 €</td>
    </tr>
  </tfoot>
</table>
```
