## Cours
Pour présenter une image avec sa légende de façon sémantique et claire, HTML propose le duo `<figure>` et `<figcaption>` :

- `<figure>` : conteneur autonome représentant une illustration, un schéma, un graphique ou une photo en lien avec le contenu principal.
- `<figcaption>` (figure caption) : la légende textuelle de l'illustration, placée directement à l'intérieur de `<figure>` (au-dessus ou en dessous de l'image).

Exemple :
```html
<figure>
  <img src="schema.png" alt="Schéma du réseau">
  <figcaption>Figure 1 : Schéma d'architecture réseau.</figcaption>
</figure>
```

## Énoncé
Dans `index.html`, crée une illustration sémantique contenant :
1. Une balise `<figure>`
2. Une image `<img>` à l'intérieur, avec ses attributs `src` et `alt`
3. Une légende `<figcaption>` à l'intérieur de la figure

## Méthode
- [ ] Ouvre la balise `<figure>`
- [ ] Insère l'image `<img>` avec `src` et `alt`
- [ ] Insère la légende `<figcaption>`
- [ ] Ferme la balise `</figure>`

## Résultat
- [ ] La page affiche une image légendée sémantiquement dans une balise `<figure>`

## Indice
La balise `<figcaption>` doit se trouver à l'intérieur de `<figure>`, avant ou après l'`<img>`.

## Tests
```js
const figure = $("figure");
assert(figure, "Ajoute une balise <figure>");

const img = figure ? figure?.querySelector("img") : null;
assert(img, "Place une image <img> dans la <figure>");
assert(img && img.getAttribute("src"), "Indique l'adresse de l'image de la figure dans l'attribut src");
assert(img && img.getAttribute("alt"), "Ajoute un attribut alt qui décrit l'image de la figure");

const figcaption = figure ? figure?.querySelector("figcaption") : null;
assert(figcaption, "Ajoute une légende <figcaption> dans la <figure>");
assert(figcaption && figcaption.textContent.trim().length > 0, "Écris le texte de la légende dans <figcaption>");
```

## Solution: index.html
```html
<figure>
  <img src="https://picsum.photos/400/250" alt="Vue aérienne d'une forêt en automne">
  <figcaption>Figure 1 — Vue aérienne d'une forêt en automne.</figcaption>
</figure>
```
