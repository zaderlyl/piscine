## Cours
La balise `<iframe>` (inline frame) permet d'incorporer directement **une autre page web ou un document externe** au sein de sa propre page (par exemple une vidéo YouTube, une carte interactive, un lecteur audio ou un widget) :

- `src` : l'adresse URL du document ou du service à intégrer.
- `title` : **indispensable pour l'accessibilité**, cet attribut décrit le contenu embarqué pour permettre aux utilisateurs de lecteurs d'écran de savoir ce qui est affiché dans le cadre.
- `width` et `height` : la largeur et la hauteur de l'iframe en pixels.

Exemple :
```html
<iframe src="https://example.com" title="Page de démonstration" width="600" height="400"></iframe>
```

## Énoncé
Dans `index.html`, insère une balise `<iframe>` complète comprenant :
- l'attribut `src` avec l'adresse d'une page web externe
- l'attribut `title` décrivant clairement le contenu du cadre
- les attributs de dimension `width` et `height` en pixels

## Méthode
- [ ] Ouvre la balise `<iframe ...>` et ferme-la avec `</iframe>`
- [ ] Renseigne l'URL dans `src`
- [ ] Ajoute une description dans l'attribut `title`
- [ ] Renseigne `width` et `height`

## Résultat
- [ ] La page affiche un cadre `<iframe>` correctement dimensionné et accessible

## Indice
La balise `<iframe>` n'est pas auto-fermante : elle nécessite toujours sa balise fermante `</iframe>`.

## Tests
```js
const iframe = $("iframe");
assert(iframe, "Il faut une balise <iframe> dans la page");
assert(iframe && iframe.getAttribute("src"), "La balise <iframe> doit comporter un attribut src");
assert(iframe && iframe.getAttribute("title"), "La balise <iframe> doit comporter un attribut title pour l'accessibilité");
assert(iframe && iframe.getAttribute("title").trim().length > 0, "L'attribut title de l'iframe ne doit pas être vide");
assert(iframe && iframe.getAttribute("width") && Number(iframe.getAttribute("width")) > 0, "L'iframe doit avoir un attribut width numérique");
assert(iframe && iframe.getAttribute("height") && Number(iframe.getAttribute("height")) > 0, "L'iframe doit avoir un attribut height numérique");
```

## Solution: index.html
```html
<h2>Carte interactive du campus</h2>
<iframe
  src="https://www.openstreetmap.org/export/embed.html"
  title="Carte interactive OpenStreetMap du campus universitaire"
  width="600"
  height="350">
</iframe>
```
