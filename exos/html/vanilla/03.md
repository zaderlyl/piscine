## Cours
Tu viens d'écrire le squelette à la main. Dans un éditeur de code, on gagne du temps avec **Emmet** : une abréviation, puis la touche Tab, la transforme en code. Le raccourci `!` produit le squelette complet d'une page HTML.

Une fois cet exo réussi, le raccourci `!` est débloqué : tu pourras l'utiliser dans les exos suivants. Pour l'instant, écris le squelette à la main.

## Énoncé
Dans `index.html`, écris le squelette complet d'une page avec :
- un `title` non vide dans le `head` ;
- un `h1` dans le `body`, avec le texte `Bienvenue`.

## Méthode
- [ ] Le squelette contient `DOCTYPE`, `html`, `head` et `body`
- [ ] Le `title` est dans le `head` et n'est pas vide
- [ ] Le `h1` contient le texte `Bienvenue`

## Résultat
- [ ] La page affiche le titre `Bienvenue`, et l'onglet affiche le titre de la page

## Indice
Le titre de l'onglet se met dans `title`, dans le `head`. Le `h1` se met dans le `body`.

## Tests
```js
assert(document.doctype && document.doctype.name === "html", "Commence par <!DOCTYPE html>");
assert($("head title") && $("head title").textContent.trim() !== "", "Ajoute un title non vide dans le head");
assert($$("body h1").some((h) => h.textContent.trim() === "Bienvenue"), "Ajoute un h1 avec le texte Bienvenue dans le body");
```

## Solution: index.html
```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Ma page</title>
  </head>
  <body>
    <h1>Bienvenue</h1>
  </body>
</html>
```
