## Cours
Plutôt que d'utiliser des `<div>` partout, HTML5 fournit des **balises sémantiques de structure** qui donnent du sens aux grandes zones d'une page :

- `<header>` : l'en-tête de la page ou d'une section (logo, titre du site, slogan).
- `<nav>` : la zone dédiée à la navigation (liens de menu principaux).
- `<main>` : le contenu central et principal de la page. **Il ne doit y avoir qu'un seul `<main>` par page**.
- `<section>` : une partie thématique du document, débutant généralement par un titre `<h2>`.
- `<article>` : un contenu autonome et indépendant (un article de blog, une fiche recette, un témoignage).
- `<footer>` : le pied de page (mentions légales, copyright, liens de contact).

Ces balises permettent aux moteurs de recherche et aux outils d'accessibilité de naviguer directement vers les sections clés.

## Énoncé
Dans `index.html`, construis le squelette sémantique complet d'une page web :
1. Un `<header>` contenant le titre du site et un menu `<nav>`.
2. Un élément `<main>` unique représentant le corps de la page.
3. À l'intérieur du `<main>`, au moins une `<section>` ou un `<article>`.
4. Un `<footer>` pour le pied de page.

## Méthode
- [ ] Place `<header>`, `<main>` et `<footer>` dans le `<body>`
- [ ] Imbrique `<nav>` dans le `<header>`
- [ ] Imbrique au moins une `<section>` ou un `<article>` dans `<main>`

## Résultat
- [ ] La page respecte la structure sémantique standard du Web moderne avec les balises appropriées

## Indice
La structure classique suit cet ordre vertical :
`<header>` puis `<main>` puis `<footer>`.

## Tests
```js
const header = $("header");
assert(header, "Ajoute un en-tête <header>");

const nav = $("nav");
assert(nav, "Ajoute un menu de navigation <nav>");

const main = $$("main");
assert(main.length === 1, "Garde une seule balise <main> dans la page");

const sectionOuArticle = $("main section, main article");
assert(sectionOuArticle, "Place au moins une <section> ou un <article> dans le <main>");

const footer = $("footer");
assert(footer, "Ajoute un pied de page <footer>");
```

## Solution: index.html
```html
<header>
  <h1>Le Journal du Web</h1>
  <nav>
    <ul>
      <li><a href="#accueil">Accueil</a></li>
      <li><a href="#articles">Articles</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <h2>Les nouveautés de HTML5</h2>
    <p>Le balisage sémantique apporte une meilleure lisibilité pour les robots et les utilisateurs.</p>
  </article>
</main>

<footer>
  <p><small>© 2026 Le Journal du Web — Tous droits réservés.</small></p>
</footer>
```
