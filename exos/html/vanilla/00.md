## Cours
**HTML** sert à **structurer** une page web : dire ce qu'est un titre, un paragraphe, une image, un lien. Le navigateur lit ce code et l'affiche. HTML ne décide ni des couleurs ni de la mise en page : c'est le rôle de CSS.

### Les balises
On écrit du HTML avec des **balises**, entre chevrons `<` et `>`. La plupart vont par deux : une balise ouvrante et une balise fermante (avec un `/`). Ce qu'elles entourent est leur **contenu**. Le tout s'appelle un **élément**.

```html
<p>Bonjour tout le monde</p>
```

Ici, `<p>` ouvre un paragraphe, `Bonjour tout le monde` est son contenu et `</p>` le ferme.

### Un fichier, une page
Une page web est un fichier texte qui se termine par `.html`, par exemple `index.html`. Tu l'écris dans l'éditeur, et l'aperçu affiche ce que le navigateur en fait. Dans les exercices suivants, tu vas écrire ce fichier toi-même, balise après balise.
