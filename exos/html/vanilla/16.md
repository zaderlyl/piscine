## Cours
La balise `<a>` (anchor / ancre) permet de créer un **hyperlien** vers une autre page web ou ressource :

- `href` : l'adresse URL de destination (ex. `href="https://www.wikipedia.org"`). Sans cet attribut, le lien n'est pas cliquable.
- `target="_blank"` : ouvre le lien dans un **nouvel onglet** du navigateur.
- `rel="noopener"` : sécurise l'ouverture dans un nouvel onglet en empêchant la nouvelle page d'accéder à l'onglet d'origine via JavaScript.

## Énoncé
Dans `index.html`, crée au moins deux liens avec la balise `<a>` :
1. Un premier lien externe avec une adresse absolue (commençant par `https://`).
2. Un second lien externe qui s'ouvre dans un nouvel onglet avec `target="_blank"` et l'attribut de sécurité `rel="noopener"`.

Chaque lien doit afficher un libellé textuel clair.

## Méthode
- [ ] Utilise la balise `<a>` avec l'attribut `href`
- [ ] Configure `target="_blank"` sur le deuxième lien
- [ ] Ajoute `rel="noopener"` sur le lien ouvrant un nouvel onglet

## Résultat
- [ ] La page affiche deux liens externes cliquables, dont un configuré pour s'ouvrir dans un nouvel onglet

## Indice
La syntaxe d'un lien sécurisé dans un nouvel onglet est :
`<a href="https://..." target="_blank" rel="noopener">Mon lien</a>`

## Tests
```js
const liens = $$("a");
assert(liens.length >= 2, "Il faut au moins deux liens <a> sur la page");
assert(
  liens.every((a) => a.getAttribute("href") && /^https?:\/\//.test(a.getAttribute("href"))),
  "Tous les liens doivent avoir une adresse href absolue commençant par https:// ou http://"
);
assert(
  liens.every((a) => a.textContent.trim().length > 0),
  "Chaque lien doit contenir un texte visible"
);

const lienNouvelOnglet = liens.find((a) => a.getAttribute("target") === "_blank");
assert(lienNouvelOnglet, "Il faut au moins un lien avec target=\"_blank\"");
assert(
  lienNouvelOnglet && (lienNouvelOnglet.getAttribute("rel") || "").includes("noopener"),
  "Le lien ouvrant un nouvel onglet doit comporter l'attribut rel=\"noopener\""
);
```

## Solution: index.html
```html
<p>Consulter <a href="https://developer.mozilla.org">la documentation MDN</a>.</p>
<p>Visiter <a href="https://fr.wikipedia.org" target="_blank" rel="noopener">Wikipédia dans un nouvel onglet</a>.</p>
```
