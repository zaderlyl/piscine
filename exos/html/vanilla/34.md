## Cours
HTML5 intègre un système natif de validation côté client. Si un champ n'est pas valide, le navigateur bloque la soumission et affiche automatiquement un message d'erreur à l'utilisateur :

- `required` : rend le champ obligatoire. L'utilisateur ne peut pas soumettre le formulaire s'il est vide.
- `min="n"` et `max="n"` : impose des valeurs minimale et maximale sur les champs numériques (`type="number"`) ou de date.
- `minlength="n"` et `maxlength="n"` : impose une longueur minimale et maximale en nombre de caractères.
- `pattern="regex"` : valide la saisie selon une expression régulière. Par exemple, pour imposer un code postal français de 5 chiffres : `pattern="[0-9]{5}"`.
- `placeholder="ex: 75001"` : affiche un exemple grisé à l'intérieur du champ pour guider l'élève.

## Énoncé
Dans `index.html`, construis un formulaire avec validation native :
1. Un champ de texte obligatoire avec l'attribut `required`.
2. Un champ numérique comportant une valeur minimale `min` et une valeur maximale `max`.
3. Un champ texte vérifiant un format précis avec l'attribut `pattern` (par exemple 5 chiffres pour un code postal).
4. Un bouton de soumission `<button type="submit">`.

## Méthode
- [ ] Ajoute l'attribut `required` sur le premier champ
- [ ] Configure `type="number"`, `min="..."` et `max="..."` sur le second champ
- [ ] Configure l'attribut `pattern="..."` sur le troisième champ

## Résultat
- [ ] Le formulaire bloque automatiquement toute soumission non conforme aux critères de validation

## Indice
La syntaxe pour un code postal français de 5 chiffres :
`<input type="text" id="cp" name="cp" pattern="[0-9]{5}" placeholder="75000">`

## Tests
```js
const form = $("form");
assert(form, "Il faut une balise <form>");

const champRequis = $("input[required]", form);
assert(champRequis, "Il faut au moins un champ avec l'attribut required");

const champMinMax = $("input[min][max]", form);
assert(champMinMax, "Il faut un champ numérique comportant les attributs min et max");

const champPattern = $("input[pattern]", form);
assert(champPattern, "Il faut un champ texte vérifiant un format avec l'attribut pattern (ex. pattern=\"[0-9]{5}\")");
assert(champPattern && champPattern.getAttribute("pattern").length > 0, "L'attribut pattern ne doit pas être vide");

const bouton = $("button[type='submit'], input[type='submit'], button:not([type])", form);
assert(bouton, "Il faut un bouton de soumission");
```

## Solution: index.html
```html
<form>
  <p>
    <label for="nom">Nom :</label>
    <input type="text" id="nom" name="nom" required>
  </p>
  <p>
    <label for="quantite">Quantité (entre 1 et 10) :</label>
    <input type="number" id="quantite" name="quantite" min="1" max="10" required>
  </p>
  <p>
    <label for="code-postal">Code postal (5 chiffres) :</label>
    <input type="text" id="code-postal" name="cp" pattern="[0-9]{5}" placeholder="75001" required>
  </p>
  <p>
    <button type="submit">Commander</button>
  </p>
</form>
```
