## Cours
Une **ancre interne** permet de faire défiler automatiquement la page jusqu'à un endroit précis de la même page (très utile pour un sommaire, une table des matières ou une FAQ) :

1. Sur l'élément de destination, on ajoute un attribut `id` unique :
   `<h2 id="cours">Le cours</h2>`
2. Sur le lien, on renseigne la cible dans l'attribut `href` précédée d'un dièse `#` :
   `<a href="#cours">Aller au cours</a>`

Un identifiant `id` doit être unique dans toute la page : deux balises ne peuvent pas porter le même `id`.

## Énoncé
Dans `index.html`, crée un sommaire avec des ancres internes :
1. Au moins deux liens d'ancres pointant vers des identifiants de la page (ex. `href="#partie1"` et `href="#partie2"`).
2. Au moins deux sections ou titres portant exactement les attributs `id` correspondants (ex. `id="partie1"` et `id="partie2"`).
3. Un lien en bas de page pour remonter vers le haut (ex. `href="#sommaire"` vers le titre qui porte `id="sommaire"`).

## Méthode
- [ ] Donne un attribut `id` à chaque section ou titre cible
- [ ] Crée les liens avec l'attribut `href="#nom-de-l-id"`
- [ ] Vérifie que l'orthographe entre le `id` et le `href` est identique

## Résultat
- [ ] La page dispose d'un sommaire de liens cliquables reliés aux identifiants cibles de la page

## Indice
Attention à ne pas mettre le `#` dans la valeur de l'attribut `id` :
Cible : `<h2 id="chapitre1">...</h2>`
Lien : `<a href="#chapitre1">Chapitre 1</a>`

## Tests
```js
const liensAncres = $$("a").filter((a) => {
  const href = a.getAttribute("href") || "";
  return href.startsWith("#") && href.length > 1;
});
assert(liensAncres.length >= 2, "Ajoute au moins deux liens vers des ancres de la page (ex. href=\"#partie1\")");

for (const a of liensAncres) {
  const idCible = a.getAttribute("href").slice(1);
  const elementCible = document.getElementById(idCible);
  assert(elementCible, "Ajoute id=\"" + idCible + "\" sur l'élément visé par le lien #" + idCible);
}

assert(liensAncres.every((a) => a.textContent.trim().length > 0), "Écris un texte cliquable dans chaque lien d'ancre");

// Lien de retour : sa cible est placée avant lui dans la page
const lienRetour = liensAncres.find((a) => {
  const cible = document.getElementById(a.getAttribute("href").slice(1));
  return cible && cible.compareDocumentPosition(a) & Node.DOCUMENT_POSITION_FOLLOWING;
});
assert(lienRetour, "Ajoute en bas de page un lien qui remonte vers un élément du haut (ex. href=\"#sommaire\")");
```

## Solution: index.html
```html
<h1 id="sommaire">Sommaire</h1>
<nav>
  <ul>
    <li><a href="#html">Introduction HTML</a></li>
    <li><a href="#css">Introduction CSS</a></li>
  </ul>
</nav>

<h2 id="html">Introduction HTML</h2>
<p>Le langage HTML permet de structurer le texte et les éléments multimédias.</p>

<h2 id="css">Introduction CSS</h2>
<p>Le langage CSS permet de styliser et mettre en page les documents web.</p>

<p><a href="#sommaire">Retour au sommaire</a></p>
```
