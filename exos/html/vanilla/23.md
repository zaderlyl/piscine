## Cours
Lorsqu'une seule image contient plusieurs régions cliquables différentes (par exemple une carte du monde, un plan de musée ou un schéma technique), on utilise une **image réactive** grâce aux balises `<map>` et `<area>` :

1. L'image `<img>` est liée à la carte via l'attribut `usemap="#nom-de-carte"`.
2. La carte est définie avec `<map name="nom-de-carte">`.
3. Chaque zone interactive est définie par une balise auto-fermante `<area>` avec :
   - `shape` : la forme (`rect` pour rectangle, `circle` pour cercle, `poly` pour polygone).
   - `coords` : les coordonnées en pixels (ex. `coords="0,0,100,100"` pour un rectangle x1, y1, x2, y2).
   - `href` : le lien ouvert au clic.
   - `alt` : le texte descriptif de la zone (obligatoire pour l'accessibilité).

## Énoncé
Dans `index.html`, mets en place une image avec deux zones cliquables distinctes :
1. Une balise `<img>` reliée à une carte par l'attribut `usemap="#ma-carte"`.
2. Une balise `<map name="ma-carte">`.
3. Au moins deux balises `<area>` à l'intérieur de la carte, chacune avec ses attributs `shape`, `coords`, `href` et `alt`.

## Méthode
- [ ] Ajoute `usemap="#nom"` sur l'image
- [ ] Crée `<map name="nom">` avec le même nom (sans le `#`)
- [ ] Insère deux zones `<area>` dans la carte
- [ ] Renseigne `shape`, `coords`, `href` et `alt` sur chaque zone

## Résultat
- [ ] L'image dispose de deux zones cliquables distinctes menant vers des destinations différentes

## Indice
Attention à la correspondance des noms :
`<img src="..." alt="..." usemap="#carte">`
`<map name="carte">`
  `<area shape="rect" coords="0,0,100,100" href="..." alt="...">`
`</map>`

## Tests
```js
const img = $("img");
assert(img, "Il faut une balise <img>");
const usemap = img ? img.getAttribute("usemap") : null;
assert(usemap && usemap.startsWith("#"), "L'image doit comporter un attribut usemap commençant par # (ex. usemap=\"#carte\")");

const nomCarte = usemap ? usemap.slice(1) : "";
const map = $("map[name='" + nomCarte + "']");
assert(map, "Il faut une balise <map> avec l'attribut name=\"" + nomCarte + "\" correspondant au usemap de l'image");

const areas = map ? $$("area", map) : [];
assert(areas.length >= 2, "La balise <map> doit contenir au moins deux zones <area>");
assert(
  areas.every((a) => a.getAttribute("shape")),
  "Chaque zone <area> doit comporter un attribut shape (ex. shape=\"rect\")"
);
assert(
  areas.every((a) => a.getAttribute("coords")),
  "Chaque zone <area> doit comporter des coordonnées dans l'attribut coords"
);
assert(
  areas.every((a) => a.getAttribute("href")),
  "Chaque zone <area> doit comporter un lien de destination dans l'attribut href"
);
assert(
  areas.every((a) => a.getAttribute("alt") && a.getAttribute("alt").trim().length > 0),
  "Chaque zone <area> doit comporter un texte descriptif dans l'attribut alt pour l'accessibilité"
);
```

## Solution: index.html
```html
<img src="https://picsum.photos/400/200" alt="Bannière interactive" usemap="#banniere-navigation" width="400" height="200">

<map name="banniere-navigation">
  <area shape="rect" coords="0,0,200,200" href="gauche.html" alt="Section gauche de la bannière">
  <area shape="rect" coords="200,0,400,200" href="droite.html" alt="Section droite de la bannière">
</map>
```
