## Cours
Pour représenter une hiérarchie (un sommaire de cours, un plan détaillé, une arborescence de fichiers ou un menu de navigation), on peut **imbriquer** des listes les unes dans les autres.

La règle essentielle en HTML : **la sous-liste doit être placée à l'intérieur du `<li>` parent**, juste avant sa balise fermante `</li>` :

```html
<ul>
  <li>Fruits
    <ul>
      <li>Pomme</li>
      <li>Poire</li>
    </ul>
  </li>
  <li>Légumes</li>
</ul>
```

Ne place jamais une sous-liste directement entre deux `<li>` : elle doit toujours être le contenu d'un élément de liste.

## Énoncé
Dans `index.html`, écris une liste (ordonnée ou à puces) contenant au moins deux éléments de premier niveau.

L'un de ces éléments doit comporter une **sous-liste imbriquée** (avec `<ul>` ou `<ol>`), contenant au moins deux sous-éléments `<li>`.

## Méthode
- [ ] Ouvre la liste principale (`<ul>` ou `<ol>`)
- [ ] Dans l'un des `<li>`, insère une nouvelle liste (`<ul>` ou `<ol>`)
- [ ] Place au moins deux `<li>` dans la sous-liste
- [ ] Ferme bien la sous-liste avant de fermer le `<li>` parent

## Résultat
- [ ] La page affiche une liste hiérarchique avec au moins deux niveaux de profondeur bien imbriqués

## Indice
La balise de la sous-liste (`<ul>` ou `<ol>`) se trouve entre `<li>` et `</li>` du parent.

## Tests
```js
const listeParente = $("ul, ol");
assert(listeParente, "Ajoute une liste principale (<ul> ou <ol>)");

const sousListe = $("li > ul, li > ol");
assert(sousListe, "Place une sous-liste (<ul> ou <ol>) à l'intérieur d'un <li> de la liste principale");

const sousItems = sousListe ? [...(sousListe?.querySelectorAll("li") ?? [])] : [];
assert(sousItems.length >= 2, "Mets au moins deux éléments <li> dans la sous-liste");
assert(sousItems.every((li) => li.textContent.trim().length > 0), "Écris du texte dans chaque <li> de la sous-liste");

// Vérifie que le premier niveau a au moins 2 éléments
const itemsRacine = listeParente ? [...listeParente.children].filter((el) => el.tagName === "LI") : [];
assert(itemsRacine.length >= 2, "Mets au moins deux éléments <li> dans la liste principale");
```
