## Cours
Un site web est généralement composé de plusieurs fichiers HTML reliés entre eux. Pour naviguer d'une page à une autre sans indiquer une adresse complète `https://...`, on utilise un **chemin relatif** :

- Vers un fichier situé dans le même dossier : `<a href="contact.html">Contact</a>`
- Vers un fichier situé dans un sous-dossier : `<a href="blog/article.html">Article</a>`
- Vers le dossier parent : `<a href="../index.html">Retour à l'accueil</a>`

Bonnes pratiques du Web pour les noms de fichiers :
- Utilise uniquement des minuscules sans accents (ex. `a-propos.html` et non `À-propos.html`).
- Remplace les espaces par des tirets `-` (les espaces causent des erreurs de lien).

## Énoncé
Dans `index.html`, construis un menu de navigation vers deux autres pages du site :
1. Un premier lien relatif vers une page de contact ou de présentation (ex. `contact.html` ou `a-propos.html`).
2. Un second lien relatif vers une autre page (ex. `mentions-legales.html` ou `projets/portfolio.html`).

Veille à ce que les adresses `href` respectent les conventions web : extension `.html`, pas d'espaces ni d'accents.

## Méthode
- [ ] Utilise la balise `<a>` avec des adresses relatives
- [ ] Termine les noms de cibles par `.html`
- [ ] Évite les majuscules, accents et espaces dans les valeurs de `href`

## Résultat
- [ ] La page dispose d'une navigation interne propre vers deux pages secondaires du site

## Indice
Un chemin relatif ne commence ni par `https://`, ni par `#`. Exemple : `<a href="equipe.html">Notre équipe</a>`.

## Tests
```js
const liens = $$("a");
assert(liens.length >= 2, "Ajoute au moins deux liens <a> dans la page");

const liensRelatifs = liens.filter((a) => {
  const href = a.getAttribute("href") || "";
  return !href.startsWith("http://") && !href.startsWith("https://") && !href.startsWith("#") && !href.startsWith("mailto:") && !href.startsWith("tel:");
});

assert(liensRelatifs.length >= 2, "Ajoute au moins deux liens relatifs vers d'autres pages (ex. href=\"contact.html\")");
assert(
  liensRelatifs.every((a) => (a.getAttribute("href") || "").endsWith(".html")),
  "Termine chaque adresse de page par l'extension .html"
);
assert(
  liensRelatifs.every((a) => !/\s/.test(a.getAttribute("href") || "")),
  "Remplace les espaces des noms de fichiers par des tirets"
);
assert(
  liensRelatifs.every((a) => !/[éèêëàâäîïôöùûüç]/i.test(a.getAttribute("href") || "")),
  "Retire les accents des noms de fichiers"
);
assert(
  liensRelatifs.every((a) => a.textContent.trim().length > 0),
  "Écris un texte cliquable dans chaque lien"
);
```

## Solution: index.html
```html
<nav>
  <ul>
    <li><a href="a-propos.html">À propos</a></li>
    <li><a href="contact.html">Nous contacter</a></li>
  </ul>
</nav>
```
