## Cours
La balise `<hr>` trace une **ligne horizontale** pour séparer deux parties d'une page. Elle n'a pas de contenu : elle n'a donc pas de balise fermante.

```html
<p>Première partie</p>
<hr>
<p>Deuxième partie</p>
```

Pour remplir une page avec du texte d'exemple, on utilise souvent du **faux texte**. Dans l'éditeur, le raccourci Emmet `lorem` en produit : tape `lorem`, puis la touche Tab. Une fois cet exo réussi, `lorem` est débloqué pour les exos suivants.

## Énoncé
Dans `index.html`, écris **deux paragraphes** séparés par une **ligne horizontale**. Le texte est libre.

## Méthode
- [ ] Utilise deux balises `p`
- [ ] Place une balise `hr` entre les deux paragraphes

## Résultat
- [ ] La page affiche un paragraphe, une ligne horizontale, puis un second paragraphe

## Indice
Les trois éléments se suivent : `<p>…</p>`, puis `<hr>`, puis `<p>…</p>`.

## Tests
```js
assert($$("p").length === 2, "Il faut exactement deux paragraphes (p)");
assert($$("p").every((p) => p.textContent.trim() !== ""), "Chaque paragraphe doit contenir du texte");
assert($$("hr").length === 1, "Il faut une ligne horizontale (hr)");
assert($$("p, hr").map((e) => e.tagName).join(",") === "P,HR,P", "La ligne horizontale doit être entre les deux paragraphes");
```

## Solution: index.html
```html
<p>Première partie de la page.</p>
<hr>
<p>Deuxième partie de la page.</p>
```
