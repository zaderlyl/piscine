## Cours
Pour les formulaires complexes ou les messages longs, HTML propose des balises d'organisation et de saisie multi-lignes :

- `<textarea>` : zone de texte multi-lignes pour les commentaires, avis ou lettres de motivation. Contrairement à `<input>`, elle possède une balise fermante `</textarea>`. On définit sa taille initiale avec les attributs `rows` (nombre de lignes visibles) et `cols` (nombre de colonnes de texte).
- `<fieldset>` : encadre un groupe cohérent de champs (par exemple « Identité », « Adresse de facturation »).
- `<legend>` : donne un titre au groupe, placé obligatoirement en premier enfant direct dans le `<fieldset>`.
- `<button type="submit">` : bouton d'action complet qui peut intégrer du texte et des icônes.

## Énoncé
Dans `index.html`, crée un formulaire de contact structuré :
1. Un cadre `<fieldset>` contenant en premier élément un titre `<legend>`.
2. Une zone de texte multi-lignes `<textarea>` munie d'un attribut `name`, d'un `id` et d'un `<label>` associé.
3. Un bouton `<button>` pour valider le formulaire.

## Méthode
- [ ] Ouvre la balise `<fieldset>`
- [ ] Insère la balise `<legend>` avec le titre du bloc
- [ ] Ajoute le `<label>` et le `<textarea>`
- [ ] Ajoute le `<button>`
- [ ] Ferme le `</fieldset>`

## Résultat
- [ ] La page affiche une section de formulaire encadrée avec un titre de légende et une zone de texte multi-lignes

## Indice
La balise `<textarea>` nécessite obligatoirement sa balise fermante `</textarea>`, même si elle est vide au départ.

## Tests
```js
const fieldset = $("fieldset");
assert(fieldset, "Il faut une balise de regroupement <fieldset>");

const legend = fieldset ? $("legend", fieldset) : null;
assert(legend && legend.textContent.trim().length > 0, "La balise <fieldset> doit comporter un titre <legend>");

const textarea = $("textarea");
assert(textarea, "Il faut une zone de texte multi-lignes <textarea>");
assert(textarea && textarea.getAttribute("name"), "La zone <textarea> doit comporter un attribut name");
assert(textarea && textarea.getAttribute("id"), "La zone <textarea> doit comporter un attribut id");

const idArea = textarea ? textarea.getAttribute("id") : "";
const label = $("label[for='" + idArea + "']");
assert(label, "Il faut un <label> associé au <textarea> via l'attribut for");

const bouton = $("button");
assert(bouton, "Il faut un bouton <button> pour soumettre le formulaire");
```

## Solution: index.html
```html
<form>
  <fieldset>
    <legend>Votre message</legend>

    <p>
      <label for="message">Expliquez votre demande :</label><br>
      <textarea id="message" name="message" rows="5" cols="40"></textarea>
    </p>

    <button type="submit">Envoyer mon message</button>
  </fieldset>
</form>
```
