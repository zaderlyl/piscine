## Cours
Une **base de données** range des informations de façon organisée, pour les retrouver et les modifier facilement : les comptes d'un site, les articles d'une boutique, les notes d'une classe. Presque tous les sites en utilisent une.

### Des tables
Les informations sont rangées dans des **tables**, qui ressemblent à des tableaux. Une base contient souvent plusieurs tables, chacune consacrée à un sujet : une table `eleves`, une table `notes`.

### Des colonnes et des lignes
Dans une table, chaque **colonne** décrit une sorte d'information (le nom, l'âge) et chaque **ligne** est un enregistrement complet (un élève).

### Le schéma
Le **schéma** est le plan de la base : quelles tables, quelles colonnes, de quel type, et comment les tables sont reliées entre elles. On le conçoit avant de remplir la base. Les exercices qui suivent t'apprennent à lire un schéma, avant d'écrire des requêtes SQL pour interroger les données.
