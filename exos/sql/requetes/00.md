## Cours
**SQL** est le langage qui permet de parler à une base de données. Une base range ses informations dans des **tables**, comme des tableaux ; SQL sert à les lire et, plus tard, à les modifier.

### Une requête
Pour poser une question à la base, on écrit une **requête**. Elle se termine par un point-virgule. Les mots-clés (`SELECT`, `FROM`) s'écrivent en majuscules par habitude, ce qui les distingue du reste.

### Lire une table
`SELECT` dit **quoi** afficher, `FROM` dit **dans quelle table**. L'étoile `*` veut dire « toutes les colonnes ».

```sql
SELECT * FROM eleves;
```

Cette requête affiche toute la table `eleves`. Dans les exercices, tu écris ta requête à gauche, tu cliques sur **Exécuter** pour voir le tableau obtenu à droite, puis sur **Vérifier**.
