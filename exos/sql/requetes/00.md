## Cours
**SQL** est le langage qui permet de parler à une base de données. Une base range ses informations dans des **tables**, comme des tableaux. Pour lire une table, on écrit une **requête** : `SELECT` dit quoi afficher, `FROM` dit dans quelle table. L'étoile `*` veut dire « toutes les colonnes ». Une requête se termine par un point-virgule.

```sql
SELECT * FROM table;
```

## Énoncé
La base contient une table `eleves`. Écris une requête qui affiche **toute la table**, puis clique sur **Exécuter** pour voir le résultat et sur **Vérifier** pour valider.

## Indice
La requête a la forme `SELECT ... FROM ...;`. Remplace le premier `...` par ce qui veut dire « toutes les colonnes », et le second par le nom de la table.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2');
```

## Solutions
```sql
SELECT * FROM eleves;
```
```sql
SELECT eleves.* FROM eleves;
```
