## Cours
Avec `INNER JOIN`, une ligne sans correspondance disparaît du résultat. `LEFT JOIN` garde **toutes les lignes de la table de gauche** (celle après `FROM`). Quand il n'y a pas de correspondance, les colonnes de l'autre table valent `NULL` (« rien »).

```sql
SELECT clients.nom, commandes.total
FROM clients LEFT JOIN commandes ON clients.id = commandes.client_id;
```

## Énoncé
La table `eleves` contient `id`, `nom` et `classe`. La table `notes` contient `id`, `eleve_id` (l'élève concerné), `matiere` et `note`. Écris une requête qui affiche le **nom de chaque élève** puis sa **note**, en écrivant les colonnes sous la forme `table.colonne`. **Tous les élèves** doivent apparaître, même ceux qui n'ont aucune note. Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
C'est la même requête qu'avec `INNER JOIN`, mais avec le mot qui garde toutes les lignes de la table de gauche.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, classe TEXT);
CREATE TABLE notes (id INTEGER, eleve_id INTEGER, matiere TEXT, note INTEGER);
INSERT INTO eleves VALUES (1, 'Alice', 'MMI1'), (2, 'Bruno', 'MMI1'), (3, 'Chloé', 'MMI2'), (4, 'David', 'MMI2');
INSERT INTO notes VALUES (1, 1, 'Maths', 15), (2, 1, 'Web', 17), (3, 2, 'Maths', 12), (4, 3, 'Web', 14);
```

## Solutions
```sql
SELECT eleves.nom, notes.note FROM eleves LEFT JOIN notes ON eleves.id = notes.eleve_id;
```
```sql
SELECT eleves.nom, notes.note FROM eleves LEFT JOIN notes ON notes.eleve_id = eleves.id;
```
