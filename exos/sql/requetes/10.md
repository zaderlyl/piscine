## Cours
`COUNT(*)` compte les lignes. Le résultat est une seule ligne, avec le nombre. Avec `AS`, on donne un nom à la colonne du résultat.

```sql
SELECT COUNT(*) AS total FROM table;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui **compte les élèves**, et appelle la colonne du résultat **nb**. Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
Remplace `total` par le nom demandé et `table` par le nom de la table.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT COUNT(*) AS nb FROM eleves;
```
```sql
SELECT COUNT(id) AS nb FROM eleves;
```
