## Cours
`GROUP BY` regroupe les lignes qui ont la même valeur dans une colonne. Avec `COUNT(*)`, on obtient une ligne par groupe, avec le nombre de lignes de chaque groupe. `GROUP BY` se place après `FROM` (et après `WHERE` s'il y en a un).

```sql
SELECT colonne, COUNT(*) AS total FROM table GROUP BY colonne;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche **chaque classe** avec le **nombre d'élèves** qu'elle contient. Appelle la colonne du nombre **nb**. Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
Sélectionne la colonne `classe` et `COUNT(*) AS nb`, puis regroupe avec `GROUP BY classe`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT classe, COUNT(*) AS nb FROM eleves GROUP BY classe;
```
```sql
SELECT classe, COUNT(id) AS nb FROM eleves GROUP BY classe;
```
