## Cours
Ce palier réunit ce que tu as appris : choisir des colonnes avec `SELECT`, filtrer avec `WHERE`, trier avec `ORDER BY` et limiter avec `LIMIT`. Dans une requête, ces mots se placent toujours dans cet ordre.

```sql
SELECT colonnes FROM table WHERE condition ORDER BY colonne LIMIT nombre;
```

Ici, il n'y a pas de consigne de code : seul compte le **tableau obtenu**. Plusieurs requêtes différentes peuvent donner le bon résultat, et elles sont toutes acceptées.

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche le **nom** et l'**âge** des **3 élèves les plus âgés** qui **ne sont pas en classe MMI3**, du plus âgé au plus jeune. Clique sur **Exécuter** pour voir ton tableau, puis sur **Vérifier**.

## Indice
Il te faut un filtre, un tri et une limite, dans cet ordre : `WHERE`, `ORDER BY`, `LIMIT`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 21, 'MMI1'), (6, 'Farid', 20, 'MMI3'), (7, 'Gaëlle', 22, 'MMI3');
```

## Solutions
```sql
SELECT nom, age FROM eleves WHERE classe <> 'MMI3' ORDER BY age DESC LIMIT 3;
```
