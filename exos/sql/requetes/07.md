## Cours
Les données sont souvent réparties dans plusieurs tables. Une **jointure** les relie : `INNER JOIN` ajoute une deuxième table, et `ON` dit quelle colonne de l'une correspond à quelle colonne de l'autre (en général une clé étrangère et la clé primaire qu'elle désigne). Seules les lignes qui se correspondent sont gardées.

Quand deux tables ont une colonne du même nom, on écrit `table.colonne` pour dire de quelle table on parle.

```sql
SELECT clients.nom, commandes.total
FROM clients INNER JOIN commandes ON clients.id = commandes.client_id;
```

## Énoncé
La table `eleves` contient `id`, `nom` et `classe`. La table `notes` contient `id`, `eleve_id` (l'élève concerné), `matiere` et `note`. Écris une requête qui affiche, pour chaque note, le **nom de l'élève** puis la **note**, en écrivant les colonnes sous la forme `table.colonne`. Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
Après `FROM eleves`, ajoute `INNER JOIN notes ON ...` et relie `eleves.id` à la colonne de `notes` qui contient l'identifiant de l'élève.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, classe TEXT);
CREATE TABLE notes (id INTEGER, eleve_id INTEGER, matiere TEXT, note INTEGER);
INSERT INTO eleves VALUES (1, 'Alice', 'MMI1'), (2, 'Bruno', 'MMI1'), (3, 'Chloé', 'MMI2');
INSERT INTO notes VALUES (1, 1, 'Maths', 15), (2, 1, 'Web', 17), (3, 2, 'Maths', 12), (4, 3, 'Web', 14);
```

## Solutions
```sql
SELECT eleves.nom, notes.note FROM eleves INNER JOIN notes ON eleves.id = notes.eleve_id;
```
```sql
SELECT eleves.nom, notes.note FROM eleves INNER JOIN notes ON notes.eleve_id = eleves.id;
```
```sql
SELECT eleves.nom, notes.note FROM eleves JOIN notes ON eleves.id = notes.eleve_id;
```
```sql
SELECT eleves.nom, notes.note FROM eleves JOIN notes ON notes.eleve_id = eleves.id;
```
