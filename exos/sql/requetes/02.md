## Cours
Pour lire des données dans une table, on écrit une **requête** SQL. `SELECT` dit quelles colonnes afficher, `FROM` dit dans quelle table. Une requête se termine par un point-virgule.

```sql
SELECT colonne1, colonne2 FROM table;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche **uniquement le nom** de tous les élèves, puis clique sur **Exécuter** pour voir le résultat et sur **Vérifier** pour valider.

## Indice
Remplace `colonne` par le nom de la colonne à afficher et `table` par le nom de la table.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2');
```

## Solutions
```sql
SELECT nom FROM eleves;
```
```sql
SELECT eleves.nom FROM eleves;
```
