## Cours
`WHERE` garde seulement les lignes qui respectent une **condition**. Il se place après `FROM`. On compare avec `=`, `>`, `<`, `>=`, `<=` ou `<>` (différent de). Un texte s'écrit entre apostrophes, un nombre s'écrit tel quel.

```sql
SELECT nom FROM eleves WHERE age > 17;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche le **nom** des élèves de la classe **MMI1**, puis clique sur **Exécuter** et sur **Vérifier**.

## Indice
La condition a la forme `WHERE colonne = 'valeur'`. Le texte `MMI1` va entre apostrophes.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT nom FROM eleves WHERE classe = 'MMI1';
```
```sql
SELECT eleves.nom FROM eleves WHERE eleves.classe = 'MMI1';
```
