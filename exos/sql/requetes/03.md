## Cours
On peut mettre plusieurs conditions dans un même `WHERE`. Avec `AND`, **les deux** conditions doivent être vraies. Avec `OR`, **au moins une** doit être vraie.

```sql
SELECT nom FROM eleves WHERE age >= 18 AND classe = 'MMI2';
SELECT nom FROM eleves WHERE classe = 'MMI2' OR classe = 'MMI3';
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche le **nom** des élèves de la classe **MMI1** qui ont **18 ans ou plus**, puis clique sur **Exécuter** et sur **Vérifier**.

## Indice
Écris les deux conditions dans le `WHERE`, reliées par le mot qui exige que les deux soient vraies.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT nom FROM eleves WHERE classe = 'MMI1' AND age >= 18;
```
```sql
SELECT nom FROM eleves WHERE age >= 18 AND classe = 'MMI1';
```
```sql
SELECT nom FROM eleves WHERE classe = 'MMI1' AND age > 17;
```
```sql
SELECT nom FROM eleves WHERE age > 17 AND classe = 'MMI1';
```
