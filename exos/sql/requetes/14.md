## Cours
`SUM(colonne)` additionne les valeurs d'une colonne et `AVG(colonne)` en calcule la moyenne. Comme `COUNT`, ces fonctions renvoient **une seule ligne**. On peut en mettre plusieurs dans le même `SELECT`, séparées par des virgules, et nommer chaque colonne avec `AS`.

```sql
SELECT SUM(colonne) AS total, AVG(colonne) AS moyenne FROM table;
```

## Énoncé
La table `notes` contient les colonnes `id`, `eleve_id`, `matiere` et `note`. Écris une requête qui affiche, **dans cet ordre**, la **somme** des notes (colonne **total**) puis leur **moyenne** (colonne **moyenne**). Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
Les deux fonctions s'écrivent dans le même `SELECT`, séparées par une virgule. Chacune prend la colonne `note` entre parenthèses, et `AS` donne son nom à la colonne.

## Base
```sql
CREATE TABLE notes (id INTEGER, eleve_id INTEGER, matiere TEXT, note INTEGER);
INSERT INTO notes VALUES (1, 1, 'Maths', 15), (2, 1, 'Web', 12), (3, 2, 'Maths', 18), (4, 2, 'Web', 9), (5, 3, 'Maths', 14), (6, 3, 'Web', 16);
```

## Solutions
```sql
SELECT SUM(note) AS total, AVG(note) AS moyenne FROM notes;
```
