## Cours
Ce palier réunit les fonctions de calcul et ce que tu as appris avant : `GROUP BY` regroupe, `HAVING` filtre les groupes, `ORDER BY` trie le résultat. Dans une requête, l'ordre est toujours le même.

```sql
SELECT colonne, AVG(valeur) AS moyenne FROM table GROUP BY colonne HAVING AVG(valeur) >= 10 ORDER BY moyenne DESC;
```

Ici, il n'y a pas de consigne de code : seul compte le **tableau obtenu**. Plusieurs requêtes différentes peuvent donner le bon résultat, et elles sont toutes acceptées.

## Énoncé
La table `notes` contient les colonnes `id`, `eleve_id`, `matiere` et `note`. Écris une requête qui affiche, **dans cet ordre**, la **matière**, sa **moyenne** (colonne **moyenne**) puis son **nombre de notes** (colonne **nb**), en ne gardant que les matières qui ont **au moins 3 notes**, de la **meilleure** moyenne à la **moins bonne**. Clique sur **Exécuter** pour voir ton tableau, puis sur **Vérifier**.

## Indice
Il te faut un regroupement, un filtre sur les groupes et un tri, dans cet ordre : `GROUP BY`, `HAVING`, `ORDER BY`. Tu peux trier sur `moyenne`.

## Base
```sql
CREATE TABLE notes (id INTEGER, eleve_id INTEGER, matiere TEXT, note INTEGER);
INSERT INTO notes VALUES (1, 1, 'Maths', 15), (2, 2, 'Maths', 12), (3, 3, 'Maths', 18), (4, 1, 'Web', 17), (5, 2, 'Web', 9), (6, 3, 'Web', 14), (7, 4, 'Web', 16), (8, 1, 'Anglais', 11), (9, 2, 'Anglais', 13);
```

## Solutions
```sql
SELECT matiere, AVG(note) AS moyenne, COUNT(*) AS nb FROM notes GROUP BY matiere HAVING COUNT(*) >= 3 ORDER BY moyenne DESC;
```
