## Cours
Ce palier réunit la jointure et ce que tu as appris avant : `INNER JOIN ... ON ...` relie deux tables, puis `WHERE` filtre et `ORDER BY` trie. Dans une requête, l'ordre est toujours le même.

```sql
SELECT colonnes FROM table1 INNER JOIN table2 ON condition WHERE condition ORDER BY colonne;
```

Ici, il n'y a pas de consigne de code : seul compte le **tableau obtenu**. Plusieurs requêtes différentes peuvent donner le bon résultat, et elles sont toutes acceptées.

## Énoncé
La table `eleves` contient `id`, `nom` et `classe`. La table `notes` contient `id`, `eleve_id` (l'élève concerné), `matiere` et `note`. Écris une requête qui affiche le **nom** de chaque élève et sa **note en Maths**, de la **meilleure** à la **moins bonne**. Clique sur **Exécuter** pour voir ton tableau, puis sur **Vérifier**.

## Indice
Il te faut une jointure entre les deux tables, un filtre sur la matière, puis un tri : `INNER JOIN`, `WHERE`, `ORDER BY`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, classe TEXT);
CREATE TABLE notes (id INTEGER, eleve_id INTEGER, matiere TEXT, note INTEGER);
INSERT INTO eleves VALUES (1, 'Alice', 'MMI1'), (2, 'Bruno', 'MMI1'), (3, 'Chloé', 'MMI2'), (4, 'David', 'MMI2'), (5, 'Emma', 'MMI3');
INSERT INTO notes VALUES (1, 1, 'Maths', 15), (2, 1, 'Web', 17), (3, 2, 'Maths', 12), (4, 2, 'Web', 9), (5, 3, 'Maths', 18), (6, 3, 'Web', 14), (7, 4, 'Web', 11);
```

## Solutions
```sql
SELECT eleves.nom, notes.note FROM eleves INNER JOIN notes ON eleves.id = notes.eleve_id WHERE notes.matiere = 'Maths' ORDER BY notes.note DESC;
```
