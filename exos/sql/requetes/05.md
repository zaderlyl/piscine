## Cours
`LIMIT` garde seulement les premières lignes du résultat. Il se place tout à la fin de la requête, après `ORDER BY`. Avec un tri, il permet de trouver le plus grand, le plus petit, ou un « top ».

```sql
SELECT nom FROM eleves ORDER BY age DESC LIMIT 3;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche le **nom** de **l'élève le plus âgé**, une seule ligne, puis clique sur **Exécuter** et sur **Vérifier**.

## Indice
Trie les élèves du plus âgé au plus jeune, puis garde uniquement la première ligne avec `LIMIT`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT nom FROM eleves ORDER BY age DESC LIMIT 1;
```
```sql
SELECT eleves.nom FROM eleves ORDER BY eleves.age DESC LIMIT 1;
```
