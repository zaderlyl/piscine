## Cours
`ORDER BY` trie les lignes du résultat selon une colonne. Il se place à la fin de la requête. Par défaut le tri va du plus petit au plus grand (`ASC`). Avec `DESC`, il va du plus grand au plus petit.

```sql
SELECT nom FROM eleves ORDER BY nom;
SELECT nom FROM eleves ORDER BY age DESC;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche le **nom** et l'**âge** des élèves, du **plus âgé au plus jeune**, puis clique sur **Exécuter** et sur **Vérifier**.

## Indice
Sélectionne les deux colonnes, puis ajoute `ORDER BY colonne` suivi du mot qui inverse le tri.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 17, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 18, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT nom, age FROM eleves ORDER BY age DESC;
```
```sql
SELECT eleves.nom, eleves.age FROM eleves ORDER BY eleves.age DESC;
```
