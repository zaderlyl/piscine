## Cours
`WHERE` filtre les lignes **avant** le regroupement. Pour filtrer les **groupes** eux-mêmes, par exemple ne garder que ceux qui contiennent plus d'une ligne, on utilise `HAVING`, placé **après** `GROUP BY`. Sa condition porte sur le résultat d'une fonction comme `COUNT(*)`.

```sql
SELECT colonne, COUNT(*) AS total FROM table GROUP BY colonne HAVING COUNT(*) > 1;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche les **classes** qui ont **plus de 2 élèves**, avec leur nombre d'élèves (colonne **nb**). Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
Regroupe par classe avec `GROUP BY`, puis ajoute `HAVING COUNT(*) > 2` juste après. Le `HAVING` se place avant la fin de la requête, après le `GROUP BY`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 21, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT classe, COUNT(*) AS nb FROM eleves GROUP BY classe HAVING COUNT(*) > 2;
```
```sql
SELECT classe, COUNT(*) AS nb FROM eleves GROUP BY classe HAVING COUNT(id) > 2;
```
```sql
SELECT classe, COUNT(*) AS nb FROM eleves GROUP BY classe HAVING nb > 2;
```
```sql
SELECT classe, COUNT(*) AS nb FROM eleves GROUP BY classe HAVING COUNT(*) >= 3;
```
