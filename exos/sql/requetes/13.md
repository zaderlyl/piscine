## Cours
Ce palier réunit le comptage et ce que tu as appris avant : `WHERE` filtre les lignes **avant** le regroupement, `GROUP BY` regroupe, `ORDER BY` trie les groupes. Dans une requête, l'ordre est toujours le même.

```sql
SELECT colonne, COUNT(*) AS total FROM table WHERE condition GROUP BY colonne ORDER BY total DESC;
```

Ici, il n'y a pas de consigne de code : seul compte le **tableau obtenu**. Plusieurs requêtes différentes peuvent donner le bon résultat, et elles sont toutes acceptées.

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche **chaque classe** avec le **nombre de ses élèves de 18 ans ou plus**, de la classe qui en a **le plus** à celle qui en a **le moins**. Appelle la colonne du nombre **nb**. Clique sur **Exécuter** pour voir ton tableau, puis sur **Vérifier**.

## Indice
Il te faut un filtre, un regroupement et un tri, dans cet ordre : `WHERE`, `GROUP BY`, `ORDER BY`. Tu peux trier sur `nb`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 19, 'MMI1'), (4, 'David', 20, 'MMI1'), (5, 'Emma', 18, 'MMI2'), (6, 'Farid', 21, 'MMI2'), (7, 'Gaëlle', 17, 'MMI2'), (8, 'Hugo', 19, 'MMI3'), (9, 'Inès', 16, 'MMI3');
```

## Solutions
```sql
SELECT classe, COUNT(*) AS nb FROM eleves WHERE age >= 18 GROUP BY classe ORDER BY nb DESC;
```
