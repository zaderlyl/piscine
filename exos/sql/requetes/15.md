## Cours
`MIN(colonne)` renvoie la plus petite valeur d'une colonne et `MAX(colonne)` la plus grande. Elles fonctionnent sur des nombres, mais aussi sur des textes (ordre alphabétique). Comme les autres fonctions de calcul, elles renvoient **une seule ligne**.

```sql
SELECT MIN(colonne) AS plus_petit, MAX(colonne) AS plus_grand FROM table;
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Écris une requête qui affiche, **dans cet ordre**, l'âge du **plus jeune** élève (colonne **jeune**) puis celui du **plus âgé** (colonne **age_max**). Clique sur **Exécuter** pour voir le résultat, puis sur **Vérifier**.

## Indice
`MIN` donne la plus petite valeur et `MAX` la plus grande. Les deux se placent dans le même `SELECT`, séparées par une virgule, chacune avec son `AS`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2'), (5, 'Emma', 21, 'MMI1'), (6, 'Farid', 20, 'MMI3');
```

## Solutions
```sql
SELECT MIN(age) AS jeune, MAX(age) AS age_max FROM eleves;
```
