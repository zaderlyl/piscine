## Cours
`INSERT INTO` ajoute une nouvelle ligne dans une table : on donne le nom de la table, les colonnes, puis les valeurs dans le même ordre. Un texte s'écrit entre apostrophes, un nombre s'écrit tel quel.

```sql
INSERT INTO table (colonne1, colonne2) VALUES (valeur1, valeur2);
```

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Ajoute l'élève **Gaëlle**, **19 ans**, de la classe **MMI3**, avec l'identifiant **5**. Clique sur **Exécuter** pour voir la table, puis sur **Vérifier**.

## Indice
Écris `INSERT INTO eleves`, puis la liste des colonnes entre parenthèses, puis `VALUES` suivi des valeurs dans le même ordre.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2');
```

## Solutions
```sql
INSERT INTO eleves (id, nom, age, classe) VALUES (5, 'Gaëlle', 19, 'MMI3');
```
```sql
INSERT INTO eleves VALUES (5, 'Gaëlle', 19, 'MMI3');
```
