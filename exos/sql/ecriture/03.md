## Cours
`DELETE FROM` supprime des lignes d'une table. `WHERE` choisit les lignes à supprimer.

```sql
DELETE FROM table WHERE condition;
```

**Attention :** sans `WHERE`, **toutes** les lignes de la table sont supprimées.

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Supprime les élèves **de moins de 18 ans**, sans toucher aux autres. Clique sur **Exécuter** pour voir la table, puis sur **Vérifier**.

## Indice
Écris `DELETE FROM eleves` puis une condition `WHERE` sur la colonne `age`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2');
```

## Solutions
```sql
DELETE FROM eleves WHERE age < 18;
```
```sql
DELETE FROM eleves WHERE age <= 17;
```
