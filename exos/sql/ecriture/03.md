## Cours
Ce palier réunit les trois requêtes d'écriture : `INSERT INTO` ajoute une ligne, `UPDATE` en modifie, `DELETE FROM` en supprime. Tu peux écrire **plusieurs requêtes** à la suite, chacune terminée par un point-virgule : elles s'exécutent dans l'ordre.

Ici, il n'y a pas de consigne de code : seul compte le **contenu des tables** une fois tes requêtes exécutées. Plusieurs façons d'y arriver sont acceptées.

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. Effectue ces trois changements :
1. ajoute l'élève **Gaëlle**, 19 ans, classe MMI3, identifiant 5 ;
2. **Bruno** a maintenant 19 ans ;
3. **Chloé** quitte la formation : supprime sa ligne.

Clique sur **Exécuter** pour voir la table, puis sur **Vérifier**.

## Indice
Il te faut trois requêtes, dans n'importe quel ordre : une avec `INSERT INTO`, une avec `UPDATE` et une avec `DELETE FROM`. Pense au `WHERE` pour les deux dernières.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2');
```

## Solutions
```sql
INSERT INTO eleves (id, nom, age, classe) VALUES (5, 'Gaëlle', 19, 'MMI3');
UPDATE eleves SET age = 19 WHERE nom = 'Bruno';
DELETE FROM eleves WHERE nom = 'Chloé';
```
