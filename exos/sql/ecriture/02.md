## Cours
`UPDATE` change les valeurs de lignes qui existent déjà. `SET` donne la nouvelle valeur d'une colonne, et `WHERE` choisit les lignes à modifier.

```sql
UPDATE table SET colonne = valeur WHERE condition;
```

**Attention :** sans `WHERE`, **toutes** les lignes de la table sont modifiées.

## Énoncé
La table `eleves` contient les colonnes `id`, `nom`, `age` et `classe`. **Bruno** passe dans la classe **MMI2**. Écris la requête qui modifie sa ligne, sans toucher aux autres élèves. Clique sur **Exécuter** pour voir la table, puis sur **Vérifier**.

## Indice
Modifie la colonne `classe` avec `SET`, et limite la modification à Bruno avec `WHERE`.

## Base
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
INSERT INTO eleves VALUES (1, 'Alice', 17, 'MMI1'), (2, 'Bruno', 18, 'MMI1'), (3, 'Chloé', 16, 'MMI2'), (4, 'David', 19, 'MMI2');
```

## Solutions
```sql
UPDATE eleves SET classe = 'MMI2' WHERE nom = 'Bruno';
```
```sql
UPDATE eleves SET classe = 'MMI2' WHERE id = 2;
```
