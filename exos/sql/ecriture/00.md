## Cours
Jusqu'ici, tu as **lu** une base de données avec `SELECT`. Une requête peut aussi la **modifier**. Il y a trois requêtes d'écriture :

- `INSERT` **ajoute** une nouvelle ligne dans une table ;
- `UPDATE` **modifie** des lignes qui existent déjà ;
- `DELETE` **supprime** des lignes.

### Pas de tableau en retour
Une requête d'écriture n'affiche pas de résultat : elle change le contenu des tables. Après avoir cliqué sur **Exécuter**, tu vois donc le contenu des tables *après* ta requête, et c'est lui qui est vérifié.

### Attention à `WHERE`
`UPDATE` et `DELETE` agissent sur **toutes** les lignes de la table si on ne les restreint pas. On ajoute presque toujours un `WHERE`, comme pour `SELECT`, pour ne toucher que les lignes voulues.

Dans les exercices suivants, tu vas utiliser chacune de ces trois requêtes, puis les combiner.
