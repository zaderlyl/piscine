## Cours
Pour déclarer une clé primaire, écris `PRIMARY KEY` juste après le type de la colonne concernée. Le reste de la requête ne change pas.

```sql
CREATE TABLE produits (
  reference INTEGER PRIMARY KEY,
  nom TEXT
);
```

## Énoncé
Crée la table `eleves` avec ces colonnes, **dans cet ordre** : `id` (`INTEGER`, **clé primaire**), `nom` (`TEXT`), `age` (`INTEGER`) et `classe` (`TEXT`). Clique sur **Exécuter** pour voir la structure, puis sur **Vérifier**.

## Indice
Reprends ton `CREATE TABLE` de l'exercice précédent et ajoute `PRIMARY KEY` après le type de la colonne `id`.

## Base
```sql
-- Aucune table au départ.
```

## Solutions
```sql
CREATE TABLE eleves (id INTEGER PRIMARY KEY, nom TEXT, age INTEGER, classe TEXT);
```
