## Cours
Une clé étrangère se déclare à la fin de la liste des colonnes : `FOREIGN KEY (colonne) REFERENCES table(colonne_visée)`. La colonne visée est la clé primaire de l'autre table, qui doit déjà exister.

```sql
CREATE TABLE commandes (
  id INTEGER PRIMARY KEY,
  client_id INTEGER,
  FOREIGN KEY (client_id) REFERENCES clients(id)
);
```

## Énoncé
La table `eleves` existe déjà. Crée la table `notes` avec ces colonnes, **dans cet ordre** : `id` (`INTEGER`, **clé primaire**), `eleve_id` (`INTEGER`), `matiere` (`TEXT`) et `note` (`INTEGER`). La colonne `eleve_id` est une **clé étrangère** vers `eleves(id)`. Clique sur **Exécuter** pour voir la structure des deux tables, puis sur **Vérifier**.

## Indice
Écris les quatre colonnes comme d'habitude, puis, avant la parenthèse fermante, ajoute une ligne `FOREIGN KEY (eleve_id) REFERENCES eleves(id)`, séparée de la colonne précédente par une virgule.

## Base
```sql
CREATE TABLE eleves (id INTEGER PRIMARY KEY, nom TEXT, age INTEGER, classe TEXT);
```

## Solutions
```sql
CREATE TABLE notes (id INTEGER PRIMARY KEY, eleve_id INTEGER, matiere TEXT, note INTEGER, FOREIGN KEY (eleve_id) REFERENCES eleves(id));
```
