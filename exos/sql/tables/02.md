## Cours
`CREATE TABLE` crée une table : on donne son nom, puis, entre parenthèses, chaque colonne avec son type, séparées par des virgules. Une requête se termine par un point-virgule.

```sql
CREATE TABLE produits (
  nom TEXT,
  stock INTEGER
);
```

Après **Exécuter**, tu vois la structure de la table que tu viens de créer.

## Énoncé
Crée la table `eleves` avec ces colonnes, **dans cet ordre** : `id` (`INTEGER`), `nom` (`TEXT`), `age` (`INTEGER`) et `classe` (`TEXT`). Clique sur **Exécuter** pour voir la structure, puis sur **Vérifier**.

## Indice
Après `CREATE TABLE eleves`, ouvre une parenthèse, écris chaque colonne suivie de son type, sépare-les par des virgules et ferme la parenthèse.

## Base
```sql
-- Aucune table au départ.
```

## Solutions
```sql
CREATE TABLE eleves (id INTEGER, nom TEXT, age INTEGER, classe TEXT);
```
