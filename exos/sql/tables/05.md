## Cours
Pour relier deux tables, une colonne de l'une contient la clé primaire de l'autre : c'est une **clé étrangère**. En SQL, on la déclare à la fin de la liste des colonnes avec `FOREIGN KEY (colonne) REFERENCES table(colonne_visée)`.

```sql
CREATE TABLE commandes (
  id INTEGER PRIMARY KEY,
  client_id INTEGER,
  FOREIGN KEY (client_id) REFERENCES clients(id)
);
```

## Énoncé
Voici les tables `eleves` et `notes`. Pour chaque colonne de `notes`, choisis si elle est la clé **PRIMARY KEY**, une clé **FOREIGN KEY** vers `eleves`, ou **aucune** des deux. Puis indique, sous la clé étrangère, la colonne qu'elle **référence**. Clique ensuite sur **Vérifier**. Dans l'exercice suivant, tu écriras toi-même le `CREATE TABLE`.

## Indice
La clé étrangère contient des valeurs qu'on retrouve dans la colonne `id` de `eleves`. La table qu'elle référence est celle qui contient ces valeurs.
