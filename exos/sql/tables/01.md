## Cours
Quand on crée une table, on donne un **type** à chaque colonne. En SQL, deux types suffisent pour commencer : `INTEGER` pour un nombre entier (un identifiant, un âge) et `TEXT` pour du texte (un nom, une classe). Le type s'écrit après le nom de la colonne.

```sql
CREATE TABLE produits (
  nom TEXT,
  stock INTEGER
);
```

## Énoncé
Voici la table `eleves`. Pour chaque colonne, choisis le type SQL qui correspond à ses valeurs (`INTEGER` ou `TEXT`), puis clique sur **Vérifier**. Dans l'exercice suivant, tu écriras toi-même le `CREATE TABLE` de cette table.
