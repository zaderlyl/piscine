## Cours
En SQL, on déclare la clé primaire d'une colonne en écrivant `PRIMARY KEY` après son type. Une seule colonne identifie chaque ligne : celle dont les valeurs sont **uniques**.

```sql
CREATE TABLE produits (
  reference INTEGER PRIMARY KEY,
  nom TEXT
);
```

## Énoncé
Voici la table `eleves`, avec le type de chaque colonne. Pour chaque colonne, choisis si elle reçoit **PRIMARY KEY** ou **aucune** contrainte, puis clique sur **Vérifier**. Dans l'exercice suivant, tu écriras toi-même le `CREATE TABLE`.

## Indice
Une clé primaire n'a jamais deux fois la même valeur. Cherche les valeurs qui se répètent : ces colonnes-là ne peuvent pas être la clé.

colonnes: id  nom  age  classe
