## Cours
Avant d'envoyer un formulaire, on vérifie ce que l'utilisateur a saisi, et on lui explique ce qui ne va pas. C'est la **validation**.

Dans l'écouteur `submit`, on lit chaque champ avec sa propriété `.value` (toujours du texte), et on bloque l'envoi avec `e.preventDefault()`. Pour nettoyer une saisie, `.trim()` retire les espaces au début et à la fin :

```js
formulaire.addEventListener("submit", (e) => {
  e.preventDefault();
  const nom = champNom.value.trim();

  if (nom.length < 2) {
    champNom.classList.add("invalide");           // met le champ en évidence
    messageNom.textContent = "Nom trop court.";   // explique le problème
  } else {
    champNom.classList.remove("invalide");        // tout va bien : on nettoie
    messageNom.textContent = "";
  }
});
```

- `texte.length` : le nombre de caractères.
- `texte.includes("@")` : vrai si le texte contient un `@`.
- Un bon message d'erreur dit **ce qu'il faut corriger**, pas seulement « erreur ».

## Énoncé
Un formulaire d'inscription est affiché dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le formulaire a l'identifiant `formulaire`
- les champs ont pour identifiants `pseudo` et `email`
- sous chaque champ, un paragraphe vide est prévu pour l'erreur : `erreur-pseudo` et `erreur-email`
- un paragraphe `statut`, vide au départ, est prévu pour la confirmation
- la classe `invalide` est déjà stylée : elle colore un champ en rouge

Dans `script.js`, à l'envoi du formulaire (n'oublie pas `e.preventDefault()`), vérifie :
1. **Pseudo** : il doit contenir au moins 3 caractères (espaces de début et de fin retirés avec `trim()`). Sinon, affiche « Le pseudo doit contenir au moins 3 caractères. » dans `#erreur-pseudo` et ajoute la classe `invalide` au champ.
2. **Email** : il doit contenir un `@`. Sinon, affiche « Entre une adresse email valide. » dans `#erreur-email` et ajoute la classe `invalide` au champ.
3. Quand un champ est correct, vide son message d'erreur et retire sa classe `invalide`.
4. Si les deux champs sont corrects, écris « Inscription réussie ! » dans `#statut`. Sinon, laisse `#statut` vide.

## Méthode
- [ ] Écoute `submit` sur `#formulaire` et appelle `e.preventDefault()`
- [ ] Lis `pseudo.value.trim()` et `email.value.trim()`
- [ ] Teste `.length` et `.includes("@")`
- [ ] Affiche ou efface les messages avec `textContent`, et gère la classe `invalide` avec `classList.add` / `classList.remove`

## Résultat
- [ ] Un pseudo trop court ou un email sans `@` affiche un message précis et met le champ en rouge
- [ ] Une fois les champs corrigés, les erreurs disparaissent et « Inscription réussie ! » s'affiche

## Indice
Calcule d'abord deux booléens, par exemple `const pseudoValide = pseudo.value.trim().length >= 3;`, puis utilise-les pour afficher les messages et décider du statut.

## Solution: script.js
```js
const formulaire = document.querySelector("#formulaire");
const pseudo = document.querySelector("#pseudo");
const email = document.querySelector("#email");
const erreurPseudo = document.querySelector("#erreur-pseudo");
const erreurEmail = document.querySelector("#erreur-email");
const statut = document.querySelector("#statut");

formulaire.addEventListener("submit", (e) => {
  e.preventDefault();

  const pseudoValide = pseudo.value.trim().length >= 3;
  const emailValide = email.value.trim().includes("@");

  if (pseudoValide) {
    pseudo.classList.remove("invalide");
    erreurPseudo.textContent = "";
  } else {
    pseudo.classList.add("invalide");
    erreurPseudo.textContent = "Le pseudo doit contenir au moins 3 caractères.";
  }

  if (emailValide) {
    email.classList.remove("invalide");
    erreurEmail.textContent = "";
  } else {
    email.classList.add("invalide");
    erreurEmail.textContent = "Entre une adresse email valide.";
  }

  statut.textContent = pseudoValide && emailValide ? "Inscription réussie !" : "";
});
```
