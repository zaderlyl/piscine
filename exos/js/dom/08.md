## Cours
L'API native HTML5 `Audio` permet d'émettre des bruitages et effets sonores en quelques lignes sans dépendance externe :
```js
const son = new Audio("chemin/vers/son.mp3");
son.play();
```
On peut aussi utiliser un son court encodé en base64 pour ne pas dépendre de fichiers distants.

Exemple :
```js
const bip = new Audio("data:audio/wav;base64,UklGRiQAAABXQVZFZm10IBAAAAABAAEAQB8AAEAfAAABAAgAZGF0YQAAAAA=");
bip.play();
```

## Énoncé
Un bouton « Jouer le son » est affiché dans l'aperçu. Tu ne vois pas son code, mais le bouton a l'identifiant `btn-son`.

Dans `script.js` :
1. Crée un objet `Audio` stocké dans la variable globale `window.lecteurSon` :
   `window.lecteurSon = new Audio("data:audio/wav;base64,UklGRiQAAABXQVZFZm10IBAAAAABAAEAQB8AAEAfAAABAAgAZGF0YQAAAAA=");`
2. Attache un écouteur de clic sur `#btn-son` qui déclenche la lecture avec `window.lecteurSon.play()`.

## Méthode
- [ ] Crée l'instance avec `new Audio(...)`
- [ ] Attache un événement `click` sur le bouton
- [ ] Appelle `.play()` sur l'instance

## Résultat
- [ ] `window.lecteurSon` est un objet `Audio`
- [ ] Le clic sur `#btn-son` déclenche `.play()`

## Indice
Affecte `new Audio(...)` à `window.lecteurSon`, puis appelle `window.lecteurSon.play()` dans le gestionnaire de clic.

## Tests
```js
assert(window.lecteurSon && typeof window.lecteurSon.play === "function", "Range un objet new Audio(...) dans window.lecteurSon");
let joue = false;
if (window.lecteurSon) {
  const originalPlay = window.lecteurSon.play;
  window.lecteurSon.play = function () { joue = true; return Promise.resolve(); };
  click("#btn-son");
  window.lecteurSon.play = originalPlay;
}
assert(joue, "Appelle window.lecteurSon.play() au clic sur #btn-son");
```

## Solution: script.js
```js
window.lecteurSon = new Audio("data:audio/wav;base64,UklGRiQAAABXQVZFZm10IBAAAAABAAEAQB8AAEAfAAABAAgAZGF0YQAAAAA=");
const bouton = document.querySelector("#btn-son");
bouton.addEventListener("click", () => {
  window.lecteurSon.play();
});
```
