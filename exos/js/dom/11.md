## Cours
Une page web va souvent chercher ses données auprès d'un serveur (une **API**). Cette demande prend du temps : JavaScript ne bloque pas la page pendant l'attente, c'est de l'**asynchrone**.

`fetch(url)` envoie la demande et renvoie une **promesse**. Le mot-clé `await` met la fonction en pause jusqu'à la réponse, et `await` ne s'utilise que dans une fonction déclarée `async` :

```js
async function charger() {
  const reponse = await fetch("/api/articles"); // la réponse du serveur
  const articles = await reponse.json();        // son contenu, converti en objets JS
  console.log(articles);
}
```

- `await fetch(...)` : attend la réponse du serveur.
- `await reponse.json()` : attend la lecture du contenu JSON (c'est aussi asynchrone).
- Une fonction qui contient `await` doit s'écrire `async function` ou `async () => { ... }`.

## Énoncé
Une page « Notre équipe » est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ce qu'il faut savoir :
- le bouton a l'identifiant `btn-charger`, la liste vide a l'identifiant `liste`
- les données de l'équipe se récupèrent avec `fetch("/api/equipe")` (un serveur simulé répond après un court instant). La réponse est un tableau d'objets `{ nom, role }`

Dans `script.js` :
1. Attache un écouteur de clic sur `#btn-charger`, avec une fonction `async`.
2. Dans cette fonction, récupère les données avec `await fetch("/api/equipe")` puis `await reponse.json()`.
3. Pour chaque membre, ajoute à `#liste` un `<li>` dont le texte est `nom - role` (par exemple `Ada - Développeuse`).

## Méthode
- [ ] Déclare l'écouteur avec `async () => { ... }`
- [ ] `const reponse = await fetch("/api/equipe");`
- [ ] `const equipe = await reponse.json();`
- [ ] Crée les `<li>` avec `document.createElement("li")`, `textContent` et `appendChild`

## Résultat
- [ ] Au clic, la liste affiche les trois membres de l'équipe

## Indice
`await` n'est permis que dans une fonction `async`. Pour chaque membre : `const li = document.createElement("li"); li.textContent = ...; liste.appendChild(li);`

## Solution: script.js
```js
const bouton = document.querySelector("#btn-charger");
const liste = document.querySelector("#liste");

bouton.addEventListener("click", async () => {
  const reponse = await fetch("/api/equipe");
  const equipe = await reponse.json();
  for (const membre of equipe) {
    const li = document.createElement("li");
    li.textContent = `${membre.nom} - ${membre.role}`;
    liste.appendChild(li);
  }
});
```
