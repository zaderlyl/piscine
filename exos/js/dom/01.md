## Cours
Pour agir sur un élément de la page, JavaScript doit d'abord le **retrouver**. Quand l'élément possède un `id`, la méthode la plus directe est `document.getElementById("id")` : elle renvoie l'élément, ou `null` s'il n'existe pas.

```js
const titre = document.getElementById("mon-titre");
```

Attention : on écrit l'identifiant **sans** `#`. `getElementById("mon-titre")` est correct, `getElementById("#mon-titre")` ne trouvera rien.

Il existe d'autres méthodes plus anciennes, comme `getElementsByClassName("classe")` ou `getElementsByTagName("balise")`, qui renvoient plusieurs éléments. On les rencontre dans du vieux code, mais on utilise aujourd'hui surtout `querySelector`, vu dans l'exercice suivant.

## Page
```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <style>

    .carte { background: #fff; padding: 32px 40px; border-radius: 16px; box-shadow: 0 10px 30px rgba(31, 41, 55, .12); max-width: 360px; text-align: center; }
    .carte h1 { margin: 0 0 8px; font-size: 1.6rem; }
    .carte p { margin: 0 0 24px; color: #6b7280; line-height: 1.5; }
    .carte button { background: #4f46e5; color: #fff; border: 0; padding: 12px 24px; border-radius: 999px; font-size: 1rem; cursor: pointer; }
    .carte button:hover { background: #4338ca; }

<body>
  <main class="carte">
    <h1 id="titre">Camille Durand</h1>
    <p id="description">Étudiante en MMI, passionnée de design d'interface et de création web.</p>
    <button id="bouton-contact">Me contacter</button>
  </main>
  <script src="script.js"></script>
</body>
</html>
```

## Énoncé
Une carte de profil est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le titre a l'identifiant `titre`
- le paragraphe a l'identifiant `description`
- le bouton a l'identifiant `bouton-contact`

Dans `script.js` :
1. Retrouve le titre avec `getElementById` et stocke-le dans `window.titre`.
2. Retrouve le paragraphe et stocke-le dans `window.description`.
3. Retrouve le bouton et stocke-le dans `window.bouton`.

## Méthode
- [ ] Utilise `document.getElementById("...")`
- [ ] Écris l'identifiant sans `#`

## Résultat
- [ ] `window.titre` contient le titre
- [ ] `window.description` contient le paragraphe
- [ ] `window.bouton` contient le bouton

## Indice
Le modèle est `window.nom = document.getElementById("identifiant");`

## Tests
```js
assert(window.titre, "Stocke le titre dans window.titre avec document.getElementById");
assert(window.titre === $("#titre"), "Retrouve l'élément d'identifiant titre, sans le # devant");
assert(window.description, "Stocke le paragraphe dans window.description avec document.getElementById");
assert(window.description === $("#description"), "Retrouve l'élément d'identifiant description, sans le # devant");
assert(window.bouton, "Stocke le bouton dans window.bouton avec document.getElementById");
assert(window.bouton === $("#bouton-contact"), "Retrouve l'élément d'identifiant bouton-contact, sans le # devant");
```

## Solution: script.js
```js
window.titre = document.getElementById("titre");
window.description = document.getElementById("description");
window.bouton = document.getElementById("bouton-contact");
```
