## Cours
Un utilisateur n'agit pas qu'à la souris : il utilise aussi le clavier. L'événement `keydown` se déclenche **chaque fois qu'une touche est enfoncée**. On l'écoute souvent sur `document`, pour réagir quelle que soit la zone de la page où se trouve l'utilisateur.

L'objet événement `e` indique quelle touche a été pressée avec `e.key` :

```js
document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowUp") {
    console.log("Flèche haut");
  }
});
```

- `e.key` vaut le caractère de la touche (`"a"`, `"5"`, `" "` pour la barre d'espace) ou son nom (`"Enter"`, `"Escape"`, `"ArrowLeft"`, `"ArrowRight"`, `"ArrowUp"`, `"ArrowDown"`).
- Les majuscules comptent : `"a"` et `"A"` sont deux valeurs différentes.
- `e.preventDefault()` empêche l'action habituelle de la touche (par exemple, les flèches qui font défiler la page).

## Énoncé
Une balle est affichée au centre de l'aperçu. Tu ne vois pas son code, mais voici ce qu'il faut savoir :
- la balle a l'identifiant `balle`
- sa position est lue à partir de deux attributs : `data-x` et `data-y` (des nombres de pixels, tous deux à `0` au départ). Pour la déplacer, change ces valeurs **et** son style `transform` : `translate(<x>px, <y>px)`

Dans `script.js` :
1. Écoute l'événement `keydown` sur `document`.
2. Selon la touche (`e.key`) :
   - `ArrowRight` : la balle va de 20 px vers la droite
   - `ArrowLeft` : la balle va de 20 px vers la gauche
   - `ArrowDown` : la balle va de 20 px vers le bas
   - `ArrowUp` : la balle va de 20 px vers le haut
3. Après chaque déplacement, enregistre la nouvelle position dans `balle.dataset.x` et `balle.dataset.y`, et applique-la avec ``balle.style.transform = `translate(${x}px, ${y}px)` ``.
4. Les autres touches ne font rien.

## Méthode
- [ ] `document.addEventListener("keydown", (e) => { ... })`
- [ ] Garde `x` et `y` dans deux variables (`let x = 0; let y = 0;`)
- [ ] Compare `e.key` avec `"ArrowRight"`, `"ArrowLeft"`, `"ArrowDown"` et `"ArrowUp"`
- [ ] Mets à jour `balle.dataset.x`, `balle.dataset.y` et `balle.style.transform`

## Résultat
- [ ] Les quatre flèches déplacent la balle de 20 px dans la bonne direction
- [ ] Les autres touches n'ont aucun effet

## Indice
Pour la droite, ajoute 20 à `x`. Pour le haut, retire 20 à `y` (l'axe vertical va vers le bas : `y` augmente quand on descend).

## Tests
```js
const balle = $("#balle");
const appuyer = (touche) => document.dispatchEvent(new KeyboardEvent("keydown", { key: touche, bubbles: true }));
assert(/keydown/.test(code), "Écoute l'événement keydown pour réagir au clavier");
appuyer("ArrowRight");
assert(balle.dataset.x === "20" && balle.dataset.y === "0", "ArrowRight doit déplacer la balle de 20 px vers la droite (data-x = 20, data-y = 0)");
appuyer("ArrowDown");
assert(balle.dataset.x === "20" && balle.dataset.y === "20", "ArrowDown doit déplacer la balle de 20 px vers le bas (data-y = 20)");
appuyer("ArrowLeft");
appuyer("ArrowLeft");
assert(balle.dataset.x === "-20" && balle.dataset.y === "20", "ArrowLeft doit déplacer la balle de 20 px vers la gauche (deux appuis : data-x = -20)");
appuyer("ArrowUp");
assert(balle.dataset.x === "-20" && balle.dataset.y === "0", "ArrowUp doit déplacer la balle de 20 px vers le haut (data-y = 0)");
appuyer("a");
appuyer("Enter");
assert(balle.dataset.x === "-20" && balle.dataset.y === "0", "Les autres touches ne doivent pas déplacer la balle");
assert(balle.style.transform.replace(/\s/g, "") === "translate(-20px,0px)", "Applique la position avec balle.style.transform = `translate(${x}px, ${y}px)`");
```

## Solution: script.js
```js
const balle = document.querySelector("#balle");
let x = 0;
let y = 0;

document.addEventListener("keydown", (e) => {
  if (e.key === "ArrowRight") x += 20;
  else if (e.key === "ArrowLeft") x -= 20;
  else if (e.key === "ArrowDown") y += 20;
  else if (e.key === "ArrowUp") y -= 20;
  else return;

  balle.dataset.x = x;
  balle.dataset.y = y;
  balle.style.transform = `translate(${x}px, ${y}px)`;
});
```
