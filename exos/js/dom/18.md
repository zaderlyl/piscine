## Cours
Ce palier conclut le module **JavaScript & DOM**. Il remobilise tout ce que tu as vu : lire un formulaire, créer des éléments, écouter des clics par délégation, et sauvegarder dans `localStorage`.

Pour une application qui garde des données, une méthode fiable est de séparer :
1. **Les données** : un tableau d'objets, par exemple `[{ texte: "Réviser", fait: false }]`.
2. **L'affichage** : une fonction `afficher()` qui efface la liste puis la reconstruit à partir du tableau.

À chaque action (ajouter, supprimer, cocher), tu modifies **le tableau**, puis tu appelles `afficher()` : la page reste toujours fidèle aux données. C'est aussi dans `afficher()` que tu sauvegardes dans `localStorage`, avec `JSON.stringify(...)` pour convertir le tableau en texte (et `JSON.parse(...)` pour le relire).

```js
let taches = JSON.parse(localStorage.getItem("ma-cle")) || [];

function afficher() {
  // 1. vider la liste  2. recréer un <li> par tâche  3. mettre à jour le compteur
  localStorage.setItem("ma-cle", JSON.stringify(taches));
}
afficher();
```

## Énoncé
Une page de liste de tâches est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le formulaire a l'identifiant `formulaire`, son champ de texte `nouvelle-tache`
- la liste vide a l'identifiant `taches`, et un paragraphe vide `compteur` est prévu sous la liste
- la classe `fait`, posée sur un `<li>`, est déjà stylée : elle barre le texte de la tâche

Dans `script.js`, réalise une application qui fait **tout** ceci :
1. **Ajouter** : à l'envoi du formulaire (sans recharger la page), ajoute la tâche saisie, puis vide le champ. Une saisie vide, ou faite uniquement d'espaces, est ignorée.
2. **Afficher** : chaque tâche est un `<li>` de cette forme, avec la classe `fait` si elle est faite :
   `<li><span class="texte">Réviser</span> <button class="btn-suppr">Supprimer</button></li>`
3. **Supprimer** : un clic sur un bouton `.btn-suppr` supprime la tâche.
4. **Cocher** : un clic sur le texte `.texte` d'une tâche bascule son état « faite » (classe `fait` sur le `<li>`).
5. **Compter** : `#compteur` affiche `Reste : <n>`, où `n` est le nombre de tâches pas encore faites (par exemple `Reste : 2`).
6. **Sauvegarder** : les tâches sont enregistrées dans `localStorage` sous la clé `piscine-taches` (un tableau d'objets `{ texte, fait }` converti avec `JSON.stringify`) et relues au chargement de la page.

Pour les clics sur la liste, utilise **un seul** écouteur sur `#taches` (délégation d'événements).

## Méthode
- [ ] Garde les tâches dans un tableau : `let taches = JSON.parse(localStorage.getItem("piscine-taches")) || [];`
- [ ] Écris une fonction `afficher()` qui vide la liste, recrée les `<li>`, met à jour le compteur et sauvegarde
- [ ] À l'envoi du formulaire : `e.preventDefault()`, `trim()`, `taches.push({ texte, fait: false })`, `afficher()`
- [ ] Un seul écouteur de clic sur `#taches`, avec `e.target.closest(".btn-suppr")` et `e.target.closest(".texte")`
- [ ] Appelle `afficher()` une première fois au chargement

## Résultat
- [ ] On peut ajouter, cocher et supprimer des tâches, et le compteur reste exact
- [ ] Les tâches sont toujours là après un rechargement de l'aperçu

## Indice
Pour retrouver quelle tâche a été cliquée, pose son numéro sur le `<li>` quand tu le crées (`li.dataset.index = i;`), puis relis-le avec `e.target.closest("li").dataset.index`.

## Tests
```js
const tout = () => $$("#taches li");
const avant = tout().length;
const etat = () => JSON.parse(localStorage.getItem("piscine-taches") || "null");
const restantes = () => $$("#taches li:not(.fait)").length;

// Ajouter une tâche
type("#nouvelle-tache", "  Réviser  ");
$("#formulaire").requestSubmit();
assert(tout().length === avant + 1, "Ajoute un <li> dans #taches quand on envoie le formulaire");
const derniere = () => tout()[tout().length - 1];
assert(derniere()?.querySelector(".texte")?.textContent.trim() === "Réviser", "Écris le texte saisi (sans les espaces autour) dans un <span class=\"texte\"> du <li>");
assert(derniere()?.querySelector(".btn-suppr")?.textContent.trim() === "Supprimer", "Ajoute un bouton « Supprimer » de classe btn-suppr dans chaque <li>");
assert($("#nouvelle-tache")?.value === "", "Vide le champ de saisie après l'ajout");

// Saisie vide
type("#nouvelle-tache", "   ");
$("#formulaire").requestSubmit();
assert(tout().length === avant + 1, "Ignore une saisie vide ou faite uniquement d'espaces");

// Compteur
assert($("#compteur")?.textContent.trim() === `Reste : ${restantes()}`, "Écris dans #compteur « Reste : <n> » avec n = nombre de tâches pas encore faites");

// Sauvegarde
const sauvegarde = etat();
assert(Array.isArray(sauvegarde) && sauvegarde.length === avant + 1, "Enregistre toutes les tâches dans localStorage sous la clé piscine-taches (tableau converti avec JSON.stringify)");
const derniereSauvee = sauvegarde?.[sauvegarde.length - 1];
assert(derniereSauvee?.texte === "Réviser" && derniereSauvee?.fait === false, "Enregistre chaque tâche sous la forme { texte, fait } (fait vaut false pour une nouvelle tâche)");

// Cocher
const avantCoche = restantes();
derniere().querySelector(".texte").click();
assert(derniere()?.classList.contains("fait"), "Un clic sur le texte d'une tâche doit ajouter la classe fait au <li>");
assert(restantes() === avantCoche - 1, "Cocher une tâche doit faire baisser le nombre de tâches restantes");
assert($("#compteur")?.textContent.trim() === `Reste : ${restantes()}`, "Mets à jour #compteur après avoir coché une tâche");
assert(etat()?.[etat().length - 1]?.fait === true, "Enregistre aussi l'état « faite » dans localStorage (fait vaut true)");
derniere().querySelector(".texte").click();
assert(!derniere()?.classList.contains("fait"), "Un deuxième clic doit décocher la tâche (retire la classe fait)");

// Supprimer
derniere().querySelector(".btn-suppr").click();
assert(tout().length === avant, "Un clic sur « Supprimer » doit retirer la tâche de la liste");
assert(etat()?.length === avant, "Mets à jour localStorage après une suppression");
assert($("#compteur")?.textContent.trim() === `Reste : ${restantes()}`, "Mets à jour #compteur après une suppression");
```

## Solution: script.js
```js
const formulaire = document.querySelector("#formulaire");
const champ = document.querySelector("#nouvelle-tache");
const liste = document.querySelector("#taches");
const compteur = document.querySelector("#compteur");
const CLE = "piscine-taches";

let taches = JSON.parse(localStorage.getItem(CLE)) || [];

function afficher() {
  liste.textContent = "";
  taches.forEach((tache, i) => {
    const li = document.createElement("li");
    li.dataset.index = i;
    if (tache.fait) li.classList.add("fait");

    const texte = document.createElement("span");
    texte.className = "texte";
    texte.textContent = tache.texte;

    const bouton = document.createElement("button");
    bouton.className = "btn-suppr";
    bouton.textContent = "Supprimer";

    li.append(texte, " ", bouton);
    liste.appendChild(li);
  });
  compteur.textContent = `Reste : ${taches.filter((t) => !t.fait).length}`;
  localStorage.setItem(CLE, JSON.stringify(taches));
}

formulaire.addEventListener("submit", (e) => {
  e.preventDefault();
  const texte = champ.value.trim();
  if (texte === "") return;
  taches.push({ texte, fait: false });
  champ.value = "";
  afficher();
});

liste.addEventListener("click", (e) => {
  const li = e.target.closest("li");
  if (!li) return;
  const i = Number(li.dataset.index);
  if (e.target.closest(".btn-suppr")) {
    taches.splice(i, 1);
  } else if (e.target.closest(".texte")) {
    taches[i].fait = !taches[i].fait;
  } else {
    return;
  }
  afficher();
});

afficher();
```
