## Cours
Quand un formulaire est envoyé, le navigateur recharge la page par défaut. En JavaScript, on intercepte l'envoi avec l'événement `submit` et on bloque ce rechargement avec `e.preventDefault()`.

L'objet `FormData` lit d'un seul coup toutes les valeurs d'un formulaire, sans aller chercher chaque champ un par un. Chaque valeur est rangée sous le nom (`name`) de son champ :

```js
formulaire.addEventListener("submit", (e) => {
  e.preventDefault();
  const donnees = new FormData(formulaire);
  console.log(donnees.get("email"));          // la valeur du champ name="email"
  const objet = Object.fromEntries(donnees);  // { email: "...", message: "..." }
});
```

- `new FormData(formulaire)` : lit tous les champs du formulaire.
- `donnees.get("nom")` : lit la valeur d'un champ à partir de son `name`.
- `Object.fromEntries(donnees)` : convertit le tout en objet JavaScript.

## Énoncé
Un formulaire de contact est affiché dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le formulaire a l'identifiant `formulaire`
- ses champs ont pour `name` : `prenom`, `email` et `message`
- un paragraphe d'identifiant `resultat`, vide au départ, est prévu pour afficher la confirmation

Dans `script.js` :
1. Attache un écouteur `submit` sur `#formulaire`.
2. Bloque le rechargement de la page avec `e.preventDefault()`.
3. Lis les valeurs du formulaire avec `new FormData(...)`.
4. Écris dans `#resultat` le texte `Merci <prenom> ! Réponse envoyée à <email>.` (par exemple `Merci Sacha ! Réponse envoyée à sacha@mail.fr.`).

## Méthode
- [ ] `formulaire.addEventListener("submit", (e) => { ... })`
- [ ] `e.preventDefault();`
- [ ] `const donnees = new FormData(formulaire);`
- [ ] Lis les champs avec `donnees.get("prenom")` et `donnees.get("email")`
- [ ] Mets à jour `resultat.textContent`

## Résultat
- [ ] À l'envoi, la page ne se recharge pas
- [ ] Le paragraphe `#resultat` affiche le message de remerciement avec le prénom et l'email saisis

## Indice
`donnees.get("prenom")` renvoie ce qui est écrit dans le champ dont le `name` est `prenom`.

## Solution: script.js
```js
const formulaire = document.querySelector("#formulaire");
const resultat = document.querySelector("#resultat");

formulaire.addEventListener("submit", (e) => {
  e.preventDefault();
  const donnees = new FormData(formulaire);
  resultat.textContent = `Merci ${donnees.get("prenom")} ! Réponse envoyée à ${donnees.get("email")}.`;
});
```
