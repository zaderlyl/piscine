## Cours
L'objet `localStorage` permet d'enregistrer des informations directement dans le navigateur du visiteur, conservées même après la fermeture de la page :
- `localStorage.setItem("clé", "valeur")` : stocke une chaîne de texte.
- `localStorage.getItem("clé")` : lit la valeur enregistrée (ou renvoie `null` si la clé n'existe pas encore).

Exemple :
```js
localStorage.setItem("theme", "sombre");
const themeChoisi = localStorage.getItem("theme");
```

## Énoncé
Un compteur de score est affiché dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le score est dans un `<span>` d'identifiant `score-affiche` (il affiche toujours 0 au départ)
- le bouton « Augmenter » a l'identifiant `btn-score`

Dans `script.js` :
1. Au chargement, lis le score enregistré avec `localStorage.getItem("piscine-score")` (par défaut : `0`) et affiche-le dans `#score-affiche`.
2. Au clic sur `#btn-score`, augmente le score de 1, mets à jour l'affichage et sauvegarde la nouvelle valeur avec `localStorage.setItem("piscine-score", score)`.

Recharge l'aperçu : le score doit être conservé.

## Méthode
- [ ] Lis la valeur initiale avec `parseInt(localStorage.getItem("piscine-score"), 10) || 0`
- [ ] Modifie `score-affiche.textContent`
- [ ] Enregistre avec `localStorage.setItem("piscine-score", ...)`

## Résultat
- [ ] Le score s'incrémente au clic et est sauvegardé dans `localStorage`

## Indice
La valeur renvoyée par `localStorage.getItem` est une chaîne de caractères : convertis-la en nombre avec `parseInt`.

## Tests
```js
const scoreAffiche = $("#score-affiche");
const avant = Number(scoreAffiche?.textContent.trim()) || 0;
assert(String(avant) === (localStorage.getItem("piscine-score") ?? "0"), "Affiche dans #score-affiche le score lu avec localStorage.getItem(\"piscine-score\")");
const sauvegarde = localStorage.getItem("piscine-score");
click("#btn-score");
assert(localStorage.getItem("piscine-score") === String(avant + 1), "Enregistre le nouveau score avec localStorage.setItem(\"piscine-score\", score) à chaque clic");
assert(scoreAffiche?.textContent.trim() === String(avant + 1), "Affiche le nouveau score dans #score-affiche après le clic");
// Le clic du test ne doit pas compter : on remet le score de l'élève
if (sauvegarde === null) localStorage.removeItem("piscine-score");
else localStorage.setItem("piscine-score", sauvegarde);
if (scoreAffiche) scoreAffiche.textContent = String(avant);
```

## Solution: script.js
```js
const affichage = document.querySelector("#score-affiche");
const bouton = document.querySelector("#btn-score");
let score = parseInt(localStorage.getItem("piscine-score"), 10) || 0;
affichage.textContent = score;

bouton.addEventListener("click", () => {
  score = (parseInt(localStorage.getItem("piscine-score"), 10) || 0) + 1;
  localStorage.setItem("piscine-score", score);
  affichage.textContent = score;
});
```
