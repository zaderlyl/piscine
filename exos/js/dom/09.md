## Cours
L'API `IntersectionObserver` permet de surveiller de manière très fluide l'apparition d'un élément dans la zone visible de l'écran (*viewport*), sans ralentir le navigateur avec des écouteurs d'événements de défilement (*scroll*).

Exemple :
```js
const observateur = new IntersectionObserver((entrees) => {
  entrees.forEach((entree) => {
    if (entree.isIntersecting) {
      entree.target.classList.add("visible");
    }
  });
});
observateur.observe(document.querySelector(".section"));
```

## Énoncé
Une page à faire défiler est affichée dans l'aperçu : en bas, une boîte est cachée. Tu ne vois pas son code, mais voici ses éléments :
- la boîte a l'identifiant `boite` et la classe `boite`
- la classe `visible` est déjà stylée : elle fait apparaître la boîte en douceur

Dans `script.js` :
1. Crée un nouvel `IntersectionObserver` et stocke-le dans `window.observateur`.
2. Dans la fonction de rappel, pour chaque entrée visible (`entree.isIntersecting`), ajoute la classe `visible` à `entree.target`.
3. Lance la surveillance de `#boite` avec `window.observateur.observe(...)`.

Fais ensuite défiler l'aperçu : la boîte doit apparaître.

## Solution: script.js
```js
window.observateur = new IntersectionObserver((entrees) => {
  entrees.forEach((entree) => {
    if (entree.isIntersecting) {
      entree.target.classList.add("visible");
    }
  });
});
const boite = document.querySelector("#boite");
window.observateur.observe(boite);
```
