## Cours
La **délégation d'événements** consiste à poser un seul écouteur sur un élément parent (comme une liste `<ul>`) au lieu de poser un écouteur sur chaque enfant.

Grâce à la remontée de l'événement (*bubbling*) :
- `e.target` indique l'élément exact qui a reçu le clic.
- `e.target.closest("sélecteur")` permet de retrouver le bouton ou l'élément ciblé même si l'utilisateur a cliqué sur un texte ou une icône à l'intérieur.

Exemple :
```js
liste.addEventListener("click", (e) => {
  const bouton = e.target.closest(".btn-suppr");
  if (bouton) {
    bouton.closest("li").remove();
  }
});
```

## Énoncé
Une liste de tâches est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- la liste a l'identifiant `taches`
- chaque tâche est un `<li>` qui contient un texte et un bouton de classe `btn-suppr`

Dans `script.js` :
1. Attache **un seul** écouteur de clic sur `#taches`.
2. Quand le clic vient d'un bouton `.btn-suppr`, supprime le `<li>` correspondant du DOM avec `.remove()`.

## Méthode
- [ ] Attache l'écouteur sur `document.querySelector("#taches")`
- [ ] Vérifie la cible avec `e.target.closest(".btn-suppr")`
- [ ] Supprime le `<li>` parent avec `btn.closest("li").remove()`

## Résultat
- [ ] Cliquer sur « Supprimer » retire uniquement la tâche concernée

## Indice
Utilise `e.target.closest(".btn-suppr")` dans l'écouteur du parent, puis supprime son parent `li`.

## Tests
```js
const total = $$("#taches li").length;
const premierLi = $("#taches li");
const dernierLi = $$("#taches li")[total - 1];
$$("#taches .btn-suppr")[0].click();
assert(!document.body.contains(premierLi), "Retire le <li> avec remove() quand on clique sur son bouton Supprimer");
assert(document.body.contains(dernierLi), "Ne supprime que la tâche dont on a cliqué le bouton, pas les autres");
assert($$("#taches li").length === total - 1, "Supprime exactement une tâche par clic");
```

## Solution: script.js
```js
const liste = document.querySelector("#taches");
liste.addEventListener("click", (e) => {
  const btn = e.target.closest(".btn-suppr");
  if (btn) {
    btn.closest("li").remove();
  }
});
```
