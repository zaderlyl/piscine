## Cours
Le DOM (*Document Object Model*) représente la page HTML sous forme d'une arborescence d'objets JavaScript.

Pour manipuler un élément de la page, on utilise les sélecteurs CSS :
- `document.querySelector("sélecteur")` : renvoie le premier élément correspondant, ou `null` si aucun élément n'est trouvé.
- `document.querySelectorAll("sélecteur")` : renvoie tous les éléments correspondants sous la forme d'une `NodeList`.

Exemple :
```js
const titre = document.querySelector("#mon-titre");
const paragraphes = document.querySelectorAll(".description");
```

## Page
```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <style>
    body { margin: 0; min-height: 100vh; display: grid; place-items: center; background: #eef2f7; font-family: system-ui, sans-serif; color: #1f2937; }
    main { width: 100%; max-width: 420px; padding: 24px; }
    h1 { margin: 0 0 20px; font-size: 1.6rem; }
    .alerte { margin: 0 0 12px; padding: 14px 18px; border-radius: 12px; background: #fff; border-left: 5px solid #f59e0b; box-shadow: 0 4px 14px rgba(31, 41, 55, .1); }
  </style>
</head>
<body>
  <main>
    <h1 id="titre-principal">Bienvenue</h1>
    <p class="alerte">Ton colis a été expédié.</p>
    <p class="alerte">Une nouvelle mise à jour est disponible.</p>
    <p class="alerte">Ton abonnement expire dans 3 jours.</p>
  </main>
  <script src="script.js"></script>
</body>
</html>
```

## Énoncé
Une page de notifications est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le titre a l'identifiant `titre-principal`
- il y a trois paragraphes qui ont tous la classe `alerte`

Dans `script.js` :
1. Sélectionne le titre avec `querySelector` et stocke-le dans `window.titre`.
2. Sélectionne les trois alertes avec `querySelectorAll` et stocke-les dans `window.alertes`.

## Méthode
- [ ] Utilise `document.querySelector("#titre-principal")`
- [ ] Utilise `document.querySelectorAll(".alerte")`

## Résultat
- [ ] Le titre est sélectionné dans `window.titre`
- [ ] Les trois paragraphes sont sélectionnés dans `window.alertes`

## Indice
Utilise `#` pour cibler un identifiant et `.` pour une classe CSS.

## Tests
```js
assert(window.titre === $("#titre-principal"), "Sélectionne le titre avec document.querySelector(\"#titre-principal\") et stocke-le dans window.titre");
assert(window.alertes && window.alertes.length === 3, "Sélectionne les trois alertes avec document.querySelectorAll(\".alerte\") et stocke-les dans window.alertes");
assert(window.alertes && [...window.alertes].every((a) => a.classList.contains("alerte")), "Sélectionne uniquement les éléments de classe alerte, avec le point devant");
```

## Solution: script.js
```js
window.titre = document.querySelector("#titre-principal");
window.alertes = document.querySelectorAll(".alerte");
```
