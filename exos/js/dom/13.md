## Cours
Quand une page a besoin de **plusieurs** données, on pourrait les demander l'une après l'autre avec `await` :

```js
const profil = await (await fetch("/api/profil")).json();   // on attend...
const messages = await (await fetch("/api/messages")).json(); // ...puis on attend encore
```

C'est lent : la deuxième demande ne part qu'après la fin de la première. Les deux demandes étant indépendantes, on peut les lancer **en même temps** avec `Promise.all`, qui prend un tableau de promesses et attend qu'elles soient toutes terminées :

```js
const [reponseProfil, reponseMessages] = await Promise.all([
  fetch("/api/profil"),
  fetch("/api/messages"),
]);
```

- `Promise.all([...])` renvoie un tableau de résultats, **dans le même ordre** que les promesses.
- On le range directement dans deux variables grâce à la déstructuration (`const [a, b] = ...`).
- Si une seule promesse échoue, `Promise.all` échoue.

## Énoncé
Un tableau de bord est affiché dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le bouton a l'identifiant `btn-charger`, le paragraphe vide a l'identifiant `tableau-de-bord`
- deux données se récupèrent avec `fetch` :
  - `fetch("/api/profil")` renvoie un objet `{ prenom }`
  - `fetch("/api/messages")` renvoie un tableau de messages
- chaque demande met un moment à répondre (un serveur simulé répond après un court instant)

Dans `script.js` :
1. Attache un écouteur de clic `async` sur `#btn-charger`.
2. Lance **en même temps** les deux demandes avec `Promise.all`, puis lis leur contenu avec `.json()`.
3. Écris dans `#tableau-de-bord` le texte `<prenom> a <n> messages` (par exemple `Sacha a 3 messages`).

## Indice
`Promise.all` prend **un tableau** de promesses : `Promise.all([fetch("/api/profil"), fetch("/api/messages")])`.

## Solution: script.js
```js
const bouton = document.querySelector("#btn-charger");
const tableau = document.querySelector("#tableau-de-bord");

bouton.addEventListener("click", async () => {
  const [repProfil, repMessages] = await Promise.all([
    fetch("/api/profil"),
    fetch("/api/messages"),
  ]);
  const profil = await repProfil.json();
  const messages = await repMessages.json();
  tableau.textContent = `${profil.prenom} a ${messages.length} messages`;
});
```
