## Cours
Une fois un élément sélectionné, JavaScript permet de modifier dynamiquement son contenu et ses attributs :
- `element.textContent = "Nouveau texte"` : modifie le texte de l'élément de manière sécurisée (sans faille XSS).
- `element.classList.add("classe")` : ajoute une classe CSS à l'élément.
- `element.dataset.attribut` : lit ou écrit une valeur dans l'attribut HTML `data-attribut`.

Exemple :
```js
const carte = document.querySelector(".carte");
carte.textContent = "Chargé";
carte.classList.add("visible");
carte.dataset.statut = "pret";
```


## Énoncé
Une carte de niveau est affichée dans l'aperçu. Tu ne vois pas son code, mais voici ce qu'il faut savoir :
- la carte a l'identifiant `carte`, le texte « Niveau 1 » et un attribut `data-niveau` qui vaut `"1"`
- la classe `valide` est déjà stylée : elle colore la carte en vert

Dans `script.js`, sélectionne la carte, puis :
1. Modifie son texte avec `textContent` pour afficher « Niveau 2 ».
2. Ajoute-lui la classe CSS `valide` avec `classList.add`.
3. Modifie son attribut `dataset.niveau` pour qu'il vaille `"2"`.

- [ ] Utilise `carte.classList.add("valide")`
- [ ] Utilise `carte.dataset.niveau = "2"`
