## Cours
JavaScript sait exécuter du code **plus tard**, ou **à intervalles réguliers**.

- `setTimeout(fonction, délai)` exécute la fonction **une seule fois**, après un délai en millisecondes (1000 ms = 1 seconde).
- `setInterval(fonction, délai)` exécute la fonction **encore et encore**, toutes les `délai` millisecondes.
- `setInterval` renvoie un identifiant. On le range dans une variable, pour pouvoir **arrêter** la répétition avec `clearInterval(identifiant)`.

```js
let secondes = 0;
const minuteur = setInterval(() => {
  secondes++;
  console.log(secondes);
  if (secondes === 5) {
    clearInterval(minuteur); // on arrête la répétition
  }
}, 1000);

setTimeout(() => console.log("Une seconde plus tard"), 1000);
```

Si on oublie `clearInterval`, la fonction continue de tourner indéfiniment.

## Énoncé
Un compte à rebours est affiché dans l'aperçu. Tu ne vois pas son code, mais voici ses éléments :
- le nombre affiché a l'identifiant `compteur` et vaut `2` au départ
- le bouton a l'identifiant `btn-demarrer`
- la classe `termine` est déjà stylée : elle colore le nombre en vert

Dans `script.js` :
1. Au clic sur `#btn-demarrer`, désactive le bouton (`bouton.disabled = true`) et lance un `setInterval` qui s'exécute **toutes les secondes**.
2. À chaque seconde, diminue le nombre affiché dans `#compteur` de 1 (2, puis 1, puis 0).
3. Quand le nombre atteint `0`, arrête l'intervalle avec `clearInterval`, affiche « Terminé ! » à la place du nombre et ajoute la classe `termine` à `#compteur`.

## Méthode
- [ ] Garde la valeur dans une variable : `let restant = 2;`
- [ ] `const minuteur = setInterval(() => { ... }, 1000);`
- [ ] Mets à jour `compteur.textContent` à chaque tick
- [ ] Quand `restant === 0`, appelle `clearInterval(minuteur)`

## Résultat
- [ ] Au clic, le nombre diminue d'une unité par seconde
- [ ] À 0, le décompte s'arrête et « Terminé ! » s'affiche en vert

## Indice
Le tick qui fait passer `restant` à `0` est aussi celui qui doit arrêter l'intervalle : teste `restant === 0` juste après l'avoir diminué.

## Solution: script.js
```js
const compteur = document.querySelector("#compteur");
const bouton = document.querySelector("#btn-demarrer");

bouton.addEventListener("click", () => {
  bouton.disabled = true;
  let restant = 2;

  const minuteur = setInterval(() => {
    restant--;
    if (restant === 0) {
      clearInterval(minuteur);
      compteur.textContent = "Terminé !";
      compteur.classList.add("termine");
    } else {
      compteur.textContent = restant;
    }
  }, 1000);
});
```
