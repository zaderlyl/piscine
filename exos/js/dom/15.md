## Cours
Beaucoup d'éléments d'une page ont deux états : un menu ouvert ou fermé, un bloc déplié ou replié. Une bonne façon de les gérer est de **changer une classe CSS** : le CSS décide à quoi ressemble chaque état, et JavaScript n'a qu'à basculer la classe.

`classList.toggle("classe")` fait ce basculement : il **ajoute** la classe si l'élément ne l'a pas, et la **retire** s'il l'a déjà.

```js
const menu = document.querySelector("#menu");
bouton.addEventListener("click", () => {
  menu.classList.toggle("ouvert");
});
```

- `classList.toggle("ouvert")` : un premier clic ouvre, le suivant referme.
- `classList.contains("ouvert")` : vrai si la classe est présente.
- `classList.remove("ouvert")` : retire la classe, quel que soit l'état.

## Énoncé
Une page de questions fréquentes (FAQ) est affichée dans l'aperçu : toutes les réponses sont repliées. Tu ne vois pas son code, mais voici ses éléments :
- le conteneur a l'identifiant `faq`
- chaque question est un `<div class="element">` qui contient un bouton `.titre` (la question) et un paragraphe `.contenu` (la réponse)
- la classe `ouvert`, posée sur un `.element`, est déjà stylée : elle affiche sa réponse

Dans `script.js` :
1. Attache **un seul** écouteur de clic sur `#faq`.
2. Au clic sur un bouton `.titre`, bascule la classe `ouvert` sur le `.element` qui le contient, avec `classList.toggle`. Un deuxième clic le referme.
3. Plusieurs réponses peuvent être ouvertes en même temps.

## Méthode
- [ ] Un seul écouteur sur `document.querySelector("#faq")`
- [ ] `const titre = e.target.closest(".titre");` puis `if (titre) { ... }`
- [ ] `titre.closest(".element").classList.toggle("ouvert");`

## Résultat
- [ ] Un clic sur une question affiche sa réponse, un second clic la cache
- [ ] Les autres questions ne sont pas modifiées

## Indice
La délégation d'événements vue dans l'exercice `05` s'applique ici : écoute le conteneur, retrouve le bouton cliqué avec `e.target.closest(".titre")`, puis remonte jusqu'à son `.element`.

## Tests
```js
assert(/classList\.toggle\s*\(/.test(code), "Utilise classList.toggle(\"ouvert\") pour ouvrir et fermer une réponse");
const elements = $$("#faq .element");
const titres = $$("#faq .titre");
assert(elements.every((el) => !el.classList.contains("ouvert")), "Laisse toutes les réponses repliées tant qu'on n'a pas cliqué");
titres[0].click();
assert(elements[0].classList.contains("ouvert"), "Ajoute la classe ouvert sur l'élément cliqué");
assert(!elements[1].classList.contains("ouvert") && !elements[2].classList.contains("ouvert"), "Ne modifie que l'élément dont on a cliqué le titre");
titres[2].click();
assert(elements[0].classList.contains("ouvert") && elements[2].classList.contains("ouvert"), "Laisse plusieurs réponses ouvertes en même temps");
titres[0].click();
assert(!elements[0].classList.contains("ouvert"), "Un deuxième clic doit refermer la réponse (retire la classe ouvert)");
assert(elements[2].classList.contains("ouvert"), "Refermer une réponse ne doit pas fermer les autres");
```

## Solution: script.js
```js
const faq = document.querySelector("#faq");

faq.addEventListener("click", (e) => {
  const titre = e.target.closest(".titre");
  if (titre) {
    titre.closest(".element").classList.toggle("ouvert");
  }
});
```
