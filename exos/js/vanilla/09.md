## Cours
Un **objet littéral** permet de regrouper plusieurs informations associées à une même entité sous forme de paires **clé: valeur**, délimitées par des accolades `{}` :

```js
const livre = {
  titre: "Dune",
  pages: 412,
  disponible: true,
};
```

Pour lire ou modifier une propriété d'un objet, on utilise la **notation pointée** (`objet.propriete`) :

```js
livre.pages = 420;
console.log(livre.titre); // "Dune"
```

## Énoncé
Dans `script.js`, déclare un objet `hero` avec trois propriétés :
- `nom` : la chaîne `"Link"`
- `pointsDeVie` : le nombre `100`
- `enVie` : le booléen `true`

Sur la ligne suivante, modifie la propriété `pointsDeVie` du héros pour lui assigner la valeur `80`.

## Méthode
- [ ] Déclare `const hero = { ... };` avec les 3 propriétés initiales
- [ ] Modifie les points de vie avec `hero.pointsDeVie = 80;`

## Résultat
- [ ] L'objet `hero` existe avec ses 3 propriétés
- [ ] `hero.pointsDeVie` vaut désormais `80`

## Indice
La mise à jour d'une propriété s'écrit `hero.pointsDeVie = 80;`.

## Tests
```js

assert(hero.nom === "Link", "hero.nom doit valoir « Link »");
assert(hero.enVie === true, "hero.enVie doit valoir true");
assert(hero.pointsDeVie === 80, "hero.pointsDeVie doit valoir 80 après modification");
assert(/pointsDeVie\s*:\s*100\b/.test(code), "hero doit être initialisé avec 100 points de vie");
assert(/hero\.pointsDeVie\s*=\s*80|hero\s*\[\s*["']pointsDeVie["']\s*\]\s*=\s*80/.test(code), "Tu dois modifier les points de vie avec hero.pointsDeVie = 80");
```

## Solution: script.js
```js
const hero = {
  nom: "Link",
  pointsDeVie: 100,
  enVie: true,
};

hero.pointsDeVie = 80;
```
