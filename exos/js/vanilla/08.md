## Cours
Un tableau (`Array`) permet de stocker une liste ordonnée d'éléments entre crochets `[]` :

```js
const couleurs = ["rouge", "vert", "bleu"];
```

Chaque élément est accessible par son numéro de position, appelé **indice** (*index*). Les indices commencent toujours à **`0`** :
- `couleurs[0]` renvoie `"rouge"`
- `couleurs[1]` renvoie `"vert"`

La propriété **`.length`** donne le nombre d'éléments dans le tableau : `couleurs.length` renvoie `3`.

Pour ajouter un nouvel élément à la fin du tableau, on utilise la méthode **`.push()`** :
```js
couleurs.push("jaune");
```

## Énoncé
Dans `script.js`, déclare un tableau `fruits` contenant initialement les chaînes `["pomme", "banane"]`.
Utilise la méthode `.push()` pour ajouter `"cerise"` au tableau.
Déclare ensuite une variable `premier` contenant le premier élément de la liste, puis une variable `totalFruits` contenant le nombre total d'éléments dans le tableau.

## Méthode
- [ ] Déclare `const fruits = ["pomme", "banane"];`
- [ ] Ajoute `"cerise"` avec `fruits.push("cerise");`
- [ ] Récupère le premier élément dans `const premier = fruits[0];`
- [ ] Récupère la taille du tableau dans `const totalFruits = fruits.length;`

## Résultat
- [ ] Le tableau `fruits` contient 3 éléments : `"pomme"`, `"banane"`, `"cerise"`
- [ ] La variable `premier` vaut `"pomme"`
- [ ] La variable `totalFruits` vaut `3`

## Indice
Rappelle-toi que le premier indice est `0` : `fruits[0]`.

## Tests
```js
assert(Array.isArray(fruits), "fruits doit être un tableau");
assert(fruits.length === 3, "fruits doit contenir exactement 3 éléments");
assert(fruits[0] === "pomme", "Le premier fruit doit être « pomme »");
assert(fruits[2] === "cerise", "Le dernier fruit ajouté avec push doit être « cerise »");
assert(typeof premier !== "undefined", "La variable premier doit être déclarée");
assert(premier === "pomme", "La variable premier doit valoir « pomme »");
assert(typeof totalFruits !== "undefined", "La variable totalFruits doit être déclarée");
assert(totalFruits === 3, "La variable totalFruits doit valoir 3");
```

## Solution: script.js
```js
const fruits = ["pomme", "banane"];
fruits.push("cerise");

const premier = fruits[0];
const totalFruits = fruits.length;
```
