## Cours
Une structure conditionnelle `if` permet d'exécuter un bloc de code uniquement si une condition est vérifiée. Le mot-clé `else` permet d'exécuter une alternative si la condition est fausse :

```js
let statut = "";
if (age >= 18) {
  statut = "Majeur";
} else {
  statut = "Mineur";
}
```

Les principaux opérateurs de comparaison sont :
- `>=` : supérieur ou égal
- `<=` : inférieur ou égal
- `>` : strictement supérieur
- `<` : strictement inférieur
- `===` : strictement égal
- `!==` : différent de

## Énoncé
Dans `script.js`, déclare une variable `note` valant `14` et une variable `mention` initialisée à une chaîne vide `""`.
À l'aide d'une structure `if` et `else`, si `note` est supérieure ou égale à `10`, assigne le texte `"Reçu"` à `mention`. Sinon, assigne `"Ajourné"`.

## Méthode
- [ ] Déclare `let note = 14;`
- [ ] Déclare `let mention = "";`
- [ ] Écris la condition `if (note >= 10)`
- [ ] Remplis le bloc `else`

## Résultat
- [ ] La variable `mention` vaut `"Reçu"` pour une note de 14

## Indice
La structure s'écrit :
```js
if (note >= 10) {
  mention = "Reçu";
} else {
  mention = "Ajourné";
}
```

## Solution: script.js
```js
let note = 14;
let mention = "";

if (note >= 10) {
  mention = "Reçu";
} else {
  mention = "Ajourné";
}
```
