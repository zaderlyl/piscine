## Cours
Le mot-clé `const` crée une variable dont la valeur ne change pas :

```js
const prenom = "Alice";
```

## Énoncé
Dans `script.js`, déclare une variable `message` avec le mot-clé `const` et donne-lui la valeur `"Bonjour"`.

## Méthode
- [ ] Utilise le mot-clé `const`
- [ ] Nomme la variable `message`
- [ ] Assigne la valeur `"Bonjour"` avec le signe `=`

## Résultat
- [ ] La variable `message` contient le texte `"Bonjour"`

## Indice
Déclare la variable comme ceci : `const message = "Bonjour";`.

## Tests
```js
// Lit le code de l'élève sans planter si une variable ou une fonction manque encore
const essai = (f) => { try { return f(); } catch { return false; } };
assert(typeof message !== "undefined", "La variable message doit être déclarée");
assert(essai(() => message === "Bonjour"), "La variable message doit contenir exactement « Bonjour »");
assert(/\bconst\s+message\b/.test(code), "La variable message doit être déclarée avec const");
```

## Solution: script.js
```js
const message = "Bonjour";
```
