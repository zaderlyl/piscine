## Cours
En JavaScript moderne, la **déstructuration** permet d'extraire des propriétés d'un objet directement dans des variables distinctes du même nom :

```js
const article = { nom: "Clavier", prix: 49 };
const { nom, prix } = article;
// nom vaut "Clavier", prix vaut 49
```

L'**opérateur spread** (`...`) permet de déverser ou cloner les propriétés d'un objet dans un nouvel objet, sans modifier l'original :

```js
const articlePromo = { ...article, solde: true };
```

Cette approche permet de créer de nouveaux états sans mutation imprévue.

## Énoncé
Dans `script.js`, déclare l'objet `joueur = { pseudo: "Pixel", niveau: 5 };`.
1. Déstructure les variables `pseudo` et `niveau` depuis l'objet `joueur`.
2. Crée un nouvel objet `joueurAmeliore` en copiant les propriétés de `joueur` avec l'opérateur spread (`...joueur`) et en lui ajoutant la propriété `bouclier: true`.

## Méthode
- [ ] Déclare `const joueur = { pseudo: "Pixel", niveau: 5 };`
- [ ] Déstructure avec `const { pseudo, niveau } = joueur;`
- [ ] Crée `const joueurAmeliore = { ...joueur, bouclier: true };`

## Résultat
- [ ] Les variables `pseudo` et `niveau` contiennent `"Pixel"` et `5`
- [ ] L'objet `joueurAmeliore` contient `pseudo`, `niveau` et `bouclier: true`

## Indice
La déstructuration s'écrit `const { pseudo, niveau } = joueur;`.

## Solution: script.js
```js
const joueur = { pseudo: "Pixel", niveau: 5 };

const { pseudo, niveau } = joueur;
const joueurAmeliore = { ...joueur, bouclier: true };
```
