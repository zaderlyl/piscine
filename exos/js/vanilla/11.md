## Cours
En JavaScript, tenter d'accéder à une propriété sur une valeur `undefined` ou `null` provoque une erreur bloquante :

```js
const utilisateur = {};
utilisateur.adresse.ville; // ❌ TypeError: Cannot read properties of undefined
```

Le **chaînage optionnel** (`?.`) sécurise la lecture : si la référence avant `?.` est `null` ou `undefined`, l'évaluation s'interrompt et renvoie simplement `undefined` sans planter :

```js
const ville = utilisateur.adresse?.ville; // undefined (sans erreur)
```

L'opérateur de **coalescence des nuls** (`??`) fournit une valeur de remplacement uniquement si l'expression de gauche vaut `null` ou `undefined` :

```js
const villeFinale = utilisateur.adresse?.ville ?? "Non renseignée";
```

## Énoncé
Dans `script.js`, déclare un objet `utilisateur` contenant uniquement la propriété `nom: "Sacha"`.
Déclare ensuite une variable `ville` qui lit `utilisateur.adresse?.ville` en utilisant l'opérateur `??` pour lui affecter `"Non renseignée"` si la propriété est absente.

## Méthode
- [ ] Déclare `const utilisateur = { nom: "Sacha" };`
- [ ] Combine `?.` et `??` : `const ville = utilisateur.adresse?.ville ?? "Non renseignée";`

## Résultat
- [ ] `ville` vaut `"Non renseignée"` de façon sécurisée, sans erreur

## Indice
La syntaxe combinée s'écrit `utilisateur.adresse?.ville ?? "Non renseignée"`.

## Tests
```js
assert(typeof utilisateur === "object" && utilisateur !== null, "utilisateur doit être déclaré");
assert(typeof ville !== "undefined", "La variable ville doit être déclarée");
assert(ville === "Non renseignée", "ville doit valoir « Non renseignée » si l'adresse est absente");
```

## Solution: script.js
```js
const utilisateur = {
  nom: "Sacha",
};

const ville = utilisateur.adresse?.ville ?? "Non renseignée";
```
