## Cours
Une fonction est un bloc d'instructions réutilisable qui accomplit une tâche précise.
Elle peut recevoir des données d'entrée (appelées **paramètres**) et renvoyer un résultat à l'aide du mot-clé **`return`** :

```js
function multiplierParTrois(n) {
  return n * 3;
}

const total = multiplierParTrois(4); // total vaut 12
```

L'instruction `return` termine l'exécution de la fonction et transmet la valeur calculée au programme qui l'a appelée.

## Énoncé
Dans `script.js`, écris une fonction nommée `doubler` qui prend un paramètre `n` et renvoie son double (`n * 2`).
Appelle ensuite cette fonction en lui passant le nombre `7` et stocke le résultat dans une variable `reponse`.

## Méthode
- [ ] Déclare la fonction `function doubler(n)`
- [ ] Utilise `return n * 2;` dans le corps de la fonction
- [ ] Appelle `doubler(7)` et stocke le résultat dans `const reponse`

## Résultat
- [ ] La fonction `doubler` renvoie le double de n'importe quel nombre
- [ ] La variable `reponse` vaut `14`

## Indice
La structure s'écrit :
```js
function doubler(n) {
  return n * 2;
}
const reponse = doubler(7);
```

## Solution: script.js
```js
function doubler(n) {
  return n * 2;
}

const reponse = doubler(7);
```
