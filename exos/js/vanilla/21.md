## Cours
Pour organiser proprement son code en plusieurs fichiers sans encombrer l'objet global `window`, les navigateurs gèrent nativement les modules JavaScript grâce à l'attribut `type="module"` sur la balise `<script>` :
```html
<script type="module">
  import { maFonction } from "./outils.js";
  maFonction();
</script>
```

Dans un module :
- Le code est automatiquement exécuté en mode strict (`"use strict"`).
- Les variables déclarées restent privées au fichier.
- Le mot-clé `export` permet de partager des fonctions, variables ou constantes.

Exemple :
```js
export function doubler(x) {
  return x * 2;
}
```

## Énoncé
Dans `index.html` :
1. Crée une balise `<script type="module">`.
2. À l'intérieur, déclare et exporte une fonction `calculerTVA(prixHT)` qui renvoie `prixHT * 1.2`.

## Méthode
- [ ] Utilise la balise `<script type="module">`
- [ ] Déclare la fonction avec `export function calculerTVA(prixHT)`
- [ ] Renvoie le montant TTC calculé (`prixHT * 1.2`)

## Résultat
- [ ] La balise `<script type="module">` est présente
- [ ] La fonction `calculerTVA` est déclarée et exportée

## Indice
La balise s'écrit `<script type="module">`, puis utilise le mot-clé `export` devant la déclaration de fonction.

## Tests
```js
const scriptModule = $("script[type='module']");
assert(scriptModule, "Il faut une balise <script type='module'>");
const code = scriptModule.textContent;
assert(code.includes("calculerTVA"), "Déclare la fonction calculerTVA dans le module");
assert(code.includes("export "), "La fonction doit être exportée avec le mot-clé export");
assert(code.includes("1.2") || code.includes("0.2"), "La fonction doit calculer la TVA avec un taux de 20 % (prixHT * 1.2)");
```

## Solution: index.html
```html
<script type="module">
  export function calculerTVA(prixHT) {
    return prixHT * 1.2;
  }
</script>
```
