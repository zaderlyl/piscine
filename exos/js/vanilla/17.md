## Cours
La balise `<template>` permet de définir un modèle HTML réutilisable qui n'est pas affiché au chargement de la page.

En JavaScript, on peut cloner son contenu avec `template.content.cloneNode(true)`, remplir les données souhaitées, puis insérer le clone dans le document avec `appendChild()` :
```js
const template = document.querySelector("#mon-modele");
const clone = template.content.cloneNode(true);
clone.querySelector(".titre").textContent = "Nouvelle carte";
document.body.appendChild(clone);
```

## Énoncé
Dans `index.html` :
1. Crée un modèle `<template id="carte-profil">` contenant :
   ```html
   <article class="carte">
     <h2 class="nom"></h2>
     <p class="role"></p>
   </article>
   ```
2. Crée un conteneur `<div id="trombinoscope"></div>`.
3. Dans un script, parcours le tableau `const profils = [{ nom: "Ada", role: "Dev" }, { nom: "Alan", role: "Mathématicien" }]` :
   - Clone le template pour chaque profil avec `.cloneNode(true)`.
   - Remplis le `.nom` et le `.role`.
   - Insère chaque carte dans `#trombinoscope`.

## Méthode
- [ ] Utilise `template.content.cloneNode(true)`
- [ ] Remplis le texte des éléments du clone
- [ ] Ajoute le clone dans `#trombinoscope` avec `appendChild`

## Résultat
- [ ] `#trombinoscope` contient deux cartes `.carte` affichant respectivement "Ada" (Dev) et "Alan" (Mathématicien)

## Indice
Rappelle-toi que `template.content` contient les éléments du template à cloner avec `cloneNode(true)`.

## Tests
```js
assert($("#carte-profil"), "Ajoute une balise template avec l'identifiant carte-profil");
assert($("#trombinoscope"), "Ajoute un conteneur avec l'identifiant trombinoscope");
const cartes = $$("#trombinoscope .carte");
assert(cartes.length === 2, "Le trombinoscope doit contenir exactement deux cartes");
assert(cartes[0].querySelector(".nom")?.textContent.trim() === "Ada", "La première carte doit avoir pour nom « Ada »");
assert(cartes[1].querySelector(".role")?.textContent.trim() === "Mathématicien", "La deuxième carte doit avoir pour rôle « Mathématicien »");
```

## Solution: index.html
```html
<template id="carte-profil">
  <article class="carte">
    <h2 class="nom"></h2>
    <p class="role"></p>
  </article>
</template>
<div id="trombinoscope"></div>
<script>
  const profils = [
    { nom: "Ada", role: "Dev" },
    { nom: "Alan", role: "Mathématicien" },
  ];
  const template = document.querySelector("#carte-profil");
  const conteneur = document.querySelector("#trombinoscope");
  profils.forEach((p) => {
    const clone = template.content.cloneNode(true);
    clone.querySelector(".nom").textContent = p.nom;
    clone.querySelector(".role").textContent = p.role;
    conteneur.appendChild(clone);
  });
</script>
```
