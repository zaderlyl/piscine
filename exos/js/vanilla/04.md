## Cours
La boucle `for` permet de répéter un bloc d'instructions un nombre précis de fois à l'aide d'un compteur :

```js
let total = 0;
for (let i = 0; i < 3; i++) {
  total = total + 2;
}
```

L'en-tête `for (initialisation; condition; incrémentation)` réunit les 3 règles du cycle :
1. `let i = 0;` : initialisation du compteur au début de la boucle.
2. `i < 3;` : condition vérifiée avant chaque tour (si vrai, on entre dans la boucle).
3. `i++` : incrémentation du compteur après chaque tour (`i` augmente de 1).

## Énoncé
Dans `script.js`, déclare une variable `total` initialisée à `0`.
À l'aide d'une boucle `for`, réalise `4` tours de boucle (`let i = 0; i < 4; i++`) et ajoute `5` à la variable `total` à chaque passage.

## Méthode
- [ ] Déclare `let total = 0;`
- [ ] Rédige la boucle `for (let i = 0; i < 4; i++)`
- [ ] Dans le corps de la boucle, écris `total = total + 5;`

## Résultat
- [ ] La variable `total` vaut `20` au terme des 4 tours

## Indice
La syntaxe à l'intérieur de la boucle est `total = total + 5;` (ou `total += 5;`).

## Solution: script.js
```js
let total = 0;

for (let i = 0; i < 4; i++) {
  total = total + 5;
}
```
