## Cours
La méthode `addEventListener(type, callback)` permet d'exécuter une fonction dès qu'une action survient sur un élément (comme un clic de souris ou une touche pressée).

Exemple :
```js
const bouton = document.querySelector("#mon-bouton");
bouton.addEventListener("click", () => {
  console.log("Clic détecté !");
});
```

## Énoncé
Dans `index.html` :
1. Crée un bouton `<button id="mon-bouton">Compteur : <span id="valeur">0</span></button>`.
2. Dans un script, attache un écouteur d'événement `click` sur `#mon-bouton`.
3. À chaque clic, incrémente de 1 le nombre affiché dans `#valeur`.

## Méthode
- [ ] Sélectionne `#mon-bouton` et `#valeur`
- [ ] Utilise `bouton.addEventListener("click", () => { ... })`
- [ ] Incrémente une variable de compteur et mets à jour `valeur.textContent`

## Résultat
- [ ] Le compteur démarre à 0
- [ ] Chaque clic sur le bouton incrémente la valeur affichée de 1

## Indice
Déclare une variable `let compteur = 0;` et fais `compteur++; valeur.textContent = compteur;` dans la fonction du clic.

## Tests
```js
const bouton = $("#mon-bouton");
const valeur = $("#valeur");
assert(bouton, "Ajoute un bouton avec l'identifiant mon-bouton");
assert(valeur, "Ajoute un span avec l'identifiant valeur");
assert(valeur?.textContent.trim() === "0", "Écris 0 comme valeur de départ dans #valeur");
click("#mon-bouton");
assert(valeur?.textContent.trim() === "1", "Augmente #valeur de 1 à chaque clic (attendu : 1 après un clic)");
click("#mon-bouton");
assert(valeur?.textContent.trim() === "2", "Augmente #valeur de 1 à chaque clic (attendu : 2 après deux clics)");
```

## Solution: index.html
```html
<button id="mon-bouton">Compteur : <span id="valeur">0</span></button>
<script>
  let compteur = 0;
  const bouton = document.querySelector("#mon-bouton");
  const valeur = document.querySelector("#valeur");
  bouton.addEventListener("click", () => {
    compteur++;
    valeur.textContent = compteur;
  });
</script>
```
