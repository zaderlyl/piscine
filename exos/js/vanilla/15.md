## Cours
Quand une erreur survient, JavaScript arrête le programme. Par exemple, `JSON.parse` plante si le texte reçu n'est pas du JSON valide :

```js
JSON.parse("pas du json"); // ❌ SyntaxError : le programme s'arrête ici
```

Avec `try...catch`, on **tente** une opération risquée et on décide quoi faire si elle échoue, au lieu de laisser le programme s'arrêter :

```js
try {
  const donnees = JSON.parse(texte);
  console.log("Lecture réussie");
} catch (erreur) {
  console.log("Texte invalide :", erreur.message);
}
```

- Le code du bloc `try` s'exécute normalement.
- Dès qu'une erreur survient dans `try`, on saute directement dans `catch`, qui reçoit l'erreur.
- On peut aussi déclencher soi-même une erreur avec `throw new Error("message")`.

## Énoncé
Dans `script.js`, écris une fonction `lireJSON(texte)` qui :
1. essaie de convertir `texte` avec `JSON.parse(texte)` et renvoie le résultat ;
2. si la conversion échoue, renvoie `null` au lieu de faire planter le programme.

Appelle ensuite la fonction deux fois :
- `const valide = lireJSON('{"nom": "Sacha"}');`
- `const invalide = lireJSON("pas du json");`

## Méthode
- [ ] Place `JSON.parse(texte)` dans un bloc `try { ... }`
- [ ] Renvoie `null` dans le bloc `catch (erreur) { ... }`
- [ ] Déclare `valide` et `invalide` avec les deux appels de l'énoncé

## Résultat
- [ ] `valide` est l'objet `{ nom: "Sacha" }`
- [ ] `invalide` vaut `null`, sans erreur

## Indice
Le modèle est :
```js
function lireJSON(texte) {
  try {
    return ...;
  } catch (erreur) {
    return ...;
  }
}
```

## Solution: script.js
```js
function lireJSON(texte) {
  try {
    return JSON.parse(texte);
  } catch (erreur) {
    return null;
  }
}

const valide = lireJSON('{"nom": "Sacha"}');
const invalide = lireJSON("pas du json");
```
