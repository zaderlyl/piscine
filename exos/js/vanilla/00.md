## Cours
HTML structure le contenu d'une page web, CSS gère son apparence visuelle. JavaScript apporte **la logique et le dynamisme** : mémoriser des informations, faire des calculs, réagir aux actions de l'utilisateur ou modifier la page en direct.

Pour mémoriser une information dans un programme, on utilise une **variable**. Le mot-clé `const` permet de créer une variable dont la valeur ne change pas :

```js
const prenom = "Alice";
```

Une valeur textuelle (chaîne de caractères) s'écrit toujours entre guillemets.

## Énoncé
Dans `script.js`, déclare une variable `message` avec le mot-clé `const` et donne-lui la valeur `"Bonjour"`.

## Méthode
- [ ] Utilise le mot-clé `const`
- [ ] Nomme la variable `message`
- [ ] Assigne la valeur `"Bonjour"` avec le signe `=`

## Résultat
- [ ] La variable `message` contient le texte `"Bonjour"`

## Indice
Déclare la variable comme ceci : `const message = "Bonjour";`.

## Tests
```js
assert(typeof message !== "undefined", "La variable message doit être déclarée");
assert(message === "Bonjour", "La variable message doit contenir exactement « Bonjour »");
assert(/\bconst\s+message\b/.test(code), "La variable message doit être déclarée avec const");
```

## Solution: script.js
```js
const message = "Bonjour";
```
