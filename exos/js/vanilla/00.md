## Cours
HTML structure le contenu d'une page web, CSS gère son apparence. **JavaScript** apporte **la logique et le dynamisme** : mémoriser des informations, faire des calculs, réagir aux actions de l'utilisateur ou modifier la page en direct.

### Un programme
Un programme JavaScript est une suite d'**instructions** que le navigateur exécute les unes après les autres, de haut en bas. On les écrit dans un fichier qui se termine par `.js`, par exemple `script.js`. Chaque instruction se termine par un point-virgule.

### Mémoriser avec une variable
Pour garder une information, on la range dans une **variable** : une case qui porte un nom et contient une valeur. On peut ensuite réutiliser cette valeur en citant le nom de la case.

```js
const prenom = "Alice";
```

Un texte s'écrit toujours entre guillemets. Dans l'exercice suivant, tu vas créer ta première variable.
