## Cours
JavaScript permet d'effectuer des calculs mathématiques avec les opérateurs arithmétiques classiques :
- L'addition : `+`
- La soustraction : `-`
- La multiplication : `*`
- La division : `/`

On peut effectuer des opérations directement entre nombres ou en combinant des variables existantes :

```js
const prix = 12;
const quantite = 3;
const total = prix * quantite;
```

## Énoncé
Dans `script.js`, déclare une variable `largeur` valant `8` et une variable `hauteur` valant `5`. Déclare ensuite une variable `aire` qui calcule la surface en multipliant `largeur` par `hauteur`.

## Méthode
- [ ] Déclare `largeur = 8`
- [ ] Déclare `hauteur = 5`
- [ ] Déclare `aire = largeur * hauteur`

## Résultat
- [ ] La variable `aire` vaut `40`

## Indice
Utilise le symbole de multiplication `*` entre les deux variables : `const aire = largeur * hauteur;`.

```js
const largeur = 8;
const hauteur = 5;
const aire = largeur * hauteur;
```
