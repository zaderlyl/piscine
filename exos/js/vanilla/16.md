## Cours
Une **classe** est un plan de construction : elle décrit ce que possèdent et savent faire tous les objets d'un même type. On crée ensuite des objets (des **instances**) avec `new`.

```js
class Personnage {
  constructor(nom, vie) {
    this.nom = nom;
    this.vie = vie;
  }

  decrire() {
    return `${this.nom} a ${this.vie} points de vie`;
  }
}

const heros = new Personnage("Ada", 100);
heros.decrire(); // "Ada a 100 points de vie"
```

- `constructor` s'exécute à chaque `new` et prépare l'objet ; `this` désigne l'objet en cours de création.
- Une fonction écrite dans la classe s'appelle une **méthode**.

L'**héritage** permet de créer une classe à partir d'une autre avec `extends` : elle récupère tout ce que sait faire la classe parente, et peut y ajouter ses propres méthodes. `super(...)` appelle le constructeur du parent.

```js
class Guerrier extends Personnage {
  constructor(nom, vie, force) {
    super(nom, vie);
    this.force = force;
  }
}
```

## Énoncé
Dans `script.js` :
1. Déclare une classe `Personnage` dont le constructeur reçoit `nom` et `vie` et les enregistre dans `this.nom` et `this.vie`. Ajoute-lui une méthode `decrire()` qui renvoie le texte `"<nom> a <vie> points de vie"`.
2. Déclare une classe `Guerrier` qui **étend** `Personnage`. Son constructeur reçoit `nom`, `vie` et `force`, appelle `super(nom, vie)` et enregistre `this.force`.
3. Crée `const conan = new Guerrier("Conan", 120, 15);`.

## Méthode
- [ ] `class Personnage { constructor(nom, vie) { ... } decrire() { ... } }`
- [ ] `class Guerrier extends Personnage { constructor(nom, vie, force) { super(nom, vie); ... } }`
- [ ] `const conan = new Guerrier("Conan", 120, 15);`

## Résultat
- [ ] `conan.decrire()` renvoie `"Conan a 120 points de vie"`
- [ ] `conan.force` vaut `15`

## Indice
Dans le constructeur d'une classe qui étend une autre, `super(...)` doit être appelé **avant** d'utiliser `this`.

## Solution: script.js
```js
class Personnage {
  constructor(nom, vie) {
    this.nom = nom;
    this.vie = vie;
  }

  decrire() {
    return `${this.nom} a ${this.vie} points de vie`;
  }
}

class Guerrier extends Personnage {
  constructor(nom, vie, force) {
    super(nom, vie);
    this.force = force;
  }
}

const conan = new Guerrier("Conan", 120, 15);
```
