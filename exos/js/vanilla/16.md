## Cours
La **délégation d'événements** consiste à poser un seul écouteur sur un élément parent (comme une liste `<ul>`) au lieu de poser un écouteur sur chaque enfant.

Grâce à la remontée de l'événement (*bubbling*) :
- `e.target` indique l'élément exact qui a reçu le clic.
- `e.target.closest("sélecteur")` permet de retrouver le bouton ou l'élément ciblé même si l'utilisateur a cliqué sur un texte ou une icône à l'intérieur.

Exemple :
```js
liste.addEventListener("click", (e) => {
  const bouton = e.target.closest(".btn-suppr");
  if (bouton) {
    bouton.closest("li").remove();
  }
});
```

## Énoncé
Dans `index.html` :
1. Crée une liste `<ul id="taches">` contenant au moins deux éléments :
   - `<li><span>Tâche 1</span> <button class="btn-suppr">Supprimer</button></li>`
   - `<li><span>Tâche 2</span> <button class="btn-suppr">Supprimer</button></li>`
2. Dans un script, attache **un seul** écouteur de clic sur `#taches`.
3. Lorsqu'un clic est détecté sur un bouton `.btn-suppr`, supprime le `<li>` correspondant du DOM avec la méthode `.remove()`.

## Méthode
- [ ] Attache l'écouteur sur `document.querySelector("#taches")`
- [ ] Vérifie la cible avec `e.target.closest(".btn-suppr")`
- [ ] Supprime le `<li>` parent avec `btn.closest("li").remove()`

## Résultat
- [ ] Cliquer sur le bouton supprimer retire l'élément `<li>` de la liste

## Indice
Utilise `e.target.closest(".btn-suppr")` dans l'écouteur du parent, puis supprime son parent `li`.

## Tests
```js
const liste = $("#taches");
assert(liste, "Ajoute une liste avec l'identifiant taches");
assert($$("#taches li").length >= 2, "Ajoute au moins deux éléments <li> dans la liste");
const premierLi = $("#taches li");
const bouton = premierLi?.querySelector(".btn-suppr");
assert(bouton, "Ajoute un bouton avec la classe btn-suppr dans chaque <li>");
bouton?.click();
assert(bouton && !document.body.contains(premierLi), "Retire le <li> avec remove() quand on clique sur son bouton Supprimer");
```

## Solution: index.html
```html
<ul id="taches">
  <li><span>Tâche 1</span> <button class="btn-suppr">Supprimer</button></li>
  <li><span>Tâche 2</span> <button class="btn-suppr">Supprimer</button></li>
</ul>
<script>
  const liste = document.querySelector("#taches");
  liste.addEventListener("click", (e) => {
    const btn = e.target.closest(".btn-suppr");
    if (btn) {
      btn.closest("li").remove();
    }
  });
</script>
```
