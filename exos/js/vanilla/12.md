## Cours
Ce palier conclut le premier sous-module **Fondamentaux & Algorithmique**. Il remobilise l'ensemble des notions acquises : variables, tableaux d'objets, boucle d'accumulation et fonction réutilisable.

Dans une application ou un jeu vidéo, un catalogue ou un inventaire est généralement représenté par un tableau d'objets :

```js
const inventaire = [
  { nom: "Épée", prix: 50, stock: 2 },
  { nom: "Potion", prix: 10, stock: 5 },
  { nom: "Bouclier", prix: 40, stock: 0 },
];
```

Pour agréger des données, on utilise le **pattern d'accumulation** :
1. Initialiser une variable `total = 0`.
2. Parcourir chaque élément avec une boucle (`for` ou `for...of`).
3. Ajouter la valeur de chaque élément au total (`total += article.prix * article.stock`).
4. Renvoyer le total calculé à la fin avec `return`.

## Énoncé
Dans `script.js` :
1. Déclare le tableau `inventaire` contenant exactement ces 3 objets :
   - `{ nom: "Épée", prix: 50, stock: 2 }`
   - `{ nom: "Potion", prix: 10, stock: 5 }`
   - `{ nom: "Bouclier", prix: 40, stock: 0 }`
2. Rédige une fonction `calculerValeurTotale(articles)` qui reçoit un tableau d'articles et renvoie la somme cumulée de leurs valeurs (`prix * stock`).
3. Appelle cette fonction sur `inventaire` et enregistre le résultat dans `const valeurStock`.

## Méthode
- [ ] Déclare le tableau `const inventaire = [ ... ];`
- [ ] Déclare la fonction `calculerValeurTotale(articles)` avec un accumulateur `let total = 0;`
- [ ] Parcours les articles avec `for (const article of articles)`
- [ ] Renvoie le total avec `return total;`
- [ ] Calcule `const valeurStock = calculerValeurTotale(inventaire);`

## Résultat
- [ ] La fonction calcule correctement la valeur de n'importe quel inventaire
- [ ] La variable `valeurStock` vaut `150` (50×2 + 10×5 + 40×0)

## Indice
La boucle dans la fonction peut s'écrire :
```js
for (const article of articles) {
  total += article.prix * article.stock;
}
```

## Tests


## Solution: script.js
```js
const inventaire = [
  { nom: "Épée", prix: 50, stock: 2 },
  { nom: "Potion", prix: 10, stock: 5 },
  { nom: "Bouclier", prix: 40, stock: 0 },
];

function calculerValeurTotale(articles) {
  let total = 0;
  for (const article of articles) {
    total += article.prix * article.stock;
  }
  return total;
}

const valeurStock = calculerValeurTotale(inventaire);
```
