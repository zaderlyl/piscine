## Cours
La boucle `while` (tant que) permet de répéter un bloc d'instructions tant qu'une condition reste vraie :

```js
let tours = 0;
while (tours < 3) {
  tours = tours + 1;
}
```

Elle s'utilise principalement lorsque le nombre d'itérations n'est pas connu à l'avance.

Pour éviter qu'une boucle tourne à l'infini et bloque le navigateur, il faut respecter la **règle des trois phases** :
1. Initialiser une variable de contrôle avant la boucle.
2. Écrire la condition d'arrêt dans le `while (...)`.
3. Modifier la variable à l'intérieur de la boucle pour que la condition devienne fausse au bout d'un certain temps.

## Énoncé
Dans `script.js`, déclare une variable `population` valant `10`.
À l'aide d'une boucle `while`, tant que `population` est strictement inférieure à `50`, multiplie `population` par `2` (`population = population * 2;`).

## Méthode
- [ ] Déclare `let population = 10;`
- [ ] Rédige la condition `while (population < 50)`
- [ ] Dans le corps de la boucle, écris `population = population * 2;`

## Résultat
- [ ] La variable `population` vaut `80` au terme des itérations (10 → 20 → 40 → 80)

## Indice
La boucle s'écrit :
```js
while (population < 50) {
  population = population * 2;
}
```

## Tests
```js
assert(typeof population !== "undefined", "La variable population doit être déclarée");
assert(population === 80, "La variable population doit valoir 80 (10 doublé jusqu'à dépasser 50)");
```

## Solution: script.js
```js
let population = 10;

while (population < 50) {
  population = population * 2;
}
```
