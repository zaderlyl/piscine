## Cours
En JavaScript moderne (ES6+), les fonctions fléchées (`() => {}`) offrent une syntaxe plus concise que le mot-clé `function` :

```js
const multiplier = (a, b) => a * b;
```

Lorsque le corps de la fonction ne contient qu'une seule expression, les accolades `{}` et le mot-clé `return` sont implicites.

On peut également définir une **valeur par défaut** pour un paramètre. Si aucun argument n'est transmis lors de l'appel, cette valeur de secours est utilisée :

```js
const fêter = (nom = "visiteur") => "Bienvenue " + nom;
fêter();        // "Bienvenue visiteur"
fêter("Alice"); // "Bienvenue Alice"
```

## Énoncé
Dans `script.js`, déclare une fonction fléchée `saluer` qui reçoit un paramètre `prenom` avec la valeur par défaut `"collègue"`, et renvoie `"Bonjour " + prenom`.
Appelle cette fonction une première fois sans argument et enregistre le résultat dans une variable `messageDefaut`.
Appelle-la ensuite avec l'argument `"Léa"` et stocke le résultat dans `messagePerso`.

- [ ] Appelle `saluer()` sans argument et stocke dans `const messageDefaut`
- [ ] Appelle `saluer("Léa")` et stocke dans `const messagePerso`

- [ ] `messageDefaut` vaut `"Bonjour collègue"`
- [ ] `messagePerso` vaut `"Bonjour Léa"`

## Indice
La fonction s'écrit :
```js
const saluer = (prenom = "collègue") => "Bonjour " + prenom;
```

## Tests
```js
assert(typeof saluer === "function", "La fonction saluer doit être déclarée");
assert(saluer() === "Bonjour collègue", "saluer() sans argument doit renvoyer « Bonjour collègue »");
assert(saluer("Marc") === "Bonjour Marc", "saluer('Marc') doit renvoyer « Bonjour Marc »");
assert(typeof messageDefaut !== "undefined", "La variable messageDefaut doit être déclarée");
assert(messageDefaut === "Bonjour collègue", "messageDefaut doit valoir « Bonjour collègue »");
assert(typeof messagePerso !== "undefined", "La variable messagePerso doit être déclarée");
assert(messagePerso === "Bonjour Léa", "messagePerso doit valoir « Bonjour Léa »");
```

## Solution: script.js
```js
const saluer = (prenom = "collègue") => "Bonjour " + prenom;

const messageDefaut = saluer();
const messagePerso = saluer("Léa");
```
