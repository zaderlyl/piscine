## Cours
Une fois un élément sélectionné, JavaScript permet de modifier dynamiquement son contenu et ses attributs :
- `element.textContent = "Nouveau texte"` : modifie le texte de l'élément de manière sécurisée (sans faille XSS).
- `element.classList.add("classe")` : ajoute une classe CSS à l'élément.
- `element.dataset.attribut` : lit ou écrit une valeur dans l'attribut HTML `data-attribut`.

Exemple :
```js
const carte = document.querySelector(".carte");
carte.textContent = "Chargé";
carte.classList.add("visible");
carte.dataset.statut = "pret";
```

## Énoncé
Dans `index.html` :
1. Crée une balise `<div id="carte" data-niveau="1">Niveau 1</div>`.
2. Dans une balise `<script>`, sélectionne cet élément :
   - Modifie son texte avec `textContent` pour afficher "Niveau 2".
   - Ajoute-lui la classe CSS `valide` via `classList.add`.
   - Modifie la valeur de son attribut `dataset.niveau` pour qu'elle vaille `"2"`.

## Indice
Accède aux propriétés de ton élément sélectionné : `.textContent`, `.classList.add(...)` et `.dataset.niveau`.

## Tests
```js
const carte = $("#carte");
assert(carte, "Ajoute une div avec l'identifiant carte");
assert(carte.textContent.trim() === "Niveau 2", "Le texte de la carte doit être « Niveau 2 »");
assert(carte.classList.contains("valide"), "La carte doit avoir la classe CSS valide");
assert(carte.dataset.niveau === "2", "L'attribut data-niveau doit valoir « 2 »");
```

## Solution: index.html
```html
<div id="carte" data-niveau="1">Niveau 1</div>
<script>
  const carte = document.querySelector("#carte");
  carte.textContent = "Niveau 2";
  carte.classList.add("valide");
  carte.dataset.niveau = "2";
</script>
```
