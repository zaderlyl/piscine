## Cours
Parcourir un tableau avec une boucle `for` marche toujours, mais JavaScript propose trois méthodes plus courtes pour les cas les plus fréquents. Chacune reçoit une fonction (souvent fléchée) appelée sur chaque élément.

- `.map(f)` **transforme** chaque élément et renvoie un nouveau tableau de même taille :
  ```js
  const prix = [10, 20, 30];
  const doubles = prix.map((p) => p * 2); // [20, 40, 60]
  ```
- `.filter(f)` **garde** les éléments pour lesquels `f` renvoie `true` :
  ```js
  const grands = prix.filter((p) => p > 15); // [20, 30]
  ```
- `.reduce(f, départ)` **combine** tous les éléments en une seule valeur. `f` reçoit l'accumulateur et l'élément courant :
  ```js
  const somme = prix.reduce((total, p) => total + p, 0); // 60
  ```

Aucune de ces méthodes ne modifie le tableau d'origine.

## Énoncé
Dans `script.js`, avec ce tableau :
```js
const inventaire = [
  { nom: "Épée", prix: 50, stock: 2 },
  { nom: "Potion", prix: 10, stock: 5 },
  { nom: "Bouclier", prix: 40, stock: 0 },
];
```
1. Déclare `noms` : un tableau des noms des articles, obtenu avec `.map()`.
2. Déclare `disponibles` : le tableau des articles dont le `stock` est supérieur à 0, obtenu avec `.filter()`.
3. Déclare `valeurTotale` : la somme de `prix * stock` de tous les articles, obtenue avec `.reduce()`.

## Méthode
- [ ] Copie le tableau `inventaire` tel quel
- [ ] `const noms = inventaire.map((article) => article.nom);`
- [ ] `const disponibles = inventaire.filter((article) => article.stock > 0);`
- [ ] `const valeurTotale = inventaire.reduce((total, article) => total + ..., 0);`

## Résultat
- [ ] `noms` vaut `["Épée", "Potion", "Bouclier"]`
- [ ] `disponibles` contient l'Épée et la Potion
- [ ] `valeurTotale` vaut `150`

## Indice
Pour `reduce`, la valeur de départ est le deuxième argument : `inventaire.reduce((total, article) => total + article.prix * article.stock, 0)`.

## Solution: script.js
```js
const inventaire = [
  { nom: "Épée", prix: 50, stock: 2 },
  { nom: "Potion", prix: 10, stock: 5 },
  { nom: "Bouclier", prix: 40, stock: 0 },
];

const noms = inventaire.map((article) => article.nom);
const disponibles = inventaire.filter((article) => article.stock > 0);
const valeurTotale = inventaire.reduce((total, article) => total + article.prix * article.stock, 0);
```
