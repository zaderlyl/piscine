## Cours
Si `main` et `menu` ont avancé chacune de leur côté, Git crée un commit de fusion, avec deux parents.

Si les deux branches ont modifié des fichiers différents, la fusion se fait toute seule.

## Énoncé
1. Sur `main`, enregistre `index.html` avec le message `Change la page`.
2. Fusionne `menu` dans `main`.

## Indice
`git merge menu` fusionne la branche `menu` dans la branche courante.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
edit index.html
```

## Solution
```bash
git add index.html
git commit -m "Change la page"
git merge menu
```
