## Cours
Si `main` et `menu` ont avancé chacune de leur côté, Git crée un commit de fusion, qui a deux parents. Si les deux branches ont modifié des fichiers différents, la fusion se fait toute seule.

```
Avant :  A ← B      (menu)
         A ← C      (HEAD → main)

Après :  M  (HEAD → main)  a deux parents : C et B
```

## Énoncé
Sur `main`, enregistre `index.html` avec le message `Change la page`, puis fusionne `menu` dans `main`.

## Étapes
- commit "Change la page" | Sur `main`, prépare `index.html` puis enregistre-le : `git add index.html`, `git commit -m "Change la page"`. | `index.html` a changé sur `main`, `style.css` a changé sur `menu` : ils ne se gênent pas.
- fusion | Fusionne `menu` dans `main` : `git merge menu`. | Git crée un commit avec deux parents, sans rien te demander.

## Indice
Les deux branches ont changé des fichiers différents : la fusion est automatique.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
edit index.html
```

## Solution
```bash
git add index.html
git commit -m "Change la page"
git merge menu
```
