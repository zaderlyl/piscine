## Cours
Une pull request demande de fusionner une branche dans une autre. Elle se relit avant d'être fusionnée, ici sur `origin`.

Une fois fusionnée, ton `main` local se met à jour avec `git pull`.

## Énoncé
1. Ouvre une pull request de `menu` vers `main` : `gh pr create`.
2. Relis-la et approuve-la : `gh pr review --approve`.
3. Fusionne-la sur `origin` : `gh pr merge`.
4. Mets ton `main` local à jour : repasse sur `main`, puis `git pull`.

## Indice
Le `git pull` se fait depuis `main`, pas depuis `menu`.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
git push -u origin main
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git push -u origin menu
```

## Solution
```bash
gh pr create
gh pr review --approve
gh pr merge
git switch main
git pull
```
