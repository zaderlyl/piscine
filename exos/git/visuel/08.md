## Cours
`git revert` crée un nouveau commit qui défait les changements d'un commit précédent.

L'historique reste complet. C'est la bonne façon d'annuler un commit qui a déjà été partagé.

## Énoncé
`Ajoute le style` a cassé la page, mais le commit est déjà partagé : ne réécris pas l'historique. Annule-le avec un nouveau commit.

## Indice
`git revert HEAD` annule le dernier commit.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git add style.css
git commit -m "Ajoute le style"
```

## Solution
```bash
git revert HEAD
```
