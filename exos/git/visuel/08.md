## Cours
`HEAD` désigne le commit où tu es : ici, le dernier commit de `main`. `git revert HEAD` annule **ce dernier commit**.

`git revert` ne supprime rien. Il ajoute un nouveau commit qui défait les changements du précédent, et Git écrit son message tout seul.

Pourquoi pas `reset` ici ? `reset` efface le commit de l'historique. Si ce commit est déjà sur `origin`, les autres élèves qui l'ont récupéré ne retrouvent plus le même historique que toi. `revert` garde tout l'historique : c'est la bonne façon d'annuler un commit partagé.

```
Avant :  A ← B                  (HEAD → main)    B = « Ajoute le style »
Après :  A ← B ← R              (HEAD → main)    R = « Revert « Ajoute le style » »
```

## Énoncé
`Ajoute le style` a cassé la page, mais le commit est déjà partagé. Ne réécris pas l'historique : annule-le avec un nouveau commit.

## Étapes
- commit "Revert « Ajoute le style »" | Annule le dernier commit : `git revert HEAD`. | Git écrit le message tout seul : tu n'as rien à taper.

## Indice
Le commit à annuler est le dernier, donc `HEAD`. La commande est `git revert HEAD`.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git add style.css
git commit -m "Ajoute le style"
```

## Solution
```bash
git revert HEAD
```
