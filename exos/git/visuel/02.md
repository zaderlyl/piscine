## Cours
Une branche est une étiquette qui pointe vers un commit. Quand tu fais un commit, l'étiquette de la branche courante avance.

`git switch -c <nom>` crée une branche à partir du commit courant et te place dessus.

## Énoncé
Ton dépôt a déjà un commit `Ajoute la page`, et `style.css` est modifié.

Crée une branche `menu` à partir du commit courant, place-toi dessus, puis fais un commit de `style.css` avec le message `Ajoute le menu`.

## Indice
La commande `git switch -c menu` crée la branche et te place dessus en une fois.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
```

## Solution
```bash
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
```
