## Cours
Une branche est une étiquette qui pointe vers un commit.

`git switch -c menu` crée la branche `menu` à partir du commit courant et te place dessus. Quand tu fais un commit, c'est la branche courante qui avance.

## Énoncé
Ton dépôt a déjà un commit « Ajoute la page », et `style.css` est modifié.

1. Crée la branche `menu` et place-toi dessus.
2. Enregistre `style.css` sur `menu`, avec le message `Ajoute le menu`.

## Indice
`git switch -c menu` fait les deux premières choses en une seule commande.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
```

## Solution
```bash
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
```
