## Cours
Une branche est une étiquette qui pointe vers un commit. Quand tu fais un commit, c'est la branche courante qui avance.

`git switch -c menu` crée la branche `menu` à partir du commit courant, et te place dessus.

```
Avant :  A                        (HEAD → main)
Après :  A ← B                    (HEAD → menu)    B = « Ajoute le menu », sur menu
         main reste sur A
```

## Énoncé
Ton dépôt a déjà le commit « Ajoute la page », et `style.css` est modifié. Crée la branche `menu` et enregistre `style.css` dessus.

## Étapes
- branche menu | Crée la branche `menu` et place-toi dessus : `git switch -c menu`. | `git switch -c menu` fait les deux à la fois.
- commit "Ajoute le menu" | Prépare `style.css`, puis enregistre-le avec le message `Ajoute le menu`. | `git add style.css`, puis `git commit -m "Ajoute le menu"`.

## Indice
`git switch -c menu` fait les deux premières choses en une seule commande.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
```

## Solution
```bash
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
```
