## Cours
Un conflit arrive quand deux branches ont modifié le même fichier de façons différentes. Git ne choisit pas à ta place : tu corriges le fichier, tu l'ajoutes avec `git add`, puis tu enregistres avec `git commit`.

```
Avant :  A ← B      (menu : style.css modifié)
         A ← C      (HEAD → main : style.css modifié aussi)

Après :  conflit sur style.css : le commit attend ta correction
```

## Énoncé
Sur `main`, enregistre `style.css` avec le message `Ajoute le style`. Puis fusionne `menu` : Git signale un conflit sur `style.css`. Résous-le.

## Étapes
- commit "Ajoute le style" | Sur `main`, enregistre `style.css` : `git add style.css`, `git commit -m "Ajoute le style"`. | Ce commit est à faire avant la fusion.
- conflit | Fusionne `menu` : `git merge menu`. Git signale un conflit. | Un conflit arrive quand le même fichier a changé des deux côtés.
- index style.css | Corrige `style.css`, puis ajoute-le : `git add style.css`. | Tant qu'un conflit reste, `git commit` est refusé.
- commit "Fusionne le menu" | Enregistre la fusion : `git commit -m "Fusionne le menu"`. | Le commit de fusion garde les deux branches.

## Indice
`git status` indique les fichiers à corriger.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
edit style.css
```

## Solution
```bash
git add style.css
git commit -m "Ajoute le style"
git merge menu
git add style.css
git commit -m "Fusionne le menu"
```
