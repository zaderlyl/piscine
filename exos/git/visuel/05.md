## Cours
Un conflit arrive quand deux branches ont modifié le même fichier de façons différentes. Git ne choisit pas à ta place.

Tu corriges le fichier, tu l'ajoutes avec `git add`, puis tu enregistres avec `git commit`.

## Énoncé
1. Sur `main`, enregistre `style.css` avec le message `Ajoute le style`.
2. Fusionne `menu` dans `main`. Git signale un conflit.
3. Ajoute `style.css` avec `git add`, puis enregistre avec le message `Fusionne le menu`.

## Indice
Tant qu'un conflit reste, `git commit` est refusé. `git status` indique les fichiers à corriger.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
edit style.css
```

## Solution
```bash
git add style.css
git commit -m "Ajoute le style"
git merge menu
git add style.css
git commit -m "Fusionne le menu"
```
