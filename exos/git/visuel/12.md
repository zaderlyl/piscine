## Cours
Une fonctionnalité se livre en quatre temps : on crée une **branche**, on y enregistre plusieurs **commits**, on la **fusionne** dans `main`, puis on **publie** `main` sur `origin`. Tu connais chaque geste : ici, c'est toi qui enchaînes.

```
Avant :  A (HEAD → main)                          origin : A
Après :  A ← B ← C (HEAD → main, ta branche)      origin : A ← B ← C
```

## Énoncé
Ton site a une page, déjà publiée sur `origin`. Il te reste deux fichiers à enregistrer : `style.css` et `script.js`. Livre-les comme une fonctionnalité.

Il faut : travailler sur **une branche à toi** (tu choisis son nom), enregistrer **au moins deux commits** (un par fichier, avec les messages que tu veux), **fusionner** ta branche dans `main`, puis **publier** `main` sur `origin`.

## Étapes
- commits 3 | Crée ta branche (`git switch -c nom`), puis enregistre `style.css` et `script.js` en deux commits. | Pour chaque fichier : `git add fichier`, puis `git commit -m "ton message"`.
- integre | Reviens sur `main` (`git switch main`) et fusionne ta branche : `git merge nom`. | La fusion se fait depuis `main`, la branche à fusionner se met après `git merge`.
- serveur main | Publie `main` : `git push`. | Quand c'est publié, `origin/main` et `main` pointent sur le même commit.

## Indice
`git status` montre les fichiers qu'il reste à enregistrer, et `git branch` la branche sur laquelle tu es.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
git push -u origin main
edit style.css
edit script.js
```

## Solution
```bash
git switch -c fonctionnalite
git add style.css
git commit -m "Ajoute le style"
git add script.js
git commit -m "Ajoute le script"
git switch main
git merge fonctionnalite
git push
```
