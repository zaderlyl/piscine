## Cours
`origin` est le dépôt distant : la copie partagée de ton projet. `git push` envoie tes commits vers `origin`.

L'option `-u` retient la branche suivie, pour que `git pull` sache où aller.

```
Avant :  ton dépôt : A (HEAD → main)        origin : vide
Après :  ton dépôt : A (HEAD → main)        origin : A (main)
```

## Énoncé
Publie `main` sur `origin` pour la première fois. Puis enregistre `style.css` et publie ce nouveau commit.

## Étapes
- origine main | Publie `main` la première fois : `git push -u origin main`. | `-u` retient la branche suivie : ensuite, `git push` suffit.
- commit "Ajoute le style" | Enregistre `style.css` : `git add style.css`, puis `git commit -m "Ajoute le style"`. | Le message doit être exactement `Ajoute le style`.
- meme origin/main main | Publie le nouveau commit : `git push`. | Quand c'est publié, `origin/main` et `main` pointent sur le même commit.

## Indice
La première fois, précise `origin` et le nom de la branche. Après, `git push` suffit.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
```

## Solution
```bash
git push -u origin main
git add style.css
git commit -m "Ajoute le style"
git push
```
