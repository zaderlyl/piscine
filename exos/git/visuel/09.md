## Cours
`origin` est le dépôt distant : la copie partagée de ton projet. `git push` envoie tes commits vers `origin`.

L'option `-u` retient la branche suivie, pour que `git pull` sache où aller.

## Énoncé
1. Publie `main` sur `origin` pour la première fois.
2. Enregistre `style.css` avec le message `Ajoute le style`, puis publie-le.

## Indice
La première fois, précise `origin` et le nom de la branche. Ensuite, `git push` suffit.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
```

## Solution
```bash
git push -u origin main
git add style.css
git commit -m "Ajoute le style"
git push
```
