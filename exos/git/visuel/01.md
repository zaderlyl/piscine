## Cours
Un dépôt Git est un dossier que Git surveille. On le crée avec `git init`.

Un commit enregistre un état du projet. Il se fait en deux temps : `git add` prépare les fichiers, puis `git commit` les enregistre avec un message.

Les fichiers modifiés ne sont pas encore enregistrés. `git status` indique où en sont tes fichiers.

## Énoncé
Ton dossier contient deux fichiers modifiés : `index.html` et `style.css`, mais aucun dépôt Git.

Crée le dépôt, puis fais deux commits :
1. d'abord `index.html`, avec le message `Ajoute la page` ;
2. ensuite `style.css`, avec le message `Ajoute le style`.

## Indice
Commence par `git init`. Pour chaque commit : `git add <fichier>`, puis `git commit -m "<message>"`.

## Départ
```bash
```

## Solution
```bash
git init
git add index.html
git commit -m "Ajoute la page"
git add style.css
git commit -m "Ajoute le style"
```
