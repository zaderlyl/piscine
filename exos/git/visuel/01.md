## Cours
Un dépôt Git est un dossier que Git surveille. `git init` le crée.

Un commit enregistre un état du projet, en deux temps : `git add` prépare le fichier, `git commit` l'enregistre avec un message.

## Énoncé
Ton dossier contient `index.html`, modifié. Il n'y a pas encore de dépôt.

1. Crée le dépôt avec `git init`.
2. Prépare `index.html` avec `git add index.html`.
3. Enregistre-le avec `git commit -m "Ajoute la page"`.

## Indice
Fais les trois commandes dans cet ordre. Le message doit être exactement `Ajoute la page`.

## Solution
```bash
git init
git add index.html
git commit -m "Ajoute la page"
```
