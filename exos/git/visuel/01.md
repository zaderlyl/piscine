## Cours
Un dépôt Git est un dossier que Git surveille : `git init` le crée. Un commit enregistre un état du projet, et se fait en deux temps : `git add` prépare le fichier, `git commit` l'enregistre.

```
Avant :  (pas de dépôt)
Après :  A   (HEAD → main)      A = « Ajoute la page »
```

## Énoncé
Ton dossier contient `index.html`, modifié, mais il n'y a pas encore de dépôt. Fais ton premier commit.

## Étapes
- branche main | Crée le dépôt avec `git init`. | `git init` crée le dossier caché `.git`, où Git garde l'historique.
- index index.html | Prépare `index.html` avec `git add index.html`. | `git add` prépare seulement le fichier : il n'est pas encore enregistré.
- commit "Ajoute la page" | Enregistre avec `git commit -m "Ajoute la page"`. | Le message doit être exactement `Ajoute la page`.

## Indice
Trois commandes, dans cet ordre : `git init`, `git add index.html`, `git commit -m "Ajoute la page"`.

## Solution
```bash
git init
git add index.html
git commit -m "Ajoute la page"
```
