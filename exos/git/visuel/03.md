## Cours
`git merge menu` ramène dans la branche courante les commits de `menu`.

Si la branche courante n'a pas bougé depuis la création de `menu`, Git avance simplement la branche jusqu'au dernier commit de `menu`. C'est une fusion en « avance rapide ».

## Énoncé
La branche `menu` a un commit de plus que `main`. Fusionne `menu` dans `main`.

Tu dois être sur `main`. À la fin, `main` et `menu` doivent pointer vers le même commit.

## Indice
La commande prend le nom de la branche à fusionner, et fusionne dans la branche sur laquelle tu es.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
```

## Solution
```bash
git merge menu
```
