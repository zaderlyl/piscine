## Cours
`git merge menu` ramène dans la branche courante les commits de `menu`. Si `main` n'a pas bougé depuis la création de `menu`, Git avance simplement `main` : c'est une fusion en « avance rapide ».

```
Avant :  A ← B          (HEAD → main)    menu : B
Après :  A ← B          (HEAD → main, menu)
```

## Énoncé
La branche `menu` a un commit de plus que `main`. Fais avancer `main` jusqu'à `menu`.

## Étapes
- meme main menu | Fusionne `menu` dans `main` : tu dois être sur `main`, puis `git merge menu`. | Le nom de la branche à fusionner se met après `git merge`.

## Indice
`git merge menu` fusionne `menu` dans la branche sur laquelle tu es.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git switch -c menu
git add style.css
git commit -m "Ajoute le menu"
git switch main
```

## Solution
```bash
git merge menu
```
