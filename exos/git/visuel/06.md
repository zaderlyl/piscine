## Cours
`git restore` annule les modifications d'un fichier : il revient à la version du dernier commit. Une modification annulée ne peut pas être récupérée.

```
Avant :  style.css modifié, pas prêt
Après :  style.css identique au dernier commit
```

## Énoncé
`style.css` a été modifié par erreur. Annule cette modification.

## Étapes
- propre | Annule la modification : `git restore style.css`. | La commande prend le nom du fichier.

## Indice
`git restore <fichier>`.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
```

## Solution
```bash
git restore style.css
```
