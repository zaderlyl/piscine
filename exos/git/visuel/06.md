## Cours
`git restore` annule les modifications d'un fichier : le fichier revient à la version du dernier commit.

Attention : une modification annulée ne revient pas.

## Énoncé
`style.css` a été modifié par erreur. Annule cette modification.

## Indice
La commande prend le nom du fichier : `git restore <fichier>`.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
```

## Solution
```bash
git restore style.css
```
