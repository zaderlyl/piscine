## Cours
`git fetch` télécharge les nouveautés d'`origin` sans toucher à tes branches : elles apparaissent sous `origin/main`. `git pull` fait un `fetch`, puis fusionne `origin/main` dans ta branche courante.

```
Avant :  ton dépôt : A (HEAD → main)        origin : A ← D (main)
Après :  ton dépôt : A ← D (HEAD → main)    origin : A ← D (main)
```

## Énoncé
Un autre élève a publié « Ajoute la doc » sur `origin`. Récupère ce commit et mets `main` à jour.

## Étapes
- branche origin/main | Récupère les nouveautés : `git fetch`, ou directement `git pull`. | `origin/main` apparaît dès que tu as récupéré.
- meme main origin/main | Mets `main` à jour : `git pull`. | Ici `main` avance sans fusion : c'est une avance rapide.

## Indice
`git pull` suffit.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
git push -u origin main
autre-dev push "Ajoute la doc"
```

## Solution
```bash
git pull
```
