## Cours
`git fetch` télécharge les nouveautés d'`origin` sans toucher à tes branches. Elles apparaissent sous `origin/main`.

`git pull` fait un `fetch`, puis fusionne la branche distante dans ta branche courante.

## Énoncé
Un autre élève a publié `Ajoute la doc` sur `origin`. Récupère ce commit et mets `main` à jour.

## Indice
Ici, `git pull` suffit.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git remote add origin https://exemple.test/piscine.git
git push -u origin main
autre-dev push "Ajoute la doc"
```

## Solution
```bash
git pull
```
