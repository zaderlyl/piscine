## Cours
`git reset` recule la branche d'un ou plusieurs commits.

Avec `--soft`, les modifications restent prêtes à être enregistrées. Sans option, elles redeviennent des modifications non indexées.

## Énoncé
Tu as enregistré `Ajoute le style` trop tôt. Annule ce commit, mais garde ses modifications prêtes à être enregistrées.

## Indice
`HEAD~1` désigne le commit qui précède le commit courant.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git add style.css
git commit -m "Ajoute le style"
```

## Solution
```bash
git reset --soft HEAD~1
```
