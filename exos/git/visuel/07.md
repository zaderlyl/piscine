## Cours
`HEAD` désigne **le commit où tu es en ce moment** : sur `main`, c'est le dernier commit enregistré.

`HEAD~1` veut dire « le commit juste avant HEAD ». `HEAD~2` serait deux commits avant.

`git reset --soft HEAD~1` déplace la branche sur ce commit précédent. Le dernier commit disparaît de l'historique, mais ses fichiers restent prêts à être enregistrés.

```
Avant :  A ← B        (HEAD → main)    B = « Ajoute le style »
Après :  A            (HEAD → main)    les fichiers de B sont prêts
```

- `--soft` : les fichiers restent dans la zone de préparation (`git add` les a mis là).
- Sans option : les fichiers redeviennent modifiés, mais pas prêts.

## Énoncé
Tu as enregistré `Ajoute le style` trop tôt. Annule ce commit, mais garde ses fichiers prêts à être enregistrés.

## Indice
Le commit à annuler est `HEAD`. Tu veux revenir d'un commit en arrière, donc le commit d'avant, c'est `HEAD~1`. L'option qui garde les fichiers prêts est `--soft`.

## Départ
```bash
git add index.html
git commit -m "Ajoute la page"
git add style.css
git commit -m "Ajoute le style"
```

## Solution
```bash
git reset --soft HEAD~1
```
